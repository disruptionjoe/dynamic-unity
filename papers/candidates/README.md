# papers/candidates/

Staged, source-hardened theorem, no-go, and prediction packages identified
through Lane 4 and ready for the Drafting Factory to assemble. Placement here
does not change a claim's grade. Terminal state is a Joe-review draft; Joe
always publishes.

The broader upstream inventory lives in
`../PAPER-OPPORTUNITY-PORTFOLIO-2026-07-24.md`, with its machine-readable
source in `../paper-opportunity-portfolio.json`. That portfolio intentionally
includes cheap-seed-ready, merge, clarification, research-dependent, and
transfer candidates. It is not a second drafting queue.

Only place a package in this directory when source hardening has produced a
bounded paper object worth handing to the Factory. A complete opportunity seed
may be recorded before that point; Factory seed readiness is neither scientific
promotion nor manuscript readiness.
