## Cheapest exact proof

For \(g'=c^2g\),

\[
\prec_{g'}=\prec_g,
\qquad
d\mathrm{vol}_{g'}=c^d d\mathrm{vol}_g.
\]

With \(\rho'=\rho/c^d\),

\[
\Lambda_{g',\rho'}
=
\rho'd\mathrm{vol}_{g'}
=
\rho d\mathrm{vol}_g
=
\Lambda_{g,\rho}.
\]

The complete Poisson point-process law is therefore identical. Since the
causal relation is also identical, the induced unmarked causal-set law is
identical. Every statistic of that object factors through the same quotient.

## Cheapest constructive control

For a fixed known \(m>0\),

\[
q_m(x,y)=e^{-m\tau_g(x,y)}
\]

changes under \(g\mapsto c^2g\), because
\(\tau_{c^2g}=c\tau_g\). A retained value reconstructs

\[
\tau_g(x,y)=-\frac{\log q_m(x,y)}m.
\]

If \(m\) is allowed to covary as \(m'=m/c\), the mark is invariant and the
scale gauge returns. The positive result therefore depends on a physically
fixed scale, not merely on adding more data.
