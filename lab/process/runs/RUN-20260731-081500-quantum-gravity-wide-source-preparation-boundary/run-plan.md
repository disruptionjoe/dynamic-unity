## Frozen specimen

Use one positive two-cell, one-particle source with local mass/energy cells

\[
T_L=aP_L+\frac J2X,
\qquad
T_R=bP_R+\frac J2X,
\]

where \(a,b>0\), \(J\ge0\), and \(T_L+T_R\) is the complete source
Hamiltonian. Compare:

1. the hopping case \(J>0\), where a global stationary state can be wide;
2. the commuting case \(J=0\), where local profiles are exact; and
3. one two-source lattice interaction induced by the exact local profiles.

## Preregistered returns

- **Constructive lift:** a wide stationary state is a common local-energy
  eigenstate and supplies a non-Newtonian profile phase.
- **Spectral trilemma:** hopping makes the local cells noncommuting; removing
  hopping restores only localized joint profiles and the Newton operator;
  coarse-graining gains determinacy only by erasing the shape target.
- **Model-scope exit:** this finite source class is irrelevant to the paper's
  intended QFT source; preserve a QFT spectral-realizability reopener.

## Controls and stops

- A finite lattice counterexample does not refute every QFT source.
- Zero expected current does not imply that the local stress commutator
  annihilates the state.
- A wavefunction density or stress expectation is not a deterministic
  eigenvalue profile.
- Do not replace the source operator with its expectation; that is a different
  semiclassical closure.
- Stop before device optimization, magnitude estimates, or hardware.
