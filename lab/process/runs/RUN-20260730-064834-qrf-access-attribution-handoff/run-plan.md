- **Purpose/North Star:** make physical reality intelligible by determining
  whether independently selected certified causal records reconstruct

- **Perspective/ontology:** methodological physical realism. A quantum

## Exact question

Does the reduced-QRF framework supply:

1. a physically selected observer/access/record interface;
2. an exact condition under which a block-valued fact survives a change of
   physical reference and loss of inaccessible degrees of freedom;
3. an observer-accessible statistic that identifies environmental versus
   reference-induced decoherence; or
4. only a typed conditional channel plus a source-attribution ambiguity that
   independent reference calibration can repair?

## Controls

- **Strongest absorber:** reduced QRF/open-system theory, random-unitary
  channels, nuisance-parameter identifiability, Ramsey metrology, and
  `HC-DU-149`.
- **Cheapest kill:** the source explicitly chooses the accessible subsystem,
  PVMs, factorized assignment, and phase reference; or its environment/frame
  factors enter only through one product.
- **Positive handoff control:** construct one block-preserving reduced effect
  that does not commute with the controlled inaccessible dynamics and changes
  an output population, then one commuting effect that preserves it.
- **Positive attribution repair:** independently calibrate one reference
  contribution and require the environment/reference design matrix to become
  full rank.
- **Anti-conflation:** changing coordinates for the same complete experiment
  must preserve statistics when state and measurement are transformed
  together. Local Ramsey experiments tied to different physical phase
  standards are different operational procedures, not contradictory
  descriptions of one procedure.
- **Stop:** do not infer intrinsic gravitational decoherence, a selected
  observer, a formed record, new physics, or an experimental authorization
  from a reduced channel alone.
