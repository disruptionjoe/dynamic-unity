# Dual-phase xenon S1/S2 event-pairing gate

## Cold-start contract

- **Purpose:** make physical reality intelligible as one coherent,
  evidence-accountable whole.
- **North Star:** determine what target-blind physical antecedents, if any,
  select material, provenance-bearing, observer-indexed record interfaces;
  then test reconstruction, operational duality, and finite remainder.
- **Starting state:** `HC-DU-182` joins acquisition and conditional absolute
  depth but leaves event association, prompt event time, path polarity,
  source identity, and response order open.
- **Bounded role:** test a distinct single detector architecture that
  physically joins prompt S1 and delayed S2; determine whether the joined
  stream selects common-event identity.
- **Owning lane/channels:** Lane 3 with Lanes 1, 4, and 7 support;
  `CH-EMPIRICAL`, `CH-FORMAL`, `CH-MODEL`, and `CH-COLLIDE`.

## Frozen question

> Does one source-pinned dual-phase detector physically join event time,
> depth, transverse position, response class, and retained acquisition; and
> does that joined packet certify which prompt and delayed signals belong to
> the same occurrence?

## Pre-registered theorem, kills, and repairs

- **Pairing criterion:** a target factors through a raw peak packet iff it is
  constant across every physically admissible S1/S2 matching.
- **Unique-matching repair:** one admissible matching is sufficient for exact
  event pairing.
- **Ambiguity kill:** two S1 and two S2 peaks can share one drift window while
  admitting two perfect matchings with different reconstructed depths.
- **S2-only kill:** without prompt S1, delayed arrival time does not separate
  event time from depth.
- **Repairs:** retain a common causal tag, or justify a completion class whose
  compatibility graph is uniquely matchable. Keep record refinement and
  completion narrowing distinct.
- **Archive boundary:** lossless triggerless storage retains peaks, not their
  common-occurrence truth.

## Grade and absorber contract

- **Maximum:** scoped Grade 4 event-pairing/depth factorization boundary.
- **Conditional:** Grade 3 depth reconstruction in a calibrated,

- **Source audit:** Grade 2.
- **Absorbers:** dual-phase xenon response, TPC transport, DAQ, event
  building, accidental-coincidence analysis, bipartite matching, data
  association, calibration, and classification.
- **No novelty credit:** for S1/S2 reconstruction or matching theory as such.
