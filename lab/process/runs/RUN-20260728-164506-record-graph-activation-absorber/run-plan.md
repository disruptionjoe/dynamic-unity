# Can settlement distinguish type arrival from delayed activation?

## Question

Time as Finality's nucleation-ratchet toy leaves one apparent in-model
issuance residue: a type arriving later may consume only a record that already
exists, producing a chain rather than the star available when every type is
declared initially.

Does this order-dependent consumption edge distinguish physical type issuance,
or can a fixed type universe with delayed activation generate the same
time-indexed weighted record graph and therefore every record-derived
settlement value?

## Frozen contract

- **Primary Lane:** 1, supported by 2, 5, and 7.
- **Channels:** formal, collision, and synthesis.
- **Maximum grade:** scoped Grade 4 factorization/necessity boundary using
  standard graph and sufficient-statistic mathematics; no source issuance,
  physical record selection, time, or new law.
- **External input:** Time as Finality commit `9981cb1`; it is evidence to
  verify, not Dynamic Unity authority.
- **Strongest absorbers:** fixed type reservoir plus delayed activation,
  fixed stage-0 oracle/completed history, graph isomorphism, hidden-state
  activation, and commitment/opening models.
- **Cheapest kill:** construct a predeclared fixed-type process whose activation
  order and edge rule reproduce the nucleated arm's complete time-indexed
  weighted record graph.
- **Local-model boundary:** an exact graph-factorization proof and one finite
  witness decide the attribution question. Do not rebuild or extend TaF's
  simulation unless those leave a genuine ambiguity.
- **Hardware:** unavailable and irrelevant.

## Method

1. Freeze the record-derived settlement functional and identify its complete
   sufficient object.
2. Factor the toy's varying mechanisms into type pre-existence, activation
   order, variant selection, and consumption-edge rule.
3. Construct the missing predeclared-plus-delayed-activation chain arm.
4. Prove equality of every graph-derived observable under equality of the
   time-indexed weighted record graphs.
5. Separate attainability, defect, settlement, provenance, and source-issuance
   claims.
6. State the minimum record or intervention that could distinguish
   pre-existence from genuine source extension.
7. Return a reopener verdict for Dynamic Unity.

## Stop

Stop when the fixed-type activation completion either reproduces the complete
observable record process or fails for one exact typed reason. Do not infer
source ontology from graph shape, settlement price, stochastic symmetry
breaking, or a model label. Do not import TaF's declared record interface as
physical selection.
