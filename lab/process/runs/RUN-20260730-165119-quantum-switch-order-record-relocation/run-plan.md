## Frozen question

> distinguishable order carrier, has a physical order been finalized, or has
> order coherence merely moved into a larger system and become inaccessible

## Frozen specimen

Use a two-branch quantum-controlled order with branch labels
\(A\prec B\) and \(B\prec A\). Correlate those branches with pure marker
states \(|r_0\rangle,|r_1\rangle\) of overlap
\(\gamma=\langle r_0|r_1\rangle\). Keep four objects distinct:

1. the coherent global order-plus-marker state;
2. the reduced process after marker access is withheld;
3. the diagonal order record available to a restricted observer; and
4. a coherent joint action that can erase the marker and reveal the hidden
   off-diagonal completion.

Do not infer a global actualization from reduced causal separability.

## Controls

1. Derive the reduced branch coherence
   \(V=|\langle r_0|r_1\rangle|\).
2. Derive pure-marker distinguishability
   \(D=\sqrt{1-V^2}\) and verify \(D^2+V^2=1\) on exact rational cases.
3. For orthogonal markers, compare the coherent Bell-like completion with
   the corresponding incoherent mixture. Require identical diagonal order
   records and different \(X\otimes X\) responses.
4. Show that marker-basis conditioning restores unit branch interference
   although the unconditioned reduced branch state has zero interference.
5. Collide the scoped result with quantum-switch causal nonseparability,
   dephasing results, which-way complementarity, and quantum erasure.
