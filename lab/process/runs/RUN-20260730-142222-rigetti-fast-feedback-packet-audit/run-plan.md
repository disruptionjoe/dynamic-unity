## Pre-registered returns

### Full implementation reopener

Every admitted attempt is joined across physical acquisition, classifier,
decoder, applied action, later response, controller route/state, retention,
provenance, access, reset, and hidden-environment scope.

### Returned-shot partial reopener

Rows join integrated soft measurements, hard classifications, decoder
registers, timing, and later response, while the all-attempt acquisition
selector, rejected stratum, complete controller implementation, or archive
semantics remain absent.

### Aggregate-only absorption

The file contains only histograms, fitted process estimates, or unjoined
arrays and therefore does not improve `HC-DU-164`.

### Source mismatch

The downloaded object fails the frozen hashes or source metadata.

## Exact controls

1. Verify both hashes and the Ankaa-2 session identity.
2. Verify eight circuits with rounds 2 through 9 and 1,000 aligned rows each.
3. Verify hard and complex soft measurements share identical shapes for every
   measured qubit.
4. Verify one decoder-register row and one timing row per repetition.
5. Verify that qubit 50 contains one post-feedback measurement beyond the
   QEC measurement sequence.
6. Interpret decoder register `DASR=1` as the documented conditional
   \(X\)-branch and `0/2` as no \(X\); test the no-refit response relation
   \(Y=X_{\rm pre}\oplus\mathbf1[DASR=1]\) without claiming unit fidelity.
7. On every repeated complete hard-history key, test whether `DASR` conflicts.
8. Audit the schema for a main hardware program, firmware/configuration,
   attempt selector, rejected/retried attempts, raw waveform lineage,
   controller route/memory, and archive/reset semantics.

## Strongest absorber, cheapest kill, and stop

- **Strongest absorber:** standard real-time quantum error correction,
  classical feedback, process identification, measurement classification,
  provenance schemas, and the acquisition-visibility factorization boundary.
- **Cheapest positive:** one row index joins syndrome history, decoder
  register, branch timing, and post-feedback response.
- **Cheapest full-reopener kill:** no census of pre-return attempts or rejected
  controller executions.
- **Stop:** after the 5.6 MB fast-feedback file. Do not download the 130 MB,
  344 MB, or 741 MB stability files, contact the authors, run hardware, infer
  hidden physics, or promote an accepted-shot result to an all-attempt result.
