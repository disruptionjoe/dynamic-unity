# Full-portfolio GU-inclusive successor reassessment

## Objective

Use the five-person science council inline to reassess Dynamic Unity's full
scientific portfolio for the highest-value GU-independent or GU-inclusive
route, without rewarding a branch merely for ambition or repeating a stopped
interface-selection pattern.

## Frozen decision contract

A route can be selected only if it supplies:

1. a genuinely new physical or formal antecedent relative to the banked
   portfolio;
2. a local first learning before any external hardware requirement;
3. one sharp positive and one cheap kill;
4. direct contact with the North-Star interface-selection dependency; and
5. a reason the proposed work is not already absorbed by a completed DU
   branch or mature standard theory.

Council agreement is work-ordering input, not scientific evidence. GU is
allowed to win on earned readiness or ceiling, but repository custody and
program ambition carry no evidentiary weight.

antecedent discharges that branch's named reopener. Do not mutate GU or

conditional reopener, and explicit no-ready disposition where warranted.
