# Common causal-response host audit

- **Purpose:** make physical reality intelligible as one coherent,
  evidence-accountable whole.
- **North Star:** determine what target-blind physical antecedents, if any,
  select material, provenance-bearing, observer-indexed record interfaces;
  then test their reconstruction, operational duality, and finite remainder.
- **Evidence boundary:** methodological physical realism with detailed
  ontology open. Observer-indexed is physical rather than subjective;
  representation, lawful response, material formation, archive, access, and
  certification remain separately typed.
- **Active program/action:** the sole scientific WIP is
  `CCR-MINIMAL-PHYSICAL-ANTECEDENT-TO-FINITE-REMAINDER`; this run executes
  `CCRT-W2-COMMON-RESPONSE-OBJECT-AUDIT`.
- **Earned input:** `HC-DU-176` gives exact joint-target factorization and
  target-relative persistence in an abstract finite fixture. This run first
  corrects its executive scope from physical independence to logical
  independence of typed targets.
- **Remaining obligation:** apply one typed adapter and duty matrix to the
  strongest response formalisms and determine whether any selects a missing
  physical record-interface duty.
- **Owning lane/channel:** Lane 1 with Lanes 2, 3, 4, 6, and 7 support;
  `CH-FORMAL`, `CH-SYN`, `CH-COLLIDE`, and `CH-FRONTIER`.

Preserve the exact `HC-DU-176` factorization theorems while replacing claims

not to new physics or independent physical realizability.

## Frozen typed adapter

For each candidate record:

1. primitive object and mathematical category;
2. supplied source, state, contour, boundary, gauge, renormalization, and
   observer/instrument inputs;
3. dynamically or variationally selected outputs;
4. response semantics: in-out, in-in, retarded/advanced, noise, multi-time
   intervention, or relational action;
5. invariant response-order definition for a frozen source-observable pair;
6. formation-stage selection;
7. material-carrier and target-bearing persistence selection;
8. provenance, observer access, and certified quotient selection;
9. empirical excess over the strongest standard absorber.

Objects of unlike type are not compared until this adapter is filled. A
functional-derivative order is not a spacetime-derivative order.

## Mandatory candidates

1. classical action, Peierls response, and covariant phase space;
2. in-out 1PI effective action;
3. closed-time-path/in-in and influence-functional response;
4. Schwinger--Dyson and \(n\)PI hierarchies;
5. stochastic gravity/noise kernels;
6. locally covariant QFT and relative Cauchy evolution;
7. process tensors/quantum combs;
8. direct-action or field-eliminated descriptions; and
9. one action-selection rival, causal fermion systems.

Field-redefinition and gauge dependence must be tested explicitly, including
the Vilkovisky--DeWitt-style invariant-effective-action issue where relevant.

## Exact success, kills, and stops

- **Maximum grade:** scoped Grade 4 for exact selection, nonselection, or
  non-unification. No new-physics credit without a finite excess prediction.
- **Strongest absorbers:** effective-action and Schwinger--Dyson hierarchies,
  Peierls/covariant response, stochastic gravity, locally covariant QFT,
  process tensors, direct-action reformulation, causal variational systems,
  and ordinary detector/environment selection.
- **Cheapest kill:** every host represents or lawfully propagates supplied
  state/history/interface data while stage, carrier, archive, provenance,
  access, or certification remains externally supplied.
- **Advance gate:** Wave 3 may activate only if one physically serious host
  both selects at least one missing typed duty and exposes an invariant,
  unabsorbed response-order question.
- **Stop:** bank and return to quiescence on full absorption, type mismatch,
  field-redefinition/gauge dependence, supplied-interface dependence, or no
  host satisfying the advance gate.
- **Local-model boundary:** primary-source reconstruction first. Local
  computation may check one exact equivalence or counterexample only when it
  changes the decision. No full simulation, provider, or hardware.
