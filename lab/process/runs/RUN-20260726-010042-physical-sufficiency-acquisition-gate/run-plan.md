# Physical sufficiency acquisition gate

## Objective

Advance the North Star at its current bottleneck: replace synthetic
reconstruction examples with an implementation-complete physical process
packet. First perform the bounded public-sidecar audit already authorized by
the program. If the required trial, calibration, selective-instrument,
provenance, and causal-break joins are absent, stop reuse of the aggregate
packet and build the smallest prospective acquisition contract and executable
finite-shot gate that a real experiment must pass before `HC-DU-036C` may
return a physical factorization, refinement, or candidate remainder verdict.

## Predeclared outcomes

1. `PUBLIC_PACKET_READY`: the audited public source contains all frozen joins
   and can be ingested without reconstructing missing records from aggregates.
2. `PROSPECTIVE_GATE_READY`: the source remains incomplete, and the run
   produces an executable acquisition schema, refusal tests, positive
   schema-only controls, and a finite-shot assay contract.
3. `BLOCKED`: neither a complete packet nor an honest prospective gate can be
   established.

## Evidence boundary

Synthetic fixtures validate the schema and classifier only. They are not
physical evidence and cannot earn a North-Star ontology verdict. A
completion-class-relative finite-shot separation is a candidate physical
remainder only after the process, observer, interventions, resources,
calibrations, invalid trials, route/provenance, and every admitted memory are
implementation-complete and frozen before evaluation.

## Strongest nulls

- Aggregate probabilities without per-trial outcomes must return
  `INCOMPLETE_CONTRACT`.
- An unreset retained quantum or classical memory must block a remainder
  verdict.
- Missing calibration, controller/decoder version, invalid-trial, or
  raw-row-to-selective-map joins must block adjudication.
- A remainder absorbed by charged environment, route, decoder, controller, or
  boundary expansion is a refinement result, not new physics.
- Finite-shot uncertainty must admit an inconclusive region; point estimates
  alone cannot force factorization or separation.

## Decision rule

The swing succeeds only if a future researcher can take raw physical rows,
validate completeness mechanically, reconstruct selective histories with
uncertainty, and hand a frozen record/completion class to `HC-DU-036C` without
silently inventing unavailable data.
