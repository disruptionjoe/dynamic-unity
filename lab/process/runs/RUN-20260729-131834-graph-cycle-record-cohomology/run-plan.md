## Exact theorem targets

Let

\[
d:C^0(V;G)\to C^1(E;G),
\qquad
(da)_{uv}=a_v-a_u
\]

be the graph coboundary.

### Target A — canonical fibre

\[
\ker Q_T=\operatorname{im}d.
\]

Therefore:

- the record fibre is the affine coboundary class
  \(y+\operatorname{im}d\);
- its cardinality is \(|G|^{|V|-1}\);
- the quotient is
  \(C^1/\operatorname{im}d\cong H^1(\Gamma;G)\cong G^\beta\); and
- every spanning tree produces different coordinates for the same record
  equivalence.

### Target B — exact capability factorization

For an integer edge chain \(c\), let \(\partial c\) be its vertex boundary.
The complete response of \(L_c\) factors through \(Q_T\) exactly when

\[
[(\partial c)_v]_G=0
\quad\text{for every }v\in V.
\]

Every ordinary integer cycle satisfies this condition. Every simple open path
from \(u\) to \(v\) has boundary \(v-u\) and fails for nontrivial \(G\).

### Target C — topology-controlled first leak

For an open \(u\)-to-\(v\) path, the minimum number of dressed edges that can
change while preserving every cycle record and changing the path response is

\[
\lambda_\Gamma(u,v),
\]

the minimum \(u\)-\(v\) edge-cut size.

A step potential across a minimum cut attains the bound. Conversely, the
support of any coboundary with \(a_v\ne a_u\) contains a separating cut.

The one-cycle two-link witness from `HC-DU-122` is the specialization
\(\lambda_{C_n}(u,v)=2\). A bridge makes the first leak one link.

### Target D — minimum universal repair

Completing every open- and closed-path response requires distinguishing the
full dressed-edge tuple. Since each cycle-record fibre has
\(|G|^{|V|-1}\) basis completions, at least \(|V|-1\) additional
\(G\)-valued coordinates are necessary. The values on any spanning tree,
together with \(Q_T\), attain the bound.

This is an informational result. Finer tree/open-line access may be
destructive and is not an unchanged QND formation protocol.
