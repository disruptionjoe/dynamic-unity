reconstruction. Defining the target as the complete public behavior and then
recovering it from that same behavior is tautological closure, not a

## The theorem package to prove or kill

1. **Screened operational equivalence.** Same-center states have identical
   public trace laws under \(\mathcal C_0\). Every target defined solely as a
   functional of those trace laws factors, but this is operational closure,
   not source reconstruction.
2. **Accessibility trichotomy.** For a physical target \(t\):
   - if \(t\) factors through the independently formed public record, return
     reconstruction;
   - if \(t\) varies but no admitted action responds to it, return latent and
     not observer-accessible in the frozen class;
   - if one admitted action responds while the record identifies its inputs,
     return a first-leak/incomplete-record witness.
3. **Attribution-rank theorem.** For an abelian source space \(X\), record
   map \(S:X\to Y\), and target \(T:X\to W\), \(T\) factors through \(S\) iff
   \(\ker S\subseteq\ker T\). Full source reconstruction requires injective
   \(S\).
4. **Minimum source witness.** The one-bit total-phase assay
   \(S_1(\tau,\chi)=\tau+\chi\) cannot distinguish
   \((0,1)\) from \((1,0)\). It reconstructs total phase but neither source.
5. **Minimum repair.** Adding
   \(S_2(\tau,\chi)=\tau\) gives a rank-two sensitivity matrix and exactly
   reconstructs both source coordinates. The repair is an added calibrated
   interface/record, not a derivation from the first record.
6. **Target ladder.** Public reachability/order and public trace capability
   factor through the screened process; calibrated scalar record time
   factors only with the `HC-DU-038A` loop-consistent edge calibration;
   proper duration, conformal scale, field phase, and coherent capability do
   not follow from the public process without independent sensitivity.
