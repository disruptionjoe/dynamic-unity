# Operational localization and causal-saturation gate

## Cold-start contract

Dynamic Unity's purpose is to make physical reality intelligible as one
coherent, evidence-accountable whole. Its North Star is to determine whether
independently selected, observer-indexed certified causal records reconstruct
all observer-accessible time, geometry, fields, and capability, or expose a
finite physical remainder.

The repository begins quiescent at revision 53. `HC-DU-093/094` prove that
order reflection and causal saturation are the missing converses in
algebraic-net and process-based causal reconstruction. `HC-DU-095--098` state
the compactness, finite-packet, margin, acquisition, and source-design
obligations. `HC-DU-102` proves that calibrated Weyl displacements expose the
causal symplectic response on fixed source/readout pairs while leaving their
spacetime localization and the finite inverse margin supplied.

This swing attacks exactly that handoff:

> Can physical source/readout provenance identify events without coordinates,
> and does a finite free-field response packet then reconstruct the causal
> order or conformal geometry rather than merely the influences that the
> chosen field happens to realize?

The honest evidence boundary is exact finite-order proof, one physical
Huygens counterexample, primary-source collision, and proportional
deterministic regression. External hardware is unavailable and unnecessary.

Keep independent:

- **identity:** which source, readout, event, and record occurrence is being
  compared;

## Cheapest constructive positive

For a finite event set, assume:

1. **soundness:** a detected edge implies the true causal order,
   \(\prec_{\mathcal A,\gamma}\subseteq\prec\);
2. **causal saturation:** every cover edge of \(\prec\) is detected; and
3. **margin:** every detected response is at least \(\gamma>0\) in magnitude.

Then the transitive closure of the detected graph equals \(\prec\). If every
estimated response has error \(\epsilon<\gamma/2\), thresholding at
\(\gamma/2\) recovers the same graph exactly. This is a conditional finite
reconstruction theorem, not a derivation of saturation or the margin.

## Cheapest exact kills

1. **Huygens kill:** in the \(3+1\)-dimensional massless Minkowski wave
   equation, the causal propagator is supported on the null cone. Choose small
   compact source and readout neighborhoods whose pairwise separations are
   strictly timelike and bounded away from null. Their smeared commutator
   response is zero despite causal precedence.
2. **Sparse-net kill:** if the finite event set contains no sampled null
   intermediary, transitive closure cannot reconstruct the missing timelike
   comparison.
3. **Provenance/locality split:** a device token and authenticated occurrence
   can be identified without coordinates, but proving that its coupling is
   local still uses a supplied or independently derived local net.
4. **Spectral kill:** a relabeling-invariant spectrum discards the eigenvector
   or event-incidence data needed to reconstruct which operational events are
   causally related.
5. **Continuum kill:** exact recovery of one finite sampled poset does not by
   itself establish the dense null relation or topology required for a
   continuum conformal-reconstruction theorem.
