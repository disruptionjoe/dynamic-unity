\[
q=\operatorname{Tr}\sigma(1-P),\qquad
p_\rho=\operatorname{Tr}\rho(1-P).

## Pre-registered theorem spine

### Proposition 1 — forward relative entropy forces uniform spectral tightness

Binary measurement \(\{P,1-P\}\) and data processing should give

\[
D(\rho\Vert\sigma)\ge d(p_\rho\Vert q).
\]

Derive an explicit bound tending to zero uniformly over
\(\mathcal K_{D_0}(\sigma)\) as \(q\downarrow0\). If no such bound follows,
the candidate repair is killed.

### Proposition 2 — canonical finite deterministic approximation

Use the same spectral \(P\) and a reference-selected replacement state in
\(P\mathcal K\) to define a trace-preserving finite-output compression.
Derive a uniform trace-norm error from Proposition 1 and propagate it through
all CPTP downstream processes and bounded effects without selecting an
instrument or outcome.

### Proposition 3 — compactness is state-family control, not a formed record

The forward-relative-entropy sublevel set should be trace-norm compact and
therefore finitely coverable at every nonzero tolerance. Determine whether
the canonical spectral construction gives more than abstract finite
coverability, and type every remaining physical antecedent.

### Proposition 4 — relative-entropy orientation is load-bearing

Test whether the reverse class

\[
\{\rho:\ D(\sigma\Vert\rho)\le D_0\}
\]

is uniformly controlled by the same spectral projections. Construct the
smallest exact escaping sequence if not.

### Proposition 5 — entropy or rank language must not overclaim

Test ordinary entropy bounds, finite entropy, and finite rank as substitutes
for forward-relative-entropy control. A pure state moved arbitrarily far into
the spectral tail is the pre-registered hostile control.

### Proposition 6 — the physical selector remains open

Determine whether AQFT dynamics, modular flow, nuclearity, or the standard
split construction selects \(D_0\), the admitted family, the cutoff,
compression channel, detector, archive, or target. Do not infer selection
from mathematical naturality.
