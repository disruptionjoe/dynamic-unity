\[

\[

four-vector \(c\) of phase/timing controls. The algebraic meeting point solves

\[

This is a front-intersection control. It is not by itself a theorem that a
specified nonlinear wave equation generates a stable, detectable outgoing
singularity.

## Cheapest constructive positive

The fixed matrix has determinant \(-2\), so

\[
t=\frac{c_1+c_2}{2},\quad
x=\frac{c_1-c_2}{2},\quad
y=c_3-t,\quad
z=c_4-t.
\]

Thus every target event \(p_\star\) is reached by the one control vector
\(c=Lp_\star\), with no change to the four covectors.

## Cheapest exact kills

1. **Channel-rank kill.** The first three rows leave
   \((t,x,y,z)=(0,0,0,z)\) in their kernel. Three scalar phases cannot identify
   a generic four-dimensional event.
2. **Finite-codebook kill.** Because \(L\) is bijective, \(M\) exact control
   vectors form at most \(M\) exact event points. A continuum region cannot be
   covered exactly by a finite codebook.
3. **Latency gauge.** If the realized phase is \(c+\lambda\), then any
   alternative event \(p'\) reproduces the same commanded control record by
   taking \(\lambda'=\lambda+L(p'-p)\), whenever both latency vectors remain
   in the admitted physical class.
4. **Geometry-refit kill.** In curved spacetime the phase functions solve the
   metric-dependent eikonal equation. Designing geodesics or beams from the
   held-out metric is not record-first reconstruction.
5. **PDE kill.** Transverse front intersection is not a proof that the chosen
   field equation has the required nonlinear order, nonzero principal symbol,
   detectable amplitude, uniqueness, or absence of caustic/multiple-event
   confounds.
6. **Association kill.** A repeated control packet without retained joint
   source and response identity cannot certify which mixed output came from
   which formed occurrence.
