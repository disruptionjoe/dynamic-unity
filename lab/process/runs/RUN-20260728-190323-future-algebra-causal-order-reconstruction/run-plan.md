# Future-algebra causal-order reconstruction gate

## Purpose and North-Star relation

Dynamic Unity's Purpose is to make physical reality intelligible as one
coherent, evidence-accountable whole. Its North Star asks whether
independently selected observer-indexed certified causal records reconstruct
observer-accessible time, geometry, fields, and capability or expose a finite
physical remainder.

`HC-DU-092` earned a narrower positive antecedent: physical spacetime, field
nets, propagation, and phase can conditionally determine strict shrinking
families of future algebras. This run asks whether the **unlabelled algebraic
family and its inclusion structure**, without reusing its spacetime labels,
retains enough information to reconstruct causal order and hence conditional
conformal geometry.

This is not yet record-first reconstruction. A future algebra, an event, a
retained record, and bounded observer access remain distinct.

## Frozen object

Let \(X\) be an unknown event or region set and let

\[
F:X^{op}\longrightarrow \operatorname{Sub}(\mathcal A)
\]

assign future-accessible algebras with inclusion arrows. The reconstruction
input is the algebraic diagram:

```text
objects: the admitted future algebras
arrows: actual inclusions
optional structure: algebra type, state restrictions, relative commutants,
                    intersections, and commutation relations
```

The input does **not** retain point names, coordinates, metric, dimension,
time parameter, causal relation, or the region labels used to construct the
net. Any of those restored from a hidden label is circular.

Two cases remain typed apart:

1. a full point- or region-indexed future-cone family;
2. a one-parameter time-band co-filtration.

The latter must not inherit the information content of the former merely
because both are called co-filtrations.

## Exact questions

1. Is a contravariant future-algebra assignment automatically an order
   anti-embedding, or does AQFT isotony provide only the forward implication?
2. Which conditions make

   \[
   x\preceq y
   \quad\Longleftrightarrow\quad
   F(y)\subseteq F(x)
   \]

   valid after point labels are removed?
3. Does strict diminution along one supplied history or time parameter
   separate spacelike points, dimension, topology, or conformal geometry?
4. Can equal or inclusion-equivalent algebra diagrams arise from distinct
   causal structures?
5. If causal order is reconstructed, which continuum hypotheses permit the
   conformal metric to follow, and what remains missing for scale?
6. Which part of the result is known order/AQFT/causal-geometry mathematics,
   and which part is the Dynamic Unity typing correction?

Cheapest kill of unconditional causal reconstruction:

- find that physical strict diminution supplies only isotony along an
  antecedently labelled order, while the converse/order-reflection condition
  is absent.

  branching or dimension without additional algebraic invariants.
