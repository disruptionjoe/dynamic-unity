the observer-relative finite action envelope without a supplied subsidiary
theory, substrate/attribute choice, constructor boundary, access route, or
resource/horizon contract.

### Primitive relocation

principles do not select the full repertoire or the observer-relative finite
envelope. A typed adapter and subsidiary physical packet remain necessary.

### Empirical reopener

One published constructor-theory test supplies a frozen prediction that
survives standard quantum/thermodynamic absorbers and changes a DU completion
fibre or held-out target without interface refit.

### Cheapest kills

- Same global task repertoire, different observer-accessible envelopes.
- One finite one-shot action admitted by DU but not a repeatable,
  arbitrarily accurate constructor task.
- An acknowledged open task metric/possibility criterion in the proposed
  ultimate selector.
- A concrete experiment that demonstrates compatibility with ordinary
  unitary quantum theory rather than excess over it.
