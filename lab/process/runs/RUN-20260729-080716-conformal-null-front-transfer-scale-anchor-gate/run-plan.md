# Conformal null-front transfer and scale-anchor gate

## Cold-start contract

Dynamic Unity's purpose is to make physical reality intelligible as one
coherent, evidence-accountable whole. Its North Star is to determine whether
independently selected, observer-indexed certified causal records reconstruct
all observer-accessible time, geometry, fields, and capability, or expose a
finite physical remainder.

The repository begins quiescent at revision 60. `HC-DU-109` proves that one
fixed four-null-front architecture, varied only by four phase controls,
addresses every event in a supplied Minkowski arena. It leaves curved-geometry
transfer and physical nonlinear signal formation open.

The present question is:

> Does that fixed architecture transfer without refit across a nontrivial
> compact metric class, and if it does, what geometric information is
> necessarily invisible to the resulting event packet?

The highest-information class is a positive conformal family

\[
g_\Omega=\Omega^2\eta.
\]

Null hypersurfaces are conformally invariant, so this class gives the fixed
architecture its strongest legitimate chance. It also makes the likely
remainder exact: causal/null data determine conformal structure but do not
automatically determine metric scale.

## Frozen typed specimen

Work on a fixed four-dimensional manifold-with-source/readout region \(V\).
Let

\[
g_\Omega=\Omega^2\eta,
\qquad
0<\Omega_{\min}\le\Omega\le\Omega_{\max},
\qquad
\Omega|_V=1.
\]

The allowed conformal factors form a declared compact \(C^k\) family. Freeze
the four phase functions from `HC-DU-109`:

\[
\phi_i(p)=\ell_i p-c_i,
\]

with rows

\[
(1,1,0,0),\quad(1,-1,0,0),\quad(1,0,1,0),\quad(1,0,0,1).
\]

Freeze the conformal wave operator in four dimensions,

\[
P_g=\square_g-\frac16R_g,
\]

and the quadratic semilinear equation

\[
P_g u+a\,u^2=f,
\qquad
u|_{\text{past}}=0.
\tag{1}
\]

The source \(f\) is supported in \(V\), and the response \(u|_V\) is retained
there. Under

\[
\widetilde g=\Omega^2g,\quad
\widetilde u=\Omega^{-1}u,\quad
\widetilde a=\Omega^{-1}a,\quad
\widetilde f=\Omega^{-3}f,
\tag{2}
\]

the equation is conformally covariant.

This is a controlled PDE specimen, not a claim that equation (1) is a
fundamental physical law. The four-wave artificial-point-source step remains
conditional on the standard transversality, nonzero-symbol, source, and
detectability hypotheses.

## Cheapest constructive positive

For any null covector \(\ell\),

\[
g_\Omega^{-1}(\ell,\ell)
=
\Omega^{-2}\eta^{-1}(\ell,\ell)
=0.
\]

Thus the same four phase hypersurfaces are characteristic for every
\(g_\Omega\). Their joint event still solves \(Lp=c\), so its coordinate
location and the finite phase codebook are unchanged.

## Cheapest exact gauge

In four dimensions,

\[
P_{\Omega^2g}(\Omega^{-1}u)
=
\Omega^{-3}P_gu.
\]

With \(a_\Omega=\Omega^{-1}a\),

\[
P_{\Omega^2g}(\Omega^{-1}u)
+a_\Omega(\Omega^{-1}u)^2
=
\Omega^{-3}(P_gu+a u^2).
\]

When \(\Omega=1\) on the source/readout region \(V\), both the supplied source
and retained response agree there. The complete local source-to-solution map,
not merely one finite packet, is identical for the two metric/coefficient
pairs.

## Cheapest kills

1. **Metric/coefficient gauge.** Choose nontrivial \(\Omega=1\) on \(V\).
   Then \((g,a)\) and \((\Omega^2g,\Omega^{-1}a)\) differ in the interior but
   have the same local source-to-solution map.
2. **Scale-blind event control.** The same phase code reaches the same
   coordinate event across the conformal class precisely because it is
   insensitive to \(\Omega\). It cannot by itself reconstruct the proper scale.
3. **Fixed-coefficient exit.** If \(a\) is held fixed instead of transformed,
   the nonlinear term scales as \(\Omega^{-2}\), not \(\Omega^{-3}\). The
   covariance identity fails by a factor of \(\Omega\).
4. **Insufficiency of gauge breaking.** Failure of the covariance identity
   does not prove that a finite noisy packet is injective on \(\Omega\); it only
   removes this exact equivalence.
5. **Formation conditionality.** Transverse characteristic fronts do not prove
   a nonzero four-wave principal symbol, finite support, detectable return, or
   complete lineage.
6. **Coordinate-identification burden.** The event coordinates are compared on
   one supplied manifold. They are not observer-independent labels selected by
   the records.
