## Pre-registered theorem and counterexample targets

### Target A — endpoint-return/path-functional nonfactorization

For

\[
D(t)=\frac{F}{m\omega^2}(1-\cos\omega t),
\qquad
\tau=\frac{2\pi}{\omega},
\]

the endpoint record

\[
r_{\rm end}=(D(\tau),\dot D(\tau))
\]

is identical for \(F=0\) and \(F\ne0\), while in the pointlike
small-separation CSL limit

\[
\Lambda_{\rm CSL}
=
\lambda\frac{m^2}{4m_0^2r_c^2}
\int_0^\tau D(t)^2\,dt
=
\lambda\frac{3\pi F^2}{4m_0^2r_c^2\omega^5}.
\]

If the derivation holds, \(\Lambda_{\rm CSL}\) does not factor through the
returned pointer endpoint.

### Target B — irreversible loss is not a retained pointer archive

In the source protocol, the pointer's branch-conditioned means and momenta
recombine and its temporary which-branch information is coherently erased.
CSL can nevertheless leave a visibility deficit. This is a countermodel to

\[
\text{irreversible physical loss}
\Rightarrow
\text{retained accessible pointer record}.
\]

It does not prove that no wider ontology carries the stochastic history, and
ordinary environmental decoherence is a positive absorber for the same
logical separation.

### Target C — no-refit attribution rank

For configurations \(i=1,\ldots,n\), write the measured loss as

\[
y_i=-\log(V_i/V_{0,i})
=\lambda K_i(r_c)+(B\theta)_i.
\]

Here \(K(r_c)\) is the frozen CSL response surface and \(B\theta\) is a
declared ordinary-loss nuisance family. At fixed \(r_c\), local identification
of \(\lambda\) requires

\[
K(r_c)\notin\operatorname{col}(B).
\]

Joint local identification of nonzero \((\lambda,r_c)\) requires the two CSL
directions \(K(r_c)\) and \(\lambda\partial_{r_c}K(r_c)\) to add two ranks
beyond \(B\). One visibility datum cannot meet this criterion whenever an
ordinary-loss scalar is admitted.
