Advance the remaining North-Star bottleneck as far as possible without
pretending that a simulator or provider summary is physical evidence:

1. determine which fields a current shot-resolved dynamic-circuit provider can
   actually preserve;

3. build and locally validate the smallest hardware-ready QND-memory,
   held-out-continuation, calibration and causal-break acquisition suite; and

## Evidence boundary

- Local simulator rows are `synthetic_contract_control`, never physical
  evidence.
- Official provider documentation establishes interface availability, not
  successful execution on Joe's account or a laboratory claim.
- A provider-returned shot population is not silently renamed the complete
  physical attempt population.
- No external quantum job is authorized in this run.

## Strongest absorber and falsifier

The strongest absorber is ordinary selection/censoring: two complete attempted
processes may have the same returned-shot distribution and acceptance rate
while differing on unobserved rejected events. The bridge fails if it cannot
make that ambiguity explicit, if register rows cannot be joined shot by shot,
or if a dry-run packet is promoted beyond synthetic control grade.

## Durable output

A versioned provider-capture schema, exact acquisition-visibility
factorization statement, executable Qiskit acquisition driver, deterministic
local regression artifact, and one explicit launch gate for a future
Joe-authorized physical job.
