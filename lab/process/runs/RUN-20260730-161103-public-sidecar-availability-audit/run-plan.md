# Public implementation-sidecar availability audit

## Cold-start contract

- **Purpose:** make physical reality intelligible as one coherent,
  evidence-accountable whole.
- **North Star:** determine which target-blind physical antecedents select
  material, provenance-bearing, observer-indexed record interfaces, then test
  reconstruction and finite remainder.
- **Earned input:** `HC-DU-168--170` recover a returned-shot packet,
  action/resource split, descriptive controller workflow, and
  target/fault-relative implementation-completeness requirement.
- **Current authority:** the flagship is parked with no executable successor.
  This is one bounded public-availability side probe.
- **Owning lanes/channels:** Lanes 1, 3, and 4; `CH-COLLIDE`,
  `CH-EMPIRICAL`, and `CH-FORMAL`.

## Frozen question

> Is the missing exact executable, configuration, all-attempt, actuation, or
> archive-lineage sidecar already public on the primary release surfaces, or
> is further progress genuinely dependent on external custody?

## Frozen public surfaces

1. final Nature Communications article and supplementary PDF;
2. Zenodo concept DOI `10.5281/zenodo.13961129` and concrete record
   `15364358`;
3. official Riverlane and Rigetti public-repository inventories;
4. source scan of the five plausibly relevant Riverlane repositories; and
5. QECi and the open QECIPHY implementation.

The audit may report only absence on these surfaces. It may not infer private
or global absence.

## Exact checks

- inventory every Zenodo member and executable/configuration suffix;
- inspect the final supplement for code links and embedded files;
- search official repository names/descriptions for exact experiment terms;
- source-scan the pinned plausible Riverlane candidates;
- distinguish the historical experiment from later generic QECi/QECIPHY;
- construct one exact same-successor-view/different-historical-target twin.

## Grade, absorbers, kill, and stop

- **Maximum grade:** scoped Grade 4 availability/necessity boundary.
- **Strongest absorbers:** reproducible builds, supply-chain identity, event
  sourcing, database provenance, fault diagnosis, and reproducibility.
- **Cheapest kill:** locate an exact public executable/configuration identity,
  contemporaneous run mapping, all-attempt log, or archive-lineage artifact.
- **Stop:** no author contact, provider, hardware, proprietary inference,
  speculative reconstruction, broad web crawl, or later campaign activation.

## Durable output

- one dated bounded-availability and successor-non-substitution result;
- one compact deterministic regression and JSON artifact;
- one governed receipt; and
- the minimum current-authority, concept, and counter-assumptive updates.
