# Finite-dimensional nonlinear-packet gate

## Cold-start contract

Dynamic Unity's purpose is to make physical reality intelligible as one
coherent, evidence-accountable whole. Its North Star is to determine whether
independently selected, observer-indexed certified causal records reconstruct
all observer-accessible time, geometry, fields, and capability, or expose a
finite physical remainder.

The repository begins quiescent at revision 56. `HC-DU-105` proves that a
finite Boolean packet can isolate joint nonlinear source dependence, but
that interaction-event localization is a separate inverse problem requiring
target-kernel containment and a uniform positive margin.

The unspent obligation is to decide whether the proposed fixed finite packet
is even the correct object for the held-out target:

> Can one target-independent finite nonlinear packet exactly and robustly
> reconstruct a compact Lorentzian model class, and which target dimensions
> make that possible or impossible?

The evidence boundary is exact compact-manifold point/tangent separation,
Borsuk--Ulam and invariance-of-domain obstructions, one response-dimension
resource composition with the `HC-DU-105` Boolean context packet, collision
with standard embedding theory and nonlinear Lorentzian inverse results, and
a proportional exact-arithmetic regression. No PDE simulation or external
hardware is warranted.

Keep independent:

- **source configuration count:** how many distinct source settings are
  executed;
- **response coordinate count:** how many scalar values are retained per
  setting;
- **target dimension:** the dimension of the model/event quotient being
  reconstructed;
- **finite resolution:** target accuracy \(\delta>0\);
- **exact reconstruction:** injectivity at every nonzero target difference;
- **point separation:** different model points differ on some admitted
  response;
- **tangent separation:** every infinitesimal target direction changes some
  admitted response;
- **mathematical no-refit packet:** one finite subfamily chosen for the whole
  class before the held-out member;
- **physical selection:** dynamics or an independent apparatus law chooses
  the class and packet; and
- **compositional geometry:** a growing network of finitely localized events,
  rather than one fixed packet representing an unrestricted continuum field.

## Cheapest constructive positive

On a compact \(C^1\) model manifold, suppose the admitted scalar response
family separates every pair of points and every nonzero tangent vector. The
unit tangent bundle is compact, so finitely many responses provide a
uniformly injective differential. Their combined map is locally embedding.
The remaining nonlocal pair space is compact, so finitely many more responses
separate it. The resulting finite packet is a \(C^1\) embedding and has one
positive global inverse-Lipschitz margin.

This packet is fixed for the whole class before the held-out model. It is
mathematically no-refit. It does not physically select the model class or
responses.

## Cheapest exact kills

1. **Dimension kill:** a continuous injective packet from an open
   \(d\)-parameter target region into \(\mathbb R^N\) requires \(N\ge d\).
2. **Sphere kill:** if an admitted class contains a target-distinct
   \(S^N\), every continuous \(N\)-scalar packet identifies at least one
   antipodal pair by Borsuk--Ulam.
3. **Field-class kill:** an unrestricted regularity ball contains
   target-distinct finite-dimensional spheres of arbitrary dimension, so no
   fixed finite scalar packet exactly reconstructs the whole field or metric
   target.
4. **Tangent kill:** pointwise uniqueness of the full response operator does
   not provide a robust finite packet when a nonzero tangent target direction
   is silent to every admitted scalar response.
5. **Selection kill:** standard embedding existence chooses a mathematical
   packet from a supplied model manifold; it does not show why nature or an
   observer's apparatus selects that manifold and packet.
