## Frozen theorem target

Let \(G=U(1)^2\) act independently on two excitation modes. Freeze:

1. a \(G\)-invariant input state;
2. a candidate \(G\)-covariant channel;
3. the nontrivial relative-character coherence
   \(|10\rangle\langle01|\);
4. a number-conserving exchange Hamiltonian
   \[
   H_\phi
   =
   J\left(
   e^{i\phi}|10\rangle\langle01|
   +e^{-i\phi}|01\rangle\langle10|
   \right);
   \]
5. a diagonal \(U(1)\) global-number symmetry and independent local
   rephasings; and
6. unobserved versus retained interaction-phase provenance.

Prove or kill:

1. a fully \(G\)-covariant channel cannot create a nonzero
   relative-character mode from a \(G\)-invariant input;
2. the exchange interaction creates exact relational coherence from
   \(|10\rangle\langle10|\) while preserving total excitation because it
   reduces \(U(1)^2\) to the diagonal \(U(1)\);
3. local rephasing moves \(\phi\) and the created coherence together, so no
   absolute phase is selected;
4. uniformly forgetting \(\phi\) erases the coherence, while retaining a
   phase carrier or conditioning relation restores it; and
5. generated relational coherence is a physical access resource but is not
   by itself a formed, retained, provenance-bearing certificate.

## Controls and cheapest kill

1. Verify \(G\)-invariance of the input and diagonal-\(U(1)\) conservation of
   the exchange evolution.
2. Verify the relative-character covariance of
   \(|10\rangle\langle01|\).
3. Compare the identity and a fully local-\(G\)-covariant dephasing channel:
   neither may create the character mode.
4. Evolve at zero, quarter-swap, half-swap, and full-swap times.
5. Apply paired local rephasings and confirm coordinate covariance.
6. Average an unrecorded uniform \(\phi\) and require exact loss of the
   off-diagonal mode.
7. Retain \(\phi\) as a conditioning label and require exact recovery.

The **cheapest kill** is a \(G\)-invariant input and genuinely
\(G\)-covariant channel that creates a nonzero relative-character mode, or
failure of the exchange model to preserve total excitation.
