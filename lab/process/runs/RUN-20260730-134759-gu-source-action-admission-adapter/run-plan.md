## Pre-registered propositions

1. **Typed ladder.** A candidate action \(S\) does not define a lawful
   completion class before the complete Euler operator, domain/boundary
   conditions, and nonempty solution class are fixed.
2. **Response gate.** A lawful solution class does not define a source
   response before a background, Hessian/linearization, Green prescription,
   source insertion, and readout map are fixed.
3. **Record gate.** A response operator does not define an operational
   instrument or material record before preparation/state, interventions,
   sampling, formation, retention, provenance, access, and reset are fixed.
4. **Earliest planned activation.** Inside GU's preregistered campaign, RB8
   is the earliest named milestone that could supply the domain/Green/BFV
   portion needed to start an `HC-DU-126/127`-style audit, conditional on the
   prior Euler/stationary gates, explicit source/readout maps, and a proof
   that the response lies in—or validly generalizes—their finite linear
   arena.
5. **No index wait.** A DU source-response audit need not wait for RB10's
   held-out index if the RB8 response packet is independently complete.
   Conversely, an RB10 index does not substitute for the record/interface
   rungs.
