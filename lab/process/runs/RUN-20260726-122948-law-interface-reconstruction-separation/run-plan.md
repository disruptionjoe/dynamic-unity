# Law–interface–reconstruction separation

## Objective

Run one integrated, formal-first swing:

1. determine whether a frozen physical law can naturally select an
   observer/record interface rather than only a physical configuration;
2. test a nonvacuous \(3+1\) lawful geometry fibre against a held-out clock
   target; and
3. search for either a common positive theorem or the smallest counterexample
   showing that interface selection and geometry reconstruction do not unify
   automatically.

## Predeclared contract

- Use a symmetry/stabilizer test before constructing an interface.
- Use the law-filtered completion class before conditioning on records.
- Prove the lawful record fibre is nonempty before evaluating target
  constancy.
- Compare law-only target diameter with record-conditioned target diameter.
- Freeze dimension, source/boundary class, gauge, interface, record map, and
  held-out target before calculation.
- Use a symmetry-breaking positive control.
- Do not build a simulation if direct proof supplies the same insight.

## Frozen \(3+1\) arena

- Minkowski background with compactly supported conformal tangent
  perturbations \(h_{\mu\nu}=2\phi\eta_{\mu\nu}\).
- Trace-free linearized vacuum equation
  \(\delta R_{\mu\nu}^{\mathrm{TF}}=0\).
- Arbitrary finite target-independent linear record functionals.
- One supplied held-out clock functional along a fixed timelike curve.
- Lorentz action on candidate future-unit observer directions.
- A nonzero timelike physical current as the positive control.

## Stop conditions

- Stop if the physical law already makes the target constant before records;
  classify this as law-only closure.
- Stop if the candidate interface has no stabilizer-fixed point; classify it
  as unselected or orbit-only.
- Do not infer a complete record interface from one selected timelike vector.
- Do not claim a causal-fermion-system-specific result when ordinary
  linearized Einstein dynamics absorbs the calculation.
- Do not promote a physical law, ontology, prediction, or paper.

## Result

Completed. The compactly supported conformal vacuum tangent class is trivial
in \(3+1\), so every supplied clock target is fixed by the law before records.
The Lorentz stabilizer of Minkowski has no fixed future-unit timelike vector,
so the same law does not select an observer direction. A timelike current
supplies an equivariant positive control for that one component but not a
pointer, archive, decoder, or access boundary.

The resulting exact program theorem separates lawful realizability,
law-only closure, record-assisted reconstruction, and interface provenance.
The next arena must retain a nonzero lawful target diameter and a physically
selected interface before conditioning on records.
