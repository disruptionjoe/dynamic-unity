## Frozen mathematical arena

Let \(N=(V,E,c)\) be a finite connected simple graph with strictly positive
rational edge conductances \(c_e\). Let the labeled boundary
\(B\subseteq V\) have \(b\geq2\) vertices, and write \(I=V\setminus B\) for
the interior.

For a potential \(u\in\mathbb R^V\), let

\[
S_N(u)=\frac12u^\mathsf TL_Nu,
\]

where \(L_N\) is the weighted graph Laplacian. Fixing a boundary potential
\(x=u|_B\), stationary elimination of \(u|_I\) gives the response matrix

\[
\Lambda_N
=
L_{BB}-L_{BI}L_{II}^{-1}L_{IB}.
\]

It obeys

\[
S_{\mathrm{eff}}(x)
=
\frac12x^\mathsf T\Lambda_Nx,
\qquad
j_B(x)=\Lambda_Nx.
\]

\(\Lambda_N\) is symmetric, has zero row sums, and is positive semidefinite
with constants as its kernel. This is a finite reciprocal classical control,
not direct-action QED.

Ground the last boundary terminal. On

\[
U\cong\mathbb R^{n},
\qquad n=b-1,
\]

the response is represented by a symmetric positive-definite matrix
\(A_N\).
