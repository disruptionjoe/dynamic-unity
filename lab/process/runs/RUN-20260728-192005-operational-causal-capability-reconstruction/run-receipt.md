# Operational causal capability reconstruction gate

## Scientific return

process realizes. It does not identify every influence the ambient physics
would permit.

The smallest exact witness is a constant two-site process whose complete
intervention-response law is identical in:

- an arena where the first site can causally precede the second; and
- an arena where the sites are causally incomparable.

of all realized influences is therefore only a suborder of the physical
causal order. Under causal soundness it reconstructs the order exactly if and
only if the family is **causally saturating**.
