# Quantum output carrier versus classical shadow

## Question

Does the source-pinned gravitational input--output construction select one
physically retained and accessible quantum output record, with homodyne and
number counting merely downstream observer actions, or only a mathematical
dilation whose carrier, retention, access, and classical interface remain
supplied?

## Why this is live

`HC-DU-074` correctly found that homodyne and number counting yield different
classical trajectories for the same unconditional Diósi--Penrose generator.
That proves classical-shadow plurality. It does not by itself prove that the
underlying quantum output carrier is physically nonselected. The distinction
matters because a law may select one quantum process while leaving later
questions and classicalizations to observers.

The active action therefore separates:

```text
reduced system channel
  -> complementary-information equivalence class
  -> physical output carrier and provenance
  -> retention and bounded access
  -> admitted observer measurement
  -> classical shadow
  -> held-out target.
```

- **Owning lane:** Lane 3.
- **Supporting lanes:** Lanes 1, 4, and 7.
- **Channels:** formal proof, source analysis, exact finite control, and
  literature collision.
- **Maximum return:** scoped Grade-4 carrier/shadow separation and

  It validates the type boundary and does not simulate a universe.
- **Hardware:** unavailable, unnecessary, and unauthorized.
- **Cross-repository posture:** Dynamic Unity only.

## Frozen objects

For each candidate, separately type:

1. system channel \(\Phi\);
2. complement \(\Phi^c\) and its mathematical equivalence;
3. physical output carrier \(Q\);
4. carrier provenance and blank input;
5. retention interval;

Two physical outputs count as equivalent only when the equivalence transports
the accessible algebra, retention, and provenance—not merely the abstract
complementary information.

## Pre-registered targets

### T1 — carrier-to-shadow non-implication

Prove that two inequivalent classical shadows of one selected quantum carrier
do not imply carrier nonselection.

### T2 — access-preserving complement criterion

Show that ordinary Stinespring equivalence identifies complementary
information only up to environment isometry. It does not by itself select
where that information is physically retained or which part is accessible.

### T3 — hostile converse

Construct two dilations of one reduced erasure channel whose full complements
are related by a swap but whose fixed accessible output port carries the input
in only one completion. This must distinguish information equivalence from
access-preserving physical equivalence.

### T4 — exact finite positive control

Use one amplitude-damping dilation with a retained environment qubit. Compare
counting-like \(Z\) and homodyne-like \(X\) measurements on the same output
for phase-opposite inputs. Verify:

- one carrier is fixed;
- the \(Z\) shadow loses the phase-sign target;
- the \(X\) shadow retains it; and
- the full carrier supplies the same optimal discrimination as \(X\) for the
  predeclared sign target.

The finite fixture is a conditional positive control because its physical
retention and access are explicitly supplied.

### T5 — unchanged source application

Read Gough and Rees's source literally. Decide whether its Hudson--Parthasarathy
output field is:

- a physically selected retained record;
- a selected mathematical output process only;
- an abstract complementary-information class; or
- an interface still missing physical formation, retention, and access.

Do not require the law to choose which later observable an observer asks.
