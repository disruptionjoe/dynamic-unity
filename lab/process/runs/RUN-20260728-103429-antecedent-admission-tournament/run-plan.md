# Antecedent admission tournament

## Exact question

Does any physical result newly available to Dynamic Unity supply an
antecedent that changes the already banked interface-selection boundary and
is ready to carry one independently escrowed target into Swing 2?

This run executes Swing 1 only of
[`N10-CCR-SELECTED-RECORD-TO-NORTH-STAR`](../../../explorations/next-ten-swing-selected-record-to-north-star-campaign-scaffold-2026-07-28.md).
It cannot execute or pre-decide Swing 2.

## Frozen admission gate

A candidate is admitted only if it supplies all six:

1. a new physical antecedent or exact theorem not already consumed by
   `HC-DU-033F`, `HC-DU-033H`, `HC-DU-061`, `HC-DU-068`, or `HC-DU-073`;
2. a candidate-interface family and its physical automorphism or gauge group;
3. a plausible bounded local realization;
4. a held-out target escrowed before interface performance is inspected;
5. a finite theorem, counterexample, or source audit that decides the next
   gate without hardware; and
6. an exact cheapest kill.

Failing any hard gate prevents scoring. Familiar vocabulary, a newly dated
paper, or a new representation of an old generator is not a new antecedent.

## Candidate classes frozen before the result

1. newest source-owned GU Formalization and Time as Finality results that
   could change a DU reopener;
2. autonomous nonequilibrium quantum detectors;
3. objective-event or gravitational quantum-filtering dynamics;
4. finite-time infrared and localized-QFT realizability results;
5. topological, metastable, or autonomous memory mechanisms; and
6. any genuinely new candidate exposed by the source audit.

The last three classes may re-enter only if a named prior stop changed. This
is not permission to repeat their completed DU audits.

## Four bounded arms

### Reopener audit

Compare each source result with the exact live stop and reopener in
`CURRENT-RESEARCH.yaml`. A source-owned review result, a nonphysical
naturality result, or a construction already inside a prior audited class
does not pass.

### Primary-source reconstruction

For the strongest current physical candidates, reconstruct:

```text
physical antecedent
  -> selected dynamical structure
  -> candidate output/interface family
  -> supplied detector, monitoring, access, and archive structure
```

Use the primary paper rather than abstracts or commentary.

### Counterfactual kill

Hold the antecedent dynamics fixed and search for two operationally
inequivalent record interfaces. For open-system dynamics the minimum control
is two different unravellings of one unconditional generator. For autonomous
detectors it is two detector/write/readout designs compatible with the same
general mechanism class.

### Value-of-information chair

Admit at most one candidate, and only after the hard gate. Rank admitted
candidates by North-Star dependency removed, local decidability, scientific
ceiling, and cheapest-kill quality. If none passes, return the clean null.

## Escrow and controls

For any candidate reaching scoring, escrow a future-response target that is
not used to choose the interface. The minimum hostile control is a
same-antecedent/different-interface pair. The positive control is a source
where an interface is explicitly included in the physical antecedent; that
must be classified as conditional construction, not endogenous selection.

## Evidence and grade boundary

- **Owning lane:** Lane 3.
- **Supporting lanes:** Lanes 1, 2, 4, and 7.
- **Channels:** literature collision, formal proof, and synthesis.
- **Maximum return:** Grade-4 reopener/admission disposition.
- **Strongest absorbers:** `HC-DU-033F`, `HC-DU-033H`, `HC-DU-054`,
  `HC-DU-061`, `HC-DU-063`, `HC-DU-068`, `HC-DU-073`; quantum-trajectory
  unravelling freedom; decoherence/Quantum Darwinism; standard detector
  thermodynamics; and ordinary source/interface engineering.
- **Cheapest kill:** every newly checked source still supplies the
  instrument, unravelling, detector, access boundary, archive, target, or a
  prior closed mechanism class.
- **Retreat:** return `NO_READY_SCIENTIFIC_SUCCESSOR`; do not invent a host or
  activate Swing 2.
- **Local computation:** none unless an exact counterexample needs it. A
  source-pinned analytical counterexample is preferred.
- **External hardware:** prohibited and irrelevant.

## Allowed returns

```text
ANTECEDENT_CANDIDATE_ADMITTED
NO_READY_SCIENTIFIC_SUCCESSOR
```

An admission requires a complete passport. A no-ready result must identify
the smallest new premise that would change the decision.
