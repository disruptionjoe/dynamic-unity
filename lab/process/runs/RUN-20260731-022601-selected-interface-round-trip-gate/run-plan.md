## Typed chain and gates

```text
source-owned action and stationary gauge/BV class
-> target-blind selected flag or exact no-selection result
-> selected physical instrument
-> formed and retained record law
-> law-level target decoder
-> event-level certificate or declared finite error
-> no-refit transfer / GU-DU round-trip verdict.
```

The swing will distinguish:

1. **conditional interface reconstruction:** each named interface admits its
   own decoder;
2. **interface-independent reconstruction:** one untagged decoder works
   across all admissible interfaces;
3. **selected-interface reconstruction:** physics supplies a target-blind
   selector and the selected record-law map identifies the target;
4. **event-level certification:** one realized record identifies the target
   with zero error; and
5. **finite reliability:** overlapping laws support only bounded-error
   inference.

## Pre-registered theorem, kills, and repairs

- **Law-level factorization:** for selected record-law map \(K_s\) and target
  \(T\), an exact decoder exists on the image iff
  \(\ker K_s\subseteq\ker T\).
- **Cross-interface obstruction:** named-interface decoders do not imply one
  untagged decoder. The latter requires
  \(K_i(m)=K_j(m')\Rightarrow T(m)=T(m')\) across every admitted interface
  pair.
- **Event-level boundary:** a deterministic event decoder is exact iff
  record supports belonging to different target classes are disjoint.
- **Downstream boundary:** a common stochastic readout cannot repair an
  equality of upstream record laws and cannot increase total variation.
- **Cheapest GU kill:** the flag, apparatus, archive, interface tag, or
  decoder is independently chosen rather than selected by the source-owned
  action and physical interaction.
- **Repair types:** a target-blind physical selector; a physically retained
  interface/provenance tag; completion-class narrowing; or an explicit
  bounded-error decision contract. These are not interchangeable.
