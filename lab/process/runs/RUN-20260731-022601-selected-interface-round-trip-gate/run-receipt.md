## What was learned

The proposed GU-to-record-to-DU loop has three independent central gates:

1. physics selects the operative interface, or the target provably descends
   across every admitted interface;
2. the selected or interface-independent record law identifies the target;
   and
3. one realized record certifies the target, or a finite error contract is
   declared.

For selected record-law map \(K_s\) and target \(T\), the law-level round trip
exists exactly when

\[
\ker K_s\subseteq\ker T.
\]

For an unselected family \(\{K_i\}\), one decoder not receiving the interface
tag exists exactly when

\[
K_i(m)=K_j(m')
\quad\Longrightarrow\quad
T(m)=T(m')
\]

for every admitted interface pair and completion pair. The exact
direct-versus-flipped fixture shows that every named interface may be
individually invertible while the untagged family is ambiguous. Retaining
the interface tag repairs the fixture by enlarging the record packet.

A target-blind physical selector does not ensure reconstruction: it may
select an uninformative record law. Conversely, unique interface selection is
not logically required if the target descends across the whole family.

Law-level identification also does not imply a one-event certificate.
Distinct overlapping laws admit a decoder from the complete law while
forbidding a zero-error decoder from one outcome. Exact event certification
requires disjoint supports across target classes.
