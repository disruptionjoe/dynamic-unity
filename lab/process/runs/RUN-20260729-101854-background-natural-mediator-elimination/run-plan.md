# Background-natural mediator elimination gate

## Cold-start contract

Dynamic Unity asks whether independently selected, observer-indexed certified
causal records reconstruct all observer-accessible time, geometry, fields, and
capability, or expose a finite physical remainder. `HC-DU-115` established a
strictly query-relative fork: exact elimination of an invertible quadratic
mediator preserves the complete on-shell source action while leaving mediator
dimension, factorization, local mediator algebra, and candidate event
partition unidentified.

That result froze the background. The next untested question is whether the
equivalence is **natural under background variation**. A gravitational or
geometric query does not ask only for the action at one background; it asks
how the action changes when the metric or another physical background is
varied. A term independent of the source can therefore remain invisible to
the source query while contributing to background response.

The evidence boundary remains methodological physical realism with ontology
open. A generic parameter derivative becomes a stress-energy claim only when
the parameter is a metric component and the action, boundary terms, measure,
state, and variation convention are fixed.

## Frozen finite control

Let

\[
S(j,\phi;\lambda)
=
\frac12 A(\lambda)j^2
+B(\lambda)j\phi
+\frac12K(\lambda)\phi^2,
\qquad K(\lambda)\ne0.
\]

The stationary mediator and effective action are

\[
\phi_*(j,\lambda)=-\frac{B(\lambda)}{K(\lambda)}j,
\qquad
S_{\rm eff}(j;\lambda)
=
\frac12
\left(A(\lambda)-\frac{B(\lambda)^2}{K(\lambda)}\right)j^2.
\]

The finite control distinguishes four contracts:

1. equality of source actions at one \(\lambda_0\);
2. equality of the first background derivative at \(\lambda_0\);
3. equality of the complete source kernel on a neighborhood; and
4. equality of the complete quantum effective action, including
   source-independent determinant, measure, state, and boundary terms.

The first three are represented exactly over rational numbers. The logarithm
itself is not numerically approximated: only the exact derivative identity

\[
\frac{d}{d\lambda}\log\det K
=
\operatorname{tr}(K^{-1}K')
\]

is used.

## Exact questions

1. Does stationary elimination preserve total background response when all
   explicit background dependence is retained?
2. Can two completions agree on the complete source action at one background
   while disagreeing on its first background derivative?
3. If the complete effective source kernel agrees on a neighborhood, can a
   source-only background query still distinguish the completions?
4. Can different mediator factorizations assign different local or
   channel-specific response while preserving the same total response?
5. Can the Gaussian determinant, source-independent at fixed background,
   contribute to a held-out background or metric response?
6. What additional structure must be preserved before calling field and
   direct-action branches gravitationally equivalent?
7. Does any result select a physical metric, record, observer boundary,
   ontology, or empirical discriminator?
