# Robust reconstruction, vertical slice, and dynamics restriction

## Objective

Run three coupled knowledge-gaining stages with one typed reconstruction
contract:

1. separate stochastic record realizability from held-out target sufficiency;
2. trace one physical process all the way from selective record formation to
   a held-out observer action; and
3. determine which independently frozen kinds of dynamics actually remove
   the conformal record nullspace.

The later stages must report the two quantities defined in the first stage.
A weak or ill-typed result does not create momentum for the next.

## Stage 1 — robust realizability/sufficiency decomposition

For compact admissible model class \(M\), metric record space \(Q\), metric
target space \(Y\), record map \(r\), target map \(t\), observed stochastic
record \(q\), record tolerance \(\epsilon\), and target tolerance \(\tau\),
define

\[
\eta(q)=\inf_{m\in M}d_Q(r(m),q),
\qquad
F_{q,\epsilon}=\{m:d_Q(r(m),q)\le\epsilon\},
\]

and, when the feasible fibre is nonempty,

\[
\Delta(q,\epsilon)
=
\sup_{m,n\in F_{q,\epsilon}}d_Y(t(m),t(n)).
\]

Return:

- `ROBUSTLY_UNREALIZABLE` when \(\eta>\epsilon\);
- `ROBUST_RECONSTRUCTION` when \(\eta\le\epsilon\) and
  \(\Delta\le\tau\); or
- `ROBUST_UNDERDETERMINATION` when \(\eta\le\epsilon\) and
  \(\Delta>\tau\), with a feasible same-record/different-target witness.

Use total variation for stochastic record distributions and maximum
total variation over the declared held-out intervention family. Mixture
closure is admitted only when explicitly included in \(M\).

Prove:

1. the branches are exclusive and exhaustive under compactness/continuity;
2. the exact zero-tolerance limit recovers `HC-DU-039A`;
3. record-model misfit \(\eta\) and target spread \(\Delta\) are independent
   coordinates rather than one deficiency;
4. under an \(L\)-Lipschitz same-class record projection
   \(r_1=\pi\circ r_2\), \(q_1=\pi(q_2)\),
   \(F^{(2)}_{q_2,\epsilon}\subseteq
   F^{(1)}_{q_1,L\epsilon}\), so a refinement can reduce target spread but
   cannot repair a robustly empty projected fibre; and
5. contract/identity retyping remains distinct from refinement.

- QND record:
  \(K_r^{Q}=|r\rangle\langle r|\);

selective continuations. Carry the chain:


archive, finality, or access already distinguishes the pair, report the
earliest distinction and stop the proposed counterexample.

\[

\[

gravity or evidence that nature selects this completion class.
