## Frozen decision contract

A candidate survives only if it:

1. states an exact proposition not already banked;
2. changes a North-Star dependency rather than only improving vocabulary;
3. can return its first decision-changing result locally before hardware;
4. consumes existing evidence without another broad literature sweep;
5. names its strongest standard-theory absorber and exact cheapest kill;
6. preserves target, source, interface, access, and resource typing; and
7. yields useful information under both its positive and negative returns.

No score can rescue a candidate that fails one of these gates.
