# Exact question

Can records, capabilities, classical composability, regional finality, and
geometry be expressed as target-independent typed views of one closed
transition object, and does that formulation add any axiom beyond a complete
process plus supplied interfaces?

# Conditional posit

For the finite control only, use a four-degree carrier. Do not identify those
degrees with spacetime coordinates, Hilbert-space dimension, latent variables,
or GU data. Treat the metric, connection, view maps, action family, observer
boundary, and scale as separately typed until an antecedent selects them.

1. Define one minimal indexed operational transition package.
2. Type each proposed perspective as a quotient, dual query family,
   congruence, closure, or reconstruction target.
3. Prove the joint-kernel reconstruction criterion without presenting it as
   new mathematics.

5. Include an undercomplete view family as a positive falsifier.
6. Audit a general four-dimensional symmetric metric: four axial rulers versus
   the ten independent pointwise metric responses.
7. Decide which additional axiom, if any, remains after standard absorption.
