## Exact theorem targets

Let

\[
r:H^1(\Gamma;G)\to H^1(A;G)\oplus H^1(B;G)
\]

be restriction.

### Target A — gluing deficit

For connected \(A,B\) and \(k\) overlap components,

\[
\ker r\cong
H^0(I;G)/\Delta G
\cong
G^{k-1}.
\]

Therefore every compatible pair of local cycle records has exactly
\(|G|^{k-1}\) global cycle-record completions.

Consequences:

- if \(I\) is connected, the global cycle record is unique;
- if \(I\) is disconnected, local completeness does not imply global
  completeness; and
- the deficit depends on overlap connectivity, not merely overlap size.

### Target B — minimum cross certificates

Choose one overlap component as base. For every other component, join it to
the base by one path in \(A\) and return by one path in \(B\). The resulting
\(k-1\) cross-region cycles provide \(G\)-valued holonomies.

The local records plus those cross-cycle values determine the global cycle
class. Under a \(G\)-valued-coordinate contract, \(k-1\) is also necessary by
the completion count.

### Target C — layered physical fibre

`HC-DU-123` leaves \(|G|^{|V|-1}\) physical dressed-edge configurations
inside every global cycle class. Hence a compatible local-record fibre has

\[
|G|^{k-1}\,|G|^{|V|-1}
=
|G|^{|V|+k-2}
\]

physical basis completions.

The layers are:

```text
local cycle records
  + (k-1) cross-region cycle certificates
    = global cycle record
  + (|V|-1) finer tree/open-path coordinates
    = complete dressed-edge basis state.
```

Thus successful regional gluing does not imply complete physical
reconstruction.

### Target D — rank identity

Writing \(\beta_1(X)\) for graph cycle rank,

\[
\beta_1(\Gamma)
=
\beta_1(A)+\beta_1(B)-\beta_1(I)+(k-1).
\]

The final term is exactly the cross-region cycle rank absent from the two
local records after overlap compatibility is enforced.

## Cheapest kills

1. A connected-overlap cover has two global cycle classes with the same
   compatible local records.
2. A \(k\)-component overlap yields a global completion fibre whose size is
   not \(|G|^{k-1}\).
3. The cycle-rank identity fails.
4. Fewer than \(k-1\) \(G\)-valued cross-cycle coordinates distinguish all
   global completions.
5. The explicit cross cycles fail to reconstruct the global cycle record.
6. The full physical local-record fibre does not have
   \(|G|^{|V|+k-2}\) basis states.
7. Regional gluing silently imports a cross-region transcript, target, or
   global decoder.
