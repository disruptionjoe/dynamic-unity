# Objective-collapse event to certified-record campaign

## Question

What is the highest-information next series after `HC-DU-079`, and how should
it be gated so that Dynamic Unity does not keep varying representations or
record hosts after their decisive dependencies are already known?

## Scope

- **Owning repository:** Dynamic Unity.
- **Primary lanes:** Lanes 1 and 3.
- **Supporting lanes:** Lanes 2, 4, and 7.
- **Channels:** synthesis, literature collision, formal proof, executable
  counterexamples only when decision-changing, and empirical discrimination.
- **Artifact type:** priority tournament and non-authoritative five-swing
  campaign scaffold.
- **Claim change:** none.
- **Prediction change:** none.
- **Publication change:** none.
- **Hardware:** unavailable and not authorized.

## Required inputs

1. current quiescent routing in `CURRENT-RESEARCH.yaml`;
2. `HC-DU-075..079`, especially the physical-carrier, subsystem-factor,
   modular, self-testing, and indivisible-stochastic boundaries;
3. the completed physical-host, infrared-memory, lawful-\(3+1\), and
   branch-invariance campaigns;
4. the latest Time as Finality objective-collapse/rival conclusion as
   cross-repository source input only;
5. primary sources for rGRWf, interacting rGRWf, relativistic matter density,
   primitive ontology, and finite collapse-model bounds; and
6. Dynamic Unity's target-escrow, no-refit, access, provenance,
   complete-process, local-model, and hardware controls.

## Method

1. Compare every currently credible whole-repository trunk by:
   - changed dependency;
   - expected knowledge gain;
   - maximum ceiling;
   - local readiness;
   - strongest absorber;
   - cheapest kill; and
   - risk of repeating a closed class.
2. Prefer a candidate that changes a physical antecedent over another
   representation of a fixed antecedent.
3. Keep collapse law, primitive ontology, occurrence, retained record,
   access, certification, and target reconstruction separately typed.
4. Prepare five conditional positions, with only Position 1 eligible for a
   later explicit authorization.
5. Update current routing only enough to record the top prepared candidate;
   do not select or activate a scientific successor.

## Required output

- one priority tournament;
- one five-position gated campaign scaffold;
- exact activation, return, stop, and retreat rules;
- one current-authority note preserving quiescence;
- one run receipt;
- validation, explicit-path commit, push, and governed-session completion.

## Stop

Stop after preparation. Do not:

- execute the objective-collapse audit;
- simulate collapse trajectories;
- promote flashes or matter density to records;
- claim that the collapse law derives its primitive ontology;
- activate Swings 2–5;
- change a claim, prediction, or paper;
- request external hardware; or
- infer a new physical law.
