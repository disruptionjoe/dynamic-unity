# Frozen physical packet

Use a symmetric two-path superconducting fluxon circuit. For island charge
`q` in electron-charge units, the paths acquire relative Aharonov--Casher sign
`(-1)^q`. With path amplitudes `a,b`, the single-phase-slip amplitude is

```text
A_sps(q) = a + (-1)^q b.
```

Double slips remain admitted. At `a=b`, odd charge cancels single slips and
preserves fluxoid parity; even charge admits single slips and connects the
winding sectors. The held-out objects are:

1. exact island charge;
2. charge parity;
3. the fluxoid transition graph and its connected components;
4. one realized post-interaction fluxoid endpoint; and
5. a signed winding branch.

# Exact tests

1. Symmetric two-path interference makes the single-slip rate zero for odd
   charge and nonzero for even charge.
2. Charge parity, but not full charge, factors through that rate.
3. With single and double slips, the fluxoid transition graph is connected;
   with only double slips, it splits into exactly two parity components.
4. Charge parity therefore selects the transition-graph topology and whether
   fluxoid parity is protected.
5. One realized endpoint does not reconstruct charge parity because the two
   endpoint laws overlap; a parity-changing endpoint supplies only a one-sided
   certificate.
6. Removing the second coherent path erases charge sensitivity.
7. Path asymmetry removes exact single-slip cancellation and the two-component
   protection, even though rate modulation survives.
8. Time-reversal covariance forbids a deterministic map from a time-even
   charge-only source into a nonzero signed winding branch without a time-odd
   orientation/bias.
9. A declared time-odd orientation makes such a response map possible but
   exposes the extra supplied datum rather than hiding it.
