## Cheapest exact proof

Integrating

\[
\mu\frac{dg}{d\mu}=-b_0g^3
\]

gives

\[
\frac1{g^2(\mu)}
=
2b_0\log\frac{\mu}{\Lambda},
\qquad
\Lambda
=
\mu\exp\!\left[-\frac1{2b_0g^2(\mu)}\right].
\]

Every \(\Lambda>0\) gives a solution. The beta function determines the shape
of the flow, not the origin of \(\log\mu\). Specifying \(g\) at one reference
scale and specifying \(\Lambda\) carry the same one-parameter information.

## Cheapest constructive positive

For fixed known \(M_*>0\),

\[
q_*=e^{-M_*\tau_g}
\]

reconstructs

\[
\tau_g=-\frac{\log q_*}{M_*}.
\]

A local metric rescaling changes this mark when the matter scale is held
fixed. If both \(g\mapsto c^2g\) and \(M_*\mapsto M_*/c\), the mark is
unchanged. The latter is the declared common-unit quotient, not a
same-units physical metric rival.
