# Exact question

What is the strongest candidate law each of twenty computational and twenty
mathematical/physical lenses can formulate for physically selected common-view
closure, and which candidates survive ordinary, quadratic, and
disciplinary-distance aggregation?

# Method

1. Give each lens one and only one owned Grade-0 hypothesis.
2. Require a precise statement, decisive test, and strongest absorber.
3. Freeze one declared utility rubric before aggregation.
4. Cast separate 100-credit linear and 100-credit quadratic ballots; forbid
   self-votes.
5. Measure support breadth on a declared nine-community graph.
6. Compare rankings rather than treating either aggregation as truth.
7. Translate the stable convergence into an attempt order for `CTS-A2` without
   claiming the selector has been found.

# Maximum grade and stop

Maximum Grade 0. Persona output and voting are prioritization signals only.
Stop before physical claim promotion, novelty claims, automatic winner
selection, local simulation, hardware, or successor activation.

# Durable output

- one dated forty-hypothesis assessment;
- one deterministic ballot/audit probe;
- one complete machine-readable artifact;
- one bounded refinement of the active `CTS-A2` attempt order; and
- no claim or prediction promotion.
