Dynamic Unity's purpose is to make physical reality intelligible as one
coherent, evidence-accountable whole. Its North Star is to determine whether
independently selected, observer-indexed certified causal records reconstruct
all observer-accessible time, geometry, fields, and capability, or expose a
finite physical remainder.

finite family of direct massive point-response tails cannot retain one
positive margin over unbounded timelike depth. It leaves nonlinear wave

The unspent obligation is to reduce the ideal continuum

already a formed physical record:

> Can a finite, target-independent nonlinear source packet isolate and
> localize interaction events with a uniform margin, or does the reduction
> retain supplied counterfactual contexts and geometry-coded probes?

regression. No spacetime simulation or external hardware is warranted.

Keep independent:

- **source provenance:** a response depends jointly on all declared source
  channels;
- **event provenance:** which spacetime interaction occurrence produced the
  response;
- **formed occurrence:** one physical interaction happened and left a
  retained trace;

  across repeatable trials;

  estimated to declared precision;

  the declared target or gauge;
- **proof-designed probe:** a source or beam chosen using the unknown target
  in an existence proof; and
- **target-independent instrument:** sources and readouts fixed without
  consulting the held-out geometry.

## Cheapest constructive positive

For a response polynomial of total degree at most \(k\), the alternating sum
over all \(2^k\) Boolean source contexts divided by \(\eta^k\) exactly returns
the coefficient of
\(\epsilon_1\cdots\epsilon_k\). For an analytic response with a declared
coefficient majorant, the higher-order contamination has an explicit
geometric tail.

This is a finite joint-source-provenance certificate. If the finite
localization matrix also satisfies

\[
\ker B\subseteq\ker L,
\]

then the held-out target \(Lc\) is exactly determined; full site recovery is
the special case \(\ker B=\{0\}\). A uniform positive quotient singular value
gives robust recovery.

## Cheapest exact kills

1. **Omitted-context kill:** among arbitrary multiaffine Boolean response
   tables, omit any one vertex \(v\). The Boolean delta at \(v\) agrees with
   zero on every queried context but changes the top Möbius coefficient.
2. **Noise kill:** if each context value has norm error at most \(\varepsilon\),
   worst-case error after division is
   \(2^k\varepsilon/\eta^k\).
3. **Localization kill:** if \(\ker B\not\subseteq\ker L\), two admissible
   site distributions have the same packet but different targets.
4. **Formation kill:** a mixed derivative or finite difference compares
   several counterfactual source contexts; it is not evidence that one
   interaction occurrence left one retained record.
5. **No-refit kill:** a Gaussian beam aimed using the held-out intersection
   or geometry cannot be counted as target-independent record-first
   reconstruction.
