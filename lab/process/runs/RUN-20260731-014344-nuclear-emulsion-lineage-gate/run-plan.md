# Nuclear-emulsion material-trace lineage gate

## Cold-start contract

- **Purpose:** make physical reality intelligible as one coherent,
  evidence-accountable whole.
- **North Star:** determine what target-blind physical antecedents, if any,
  select material, provenance-bearing, observer-indexed record interfaces;
  then test reconstruction, operational duality, and finite remainder.
- **Starting state:** explicit no-ready quiescence after `HC-DU-178`.
- **Bounded role:** test the first exact reopener from `HC-DU-178` with one
  source-pinned material track detector. This is not another broad detector
  survey and not an activated successor.
- **Owning lane/channels:** Lane 3 with Lanes 1, 4, and 7 support;
  `CH-EMPIRICAL`, `CH-FORMAL`, `CH-MODEL`, and `CH-COLLIDE`.

## Frozen question

> Does a nuclear emulsion physically retain causal provenance—one particle's
> path and direction—or does it retain only a spatial field of altered grains
> from which track edges, orientation, and source identity are reconstructed?

## Typed chain

Keep separately typed:

```text
upstream particle histories
-> local ionization/deposition events
-> latent altered-grain field
-> developed silver-grain point cloud
-> tomographic images
-> reconstructed adjacency graph/path cover
-> particle/source classification.
```

## Pre-registered positive, kill, and repair

- **Positive:** the emulsion material itself forms and retains a spatial
  deposition trace before electronic readout.
- **Cheapest lineage kill:** one retained grain set admits at least two
  admissible path covers or opposite temporal orientations.
- **Exact repair:** add a physically retained edge/order tag, or freeze a
  physical admissibility class in which the grain graph has a unique path
  cover.
- **Source-certificate kill:** distinct source classes have overlapping
  material/readout laws or require an externally supplied incident direction,
  calibration, or event-time prior.
- **Advance gate:** no later campaign wave activates without an invariant,
  unabsorbed response-order question and finite held-out consequence.

## Grade, absorbers, and local boundary

- **Maximum grade:** scoped Grade 4 for exact lineage factorization,
  nonselection, or conditional reconstruction; Grade 2 for source
  reconstruction.
- **Strongest absorbers:** nuclear-emulsion physics, latent-image chemistry,
  particle tracking, multi-target data association, path-cover
  nonuniqueness, sufficient statistics, and Bayesian source classification.
- **Local computation:** one exact finite path-cover counterexample and repair
  are allowed. No detector simulation, provider, or hardware.
