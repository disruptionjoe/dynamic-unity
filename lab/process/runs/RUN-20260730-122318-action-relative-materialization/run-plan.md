## Frozen action and response class


For a complete physical history \(h\), define

\[
\sigma_H(h)
=
\mathbb P(z_2\in\cdot\mid \operatorname{do}(H_{\rm QND}),h).
\]

Do not add alternate bases, feedback pulses, raw second traces, preparation
changes, or controller commands. Any such operation is an action-class
extension, not an admitted action.

## Frozen quotient and realization question

Define

\[
h\sim_H h'
\quad\Longleftrightarrow\quad
\sigma_H(h)=\sigma_H(h').
\]

The physical behavioral quotient is \(Q_H=\Omega/{\sim_H}\).

A candidate archive \(r\) is:

- **response-sufficient** when
  \(\ker r\subseteq\ker\sigma_H\);
- an **exact realization** when
  \(\ker r=\ker\sigma_H\);
- **overfine** when its kernel is a strict subset;
- **lossy/coarse** when it merges at least one response-distinct pair; and
- **incomparable** when each relation distinguishes something the other
  merges.

The source must earn the relation. Do not infer it from the existence of a
trace, classification fidelity, or one aggregate QND number.

## Pre-registered theorem and controls

1. Prove existence and uniqueness, up to relabeling, of \(Q_H\) at the frozen
   scope.
2. Prove the factorization/minimality criterion for any record map.
3. Separate the physical-history signature
   \(\sigma_H(h)\) from the observed conditional response
   \(\bar\sigma_H(r)=\mathbb P(z_2\in\cdot\mid r)\).
4. Test the identity

   \[
   \bar\sigma_H(r)
   =
   \mathbb E[\sigma_H(H)\mid r]
   \]

   and the zero-conditional-heterogeneity criterion for physical
   sufficiency.
5. Construct exact source-report twins with identical candidate-record
   marginals and \(95\%\) aggregate repeat agreement but different
   physical-history quotients.
6. Classify \(r_V,r_\beta,r_z,r_L\) only where the source and controls earn
   the relation.
7. Add one explicitly excluded action in the finite control to verify that
   action-class enlargement can refine the quotient.
