## Objective

Use one unchanged typed contract to classify:

1. the frozen multi-time recorded-process versus endpoint-rival specimen;
2. the frozen conformal-geometry reconstruction and hidden-mode specimen; and
3. layered regional finality as an adversarial case in which locally valid
   records may possess no admitted global completion.

Return either one common theorem or the smallest exact counterexample showing
which additional type is required for a valid unification.

## Predeclared typed contract

For an admissible completion class \(M\), record map \(r:M\to Q\), target map
\(t:M\to Y\), and declared record value \(q\in Q\), define the completion
fibre

\[
F_q=\{m\in M:r(m)=q\}.
\]

Test realizability before target constancy:

1. `UNREALIZABLE_RECORD` when \(F_q=\varnothing\);
2. `RECONSTRUCTS_TARGET` when \(F_q\ne\varnothing\) and \(t\) is constant on
   \(F_q\); or
3. `UNDERDETERMINED_TARGET` when \(F_q\ne\varnothing\) and two completions in
   \(F_q\) have different target values.

An unfrozen completion, record, target, identity, or refinement contract
returns `INCOMPLETE_CONTRACT` before scientific classification.

## Theorem and counterexample targets

1. Prove the three-way fibre classifier is mutually exclusive and exhaustive.
2. Prove target reconstruction over all realized records is equivalent to
   \(\ker r\subseteq\ker t\), hence to factorization of \(t\) through
   \(\operatorname{im}r\).
3. Prove an ordinary refinement \(r_2\), with
   \(r_1=\pi\circ r_2\) on the same completion class, can split a nonempty
   fibre but cannot make an empty coarse fibre nonempty.
4. Search the binary pair-context class for the smallest locally normalized,
   overlap-consistent regional record with no global completion. Require
   every proper context subfamily to have a completion.
5. Determine whether provenance/context splitting is an ordinary refinement
   or a change to the completion/identity type.
