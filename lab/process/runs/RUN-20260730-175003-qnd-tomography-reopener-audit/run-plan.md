## Pre-registered formal tests

1. Reconstruct the source's exact intervention family and the operational
   object it identifies.
2. Audit the pinned public archive for joined outcomes, shot order, raw/IQ
   traces, rejected attempts, controller lineage, and reset semantics.
3. Prove the operational **label-sufficiency criterion**: for an
   outcome-conditioned finite-dimensional instrument map
   \(\mathcal E_n\), the outcome label alone fixes every later system-only
   response across admitted input histories iff

   \[
   \mathcal E_n(\rho)=\operatorname{tr}(F_n\rho)\tau_n,
   \]

   equivalently its Liouville/process matrix has rank one.
4. Construct two exact physical dilations with the same accessible
   outcome-conditioned instrument for every input but different hidden
   archive support.
5. Verify that extending access to the hidden support distinguishes the
   dilations while every system-plus-outcome action does not.
6. Apply the criterion to the public fitted matrices only as a numerical
   diagnostic. Do not convert finite maximum-likelihood rank into an exact
   physical claim without a rank-one null test and uncertainty contract.
