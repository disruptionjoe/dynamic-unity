# Massive-tail and formed-relay causal-saturation gate

## Cold-start contract

Dynamic Unity's purpose is to make physical reality intelligible as one
coherent, evidence-accountable whole. Its North Star is to determine whether
independently selected, observer-indexed certified causal records reconstruct
all observer-accessible time, geometry, fields, and capability, or expose a
finite physical remainder.

The repository begins quiescent at revision 54. `HC-DU-103` proves that a
sound finite response graph reconstructs a finite causal order exactly when
it contains every cover relation, and that a uniform response margin makes
the result robust. It also gives an ordinary-physics failure: a massless
\(3+1\)-dimensional Huygens field can have zero direct response between
strictly timelike regions.

The unspent obligation is physical rather than graph-theoretic:

> Does a massive or multi-field tail supply the missing causal saturation and
> uniform margin, or does robust long-range reconstruction require physically
> formed intermediate events?

The evidence boundary is exact analysis of the standard massive
Klein--Gordon retarded tail, Bessel zeros and asymptotics, one finite relay
composition proposition, primary-source collision with nonlinear Lorentzian
inverse problems, and a proportional deterministic regression. This run
does not simulate spacetime, use external hardware, or test new physics.

Keep independent:

- **direct passive response:** one fixed source-to-readout kernel;
- **local margin:** a positive response gap on one frozen bounded separation
  class;
- **global margin:** one positive gap over an unbounded causal depth;
- **abstract subdivision:** inserting points in a mathematical diagram;
- **formed relay:** an independently localized physical event with a source,
  response, retained identity, and acquired edge record;

  metric remain different objects.

## Cheapest constructive positive

For a finite event poset, suppose a physical extension adds finitely many
formed relay events such that every original cover edge is replaced by a
finite directed path of sound detected edges. If every detected edge has true
response at least \(\gamma_{\mathrm{local}}>0\) and estimation error is below

This earns a conditional compositional reconstruction theorem. It does not
derive or select the relay events.

## Cheapest exact kills

1. **Blind-shell kill:** the massive interior point-response tail is
   proportional to \(J_1(m\tau)/\tau\). It vanishes at
   \(\tau=j_{1,k}/m\), so one mass does not detect every timelike comparison.
2. **Uniform-margin kill:** each fixed massive tail decays as
   \(O(\tau^{-3/2})\). For every finite fixed family,
   \(\max_a|K_{m_a}(\tau)|\to0\), so no positive threshold works over an
   unbounded timelike horizon.
3. **Subdivision kill:** inserting unobserved mathematical vertices does not
   change the acquired event set or response relation.
4. **Interface kill:** a nonlinear source-to-solution map starts with a
   supplied spacetime, source class, observation region, nonlinear law, and
   continuum response interface; it is not already a finite formed relay
   packet.
