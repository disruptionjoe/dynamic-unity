## Frozen source semantics

Riverlane/Rigetti's Zenodo description states that the first decoder-register
column is the logical correction:

```text
DASR = 0 or 2  -> no logical error detected -> no conditional X
DASR = 1       -> logical error detected    -> conditional X
```

Therefore the source-defined action quotient is

\[
\pi(0)=\pi(2)=0,\qquad \pi(1)=1.
\]

The fast-feedback HDF5 file audited by `HC-DU-168` is the discovery packet.
The separately published
`decoder_timings_each_repetition.csv` is the only admitted held-out
replication source. Its schema is not assumed in advance.

## Exact question

> Is \(\pi(DASR)\) sufficient for every retained consequence relevant to the
> downstream action, or does it erase a distinction between action finality
> and resource/timing finality?

Three objects remain typed:

```text
decoder certificate D
  != authorized control action pi(D)
  != physical response Y
```

Timing is a retained resource coordinate, not a hidden global clock or an
ontological time claim.

## Discovery analysis

Within each fast-feedback circuit with rounds 3 through 9:

1. compare `time` for `DASR=0` versus `DASR=2`;
2. report counts, medians, median difference, empirical
   probability-of-superiority, and Kolmogorov--Smirnov distance;
3. compare the no-refit response-failure indicator

   \[
   E=\mathbf1[Y\ne X_{\rm pre}\oplus\pi(D)]
   \]

   across `DASR=0` and `DASR=2`, stratified by round and
   \(X_{\rm pre}\); and
4. treat every association as predictive unless a physical intervention
   identifies it causally.

The discovery result may generate a held-out sign hypothesis. It is not
represented as preregistered.

## Absorber, kill, and stop

- **Strongest absorber:** sufficient statistics, Markov/lumpability theory,
  classical feedback control, decoder-state minimization, and standard QEC
  latency analysis.
- **Cheapest positive:** `DASR=0` and `DASR=2` authorize the same action yet
  have separated retained time distributions within the same round.
- **Cheapest kill:** the distributions coincide at the declared resolution,
  or the held-out file omits the status join needed to test them.
- **Stop:** no causal language from association; no implementation-complete
  claim; no large raw-file download; no provider, hardware, author contact,
  or flagship successor.
