# Probability over not-yet-issued types

## Question

Can a forecaster distribute probability among individually not-yet-issued
types while preserving symmetry, normalization, and conservative extension,
without supplying a richer type universe or generator?

## Frozen contract

- **Lane:** 1, supported by 2, 4, and 7.
- **Channels:** formal, collision, and synthesis.
- **Maximum grade:** scoped Grade 4 naturality/necessity theorem; no evidence
  for source issuance.
- **Strongest absorbers:** naturality under injections, exchangeable random
  partitions, Dirichlet/Pólya processes, open-world recognition, fixed
  ambient type spaces, and `HC-DU-033C/083/085`.
- **Cheapest kill:** arbitrary injection-conservativity already contradicts
  normalized probability on a singleton-to-pair extension.
- **Local-model boundary:** the exact finite proof decides the question; do
  not build a simulation.
- **Hardware:** unavailable and irrelevant.

## Method

1. Audit the proposed stable-core/innovation-budget route against existing
   type-extension and nonstationary-learning results.
2. State probability naturality on finite type sets and injections.
3. Try the singleton-to-pair counterexample.
4. State the equivalent symmetry/conservativity/normalization trilemma.
5. Identify the maximal invariant novelty quotient.
6. Test fixed base measures, Bayesian nonparametrics, physical asymmetry, and
   probability revision as class exits.
7. Keep seeing, choosing, and type issuance distinct.

## Stop

Stop when the finite proof and strongest positive control settle the boundary.
Do not turn lack of a natural prior into lack of all probability, online class
growth into source issuance, or choosing among fixed actions into type
creation.
