# Exact question

Can the smallest autonomous writer--record--consumer dynamics select a complete
matched handoff without a separately supplied interface, or does a physically
meaningful source-to-target relation remain free after record-label gauge,
stability, convergence, and spectrum have all been fixed?

# Scope and authority

Dynamic Unity is the only write scope. Joe's direct request reopens the parked
Lane-1 stable-interaction seam for one bounded theorem-or-counterexample wave.
The public-data search is read-only and bounded; no provider or hardware is
authorized.

# Frozen model

Use the smallest binary chain with source `S`, record `R`, and target `T` in
`{+1,-1}`. The autonomous correction rules are

```text
R <- a S   when R != a S
T <- b R   when T != b R
```

for fixed local coupling signs `a,b in {+1,-1}`. The same signs define the
commuting Ising/quantum Hamiltonian

```text
H = -J (a Z_S Z_R + b Z_R Z_T).
```

The internal record-label transformation flips `R`, `a`, and `b` together.
The target ruler is held fixed in the primary comparison and co-transformed
only in the explicit gauge foil.

# Tests

1. **Autonomous convergence.** Exhaust every sign choice, source sector, and
   initial record/target state; prove that every asynchronous correction path
   reaches one absorbing matched state.
2. **Record-gauge quotient.** Prove that internal record relabeling removes the
   individual signs while preserving the product `h = a b`, leaving exactly
   two matched handoff orbits.
3. **Anchor fork.** Show that target relabeling flips `h`; classify it as gauge
   only when the target ruler and every target observable co-transform.
4. **Stability-isospectral kill.** Compare convergence profiles and exact
   classical/quantum spectra across all sign choices. Test whether those data
   select `h`.
5. **Thermal response.** At `beta J = ln 2`, compute the exact source--record,
   record--target, and source--target correlations without floating point.
6. **Quantum/open-system transfer.** Embed the chain as a diagonal three-qubit
   Hamiltonian and an autonomous mismatch-correction jump graph. Claim only
   transfer of the selection boundary, not a noncommuting quantum effect.
7. **Physical calibration.** Boundedly audit primary public autonomous-feedback
   and returned-shot feedback packets for a stronger complete handoff.

# Absorbers and maximum grade

Glauber and dissipative stabilization, gauge quotienting, sufficient

Maximum grade is scoped Grade 4 for an exact finite theorem/counterexample,

# Cheapest kill and stop rules

Cheapest kill: stability, convergence, gap, and spectrum are identical while
the gauge-invariant handoff parity `h` remains free.

Stop if:

- an absolute record label is called physical after matched relabeling;
- a target flip is called gauge while its ruler is silently held fixed;
- fixed coupling signs are called autonomously derived;
- an engineered steady state is called a naturally selected interface;
- a diagonal quantum embedding is advertised as a nonclassical result;
- public returned shots are called an all-attempt controller census; or
- any repository other than Dynamic Unity is written.
