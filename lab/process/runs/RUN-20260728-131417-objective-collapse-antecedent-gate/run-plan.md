# Objective-collapse antecedent and primitive-ontology gate

## Question

For GRW collapse models with flash and matter-density primitive ontologies,
what is selected at each of these three levels?

```text
L
  stochastic wave-function/collapse law

(L, PO)
  complete theory after a primitive ontology is posited

(L, PO, apparatus/access)
  operational record architecture for a bounded observer
```

The run must determine whether this changes Dynamic Unity's missing physical
antecedent without identifying a real occurrence with a retained or accessible
record.

## Scope

- **Primary lanes:** Lanes 1 and 3.
- **Supporting lanes:** Lanes 2, 4, and 7.
- **Channels:** literature collision, formal proof, and synthesis.
- **Maximum return:** scoped Grade-4 source classification or
  non-identification theorem, plus a conditional Grade-2 physical antecedent.
- **Strongest absorber:** the same GRW collapse dynamics admits flash and
  matter-density primitive ontologies that are reported to be empirically
  equivalent.
- **Cheapest kill of law-only selection:** one fixed collapse law compatible
  with two inequivalent primitive histories and the same operational outcome
  distributions.
- **Hardware:** unavailable and irrelevant.
- **Local model:** prohibited unless the primary-source equations leave a
  decision-changing finite question.

## Corrected return contract

The original scaffold required one exclusive chairman label. That is too
coarse. The following statements can both be true:

```text
LAW_ONLY_PRIMITIVE_ONTOLOGY_NONSELECTION
FULL_THEORY_PHYSICAL_OCCURRENCE_PROCESS_ADMITTED
```

The run therefore returns a typed tuple with one result at each level:

```text
law_level:
  UNIQUE_PO_SELECTED | PO_PLURALITY | NO_PHYSICAL_EVENT_LAW

complete_theory_level:
  FLASH_PROCESS_ADMITTED | MATTER_PROCESS_ADMITTED
  | BOTH_CONDITIONALLY_ADMITTED | MODEL_SCOPE_BLOCK

operational_record_level:
  RECORD_ARCHITECTURE_SELECTED | RECORD_ARCHITECTURE_SUPPLIED
  | NOT_YET_ADJUDICATED
```

Swing 2 may open only when the complete-theory level admits at least one
physical process. It must remain explicitly conditional on the selected
theory `(L, PO)` if the law-level result is `PO_PLURALITY`.

## Record-formation admission test

A candidate formed record must satisfy all five conditions:

1. **source binding:** it is causally/history-conditioned on the claimed
   occurrence;
2. **finite persistence:** it survives for a declared nonzero horizon;
3. **bounded access:** an admitted finite observer interaction can retrieve
   it;
4. **nontriviality:** it carries source information beyond the antecedent
   prior; and
5. **target independence:** it was not defined using the held-out response.

A primitive event or matter field can pass the complete-theory admission while
failing this record test.

## Held-out target escrow

For any later formation swing, hold fixed:

> The binary macroscopic response of a separate pointer during a fixed future
> spacetime window after a predeclared probe coupling, with the same operational
> response regions and resource budget across primitive ontologies.

The target is not used to choose flashes, matter density, a pointer quotient,
an archive, or observer access.

## Method

1. Reconstruct the native stochastic and ontology objects.
2. Complete the selected-versus-supplied ledger.
3. Prove or kill law-only primitive-ontology identification.
4. Determine what a fully specified `(L, PO)` physically admits.
5. Apply the five-part record-formation admission test.
6. Separate collapse-law empirical excess from primitive-ontology
   underdetermination.
7. Bank the smallest exact result and stop before Swing 2.

## Stop

Stop after the typed admission result. Do not:

- simulate collapse trajectories;
- infer a record from the word `flash`;
- infer observer access from physical reality;
- treat empirical equivalence as physical identity;
- generalize fixed-particle rGRWf to relativistic QFT;
- infer that objective collapse is true;
- activate Swing 2 without a later current-authority transition; or
- change paper or prediction state.
