# Finite-time infrared-memory typed-record reopener audit

## Question

Do the 2026 finite-time and detector-resolution infrared-memory results
satisfy Dynamic Unity's parked reopener by physically selecting a finite,
observer-accessible typed record and leaving an independently held-out
hard-process target—or do they select only a memory carrier or dressing while
the operational interface remains supplied?

## Scope and controls

- **Owning lane:** Lane 3.
- **Supporting lanes:** Lanes 1, 4, 6, and 7.
- **Channels:** literature collision, synthesis, and formal proof.
- **Maximum return:** scoped Grade-4 selector or nonselection theorem. A
  source reconstruction alone remains Grade 2.
- **Strongest absorber:** ordinary infrared-safe scattering, asymptotic
  symmetry/memory, detector-relative coarse graining, AQFT measurement theory,
  and representation-relative dressing or instrument choice.
- **Cheapest kill:** the proposed finite-time detector still requires
  null-infinity, zero-frequency, or infinite-time limits; its resolution,
  access algebra, instrument, or target is supplied; or the classical memory
  target is used to select the dressing later credited with reproducing it.
- **Local-computation disposition:** no model. Exact definitions, limiting
  structure, naturality, and target-leakage analysis decide this audit.
- **Hardware disposition:** unavailable, unnecessary, and irrelevant.
- **Ontology posture:** verdict-open; no record-first interpretation is
  assumed.

The primary source packet is frozen to:

1. Brett Oertel, *Finite-time memory detectors and fully constraining
   Faddeev--Kulish dressings in QED and gravity*, arXiv:2605.06774v1;
2. Takeshi Fukuyama, *Detector Resolution and Observable Infrared Memory in

3. Jan Mandrysch, Robin Simmons, and Miguel Navascués, *Causality and

## Method

1. Reconstruct the state/process class, dressing, memory observable, detector,
   limits, resolution, observer-access algebra, record map, completion fibre,
   and held-out target in the smallest serious QED arena.
2. Mark every load-bearing component:

   ```text
   DYNAMICALLY_SELECTED
   SYMMETRY_SELECTED
   DERIVED_AFTER_SELECTION
   EXTERNALLY_SUPPLIED
   FITTED_TO_TARGET
   ```

3. Separate a detector defined on a constant-time surface from a detector
   operationally available at bounded time and distance.
4. Test target leakage: a condition used to select a dressing, detector, or
   quotient cannot also serve as its held-out validation.
5. Use local-QFT realizability only as an admissibility filter. Do not infer
   that causality selects an implementable instrument or attempt a universal
   realizability algorithm.
6. Return exactly one disposition:

   ```text
   SELECTOR_FOUND
   PARTIAL_PHYSICAL_TYPING
   SUPPLIED_INTERFACE_ABSORPTION
   ASYMPTOTIC_ONLY
   TARGET_LEAKAGE
   NO_READY_SUCCESSOR
   ```

## Activation gate

A second swing may become executable only if all three conditions hold:

1. at least one nontrivial record-interface component is selected by physical
   dynamics or symmetry independently of the held-out target;
2. a bounded observer-access contract can be stated without replacing the
   source construction by a freely supplied detector; and
3. a hard-process or future-response target remains genuinely held out after
   the interface is frozen.

Partial physical typing is scientifically bankable but does not by itself
activate a successor.

## Required outputs

1. a primary-source scope and limit audit;
2. a selected/supplied/fitted typed ladder;
3. the exact target-leakage finding;
4. the strongest selector and strongest ambiguity statement warranted;
5. reopener and activation-gate disposition;
6. durable exploration evidence, governed run receipt, and live-state
   transition; and
7. validation, explicit-path commit, push, and session completion.

## Stop

Stop after the source packet decides the parked reopener. Do not build an
infrared toy, infer finite access from the phrase “finite-time,” rename a soft
cloud as a certified record, treat detector resolution as dynamically
selected, count target-fitted agreement as validation, or pre-authorize the
four conditional follow-on swings.
