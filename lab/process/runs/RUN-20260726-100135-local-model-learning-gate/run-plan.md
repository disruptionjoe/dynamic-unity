# Local model learning gate

## Objective

Make local research-model construction conditional on an epistemic payoff
available before any external-hardware boundary:

1. name the exact new local insight or decision the build can produce;
2. compare it with the result available through bounded literature review and
   formal analysis alone;
3. refuse builds whose first meaningful learning requires external hardware;
4. allow hardware to extend, but never originate, the build's first
   epistemic payoff; and
5. stop a minimally admitted build if its local learning checkpoint fails.

## Predeclared dispositions

1. `ADMIT_LOCAL_LEARNING_BUILD`: the minimal build can generate a specific,
   decision-changing local result unavailable at equal grade from the bounded
   research-only baseline.
2. `DESK_RESEARCH_FIRST`: literature or formal analysis can provide the
   proposed learning without building.
3. `EXTERNAL_PAYOFF_ONLY_STOP`: the first meaningful result arrives only
   after hardware or external data, so no local research build begins.
4. `INCOMPLETE_LEARNING_CONTRACT`: the local insight, baseline, generator,
   stop test, or hardware boundary is not specified.
5. `STOP_NO_LOCAL_LEARNING`: an admitted minimal build reached its checkpoint
   without the predeclared local insight.
6. `NO_DECISION_VALUE_STOP`: all outcomes leave the research route unchanged.
7. `REDUCE_BEFORE_ADMISSION`: a smaller construction can reach the same local
   checkpoint.

## Evidence boundary

- “New learning” means new to the active Dynamic Unity decision at a declared
  grade; it is not automatically literature novelty or new physics.
- Reproducing a known result, visualizing a cited mechanism, or preparing a
  provider adapter is not new local learning.
- A minimal verification artifact may preserve an independently obtained
  result, but it is not a research-model justification and must not expand
  into a modeling program.
- This run creates the gate only. It does not admit or build any focal model.

## Durable output

A concise local-model learning contract, exact scenario classifier, cold-start
orientation rule, and stop/reopen instructions.
