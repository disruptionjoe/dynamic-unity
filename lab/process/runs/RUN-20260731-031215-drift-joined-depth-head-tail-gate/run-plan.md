# DRIFT joined depth/head-tail gate

## Cold-start contract

- **Purpose:** make physical reality intelligible as one coherent,
  evidence-accountable whole.
- **North Star:** determine what target-blind physical antecedents, if any,
  select material, provenance-bearing, observer-indexed record interfaces;
  then test reconstruction, operational duality, and finite remainder.
- **Starting state:** `HC-DU-182--183` join acquisition, absolute depth,
  prompt timing, and event-pairing boundaries while treating source-pinned
  head-tail and depth positives as separate.
- **Bounded role:** test whether one real configuration joins absolute depth
  and physical path-polarity information; then separate ensemble sensitivity
  from per-event certification.
- **Owning lane/channels:** Lane 3 with Lanes 1, 4, and 7 support;
  `CH-EMPIRICAL`, `CH-FORMAL`, `CH-MODEL`, and `CH-COLLIDE`.

## Frozen question

> Has one existing source-pinned detector physically joined absolute depth,
> acquired event waveforms, and path polarity; and if so, does its published
> head-tail result certify the direction of each realized event?

## Source order

1. Use the 2016 DRIFT-IId head-tail paper as the sole joined architecture.
2. Use the 2014/2015 fully fiducialised DRIFT paper to audit source-free
   operation, efficiency, and failure regions in the same detector mode.
3. Do not credit MIMAC, Timepix3, CYGNO, or another architecture.
4. Use one exact binary-law fixture; do not simulate the detector.

## Pre-registered theorem, kills, and repairs

- **Joined positive:** the same physical event packet contains multi-carrier
  timing and a head-tail statistic.
- **Ensemble/event boundary:** unequal orientation-conditioned means imply
  physical information, not zero-error event certification.
- **Zero-error criterion:** exact one-event sense requires disjoint
  orientation-conditioned supports.
- **Source-tag boundary:** known calibration-source geometry is valid side
  information, not an intrinsic unknown-event provenance field.
- **Event-class kill:** overlapping minority peaks, diffusion, trigger
  threshold, and stated systematics restrict the admitted positive.
- **Repair:** publish or derive per-event likelihood/support and error on the
  same frozen detector class.

## Grade and absorber contract

- **Maximum:** scoped Grade 4 ensemble/event-certification boundary.
- **Conditional:** Grade 3 joined depth/head-tail reconstruction on the
  source's admitted event class.
- **Source audit:** Grade 2.
- **Absorbers:** directional TPCs, negative-ion drift, stopping power,
  detector calibration, binary testing, total variation, efficiency, and
  systematic-error analysis.
- **No novelty credit:** for the physical detector result or hypothesis
  testing as such.

decide the boundary. No hardware, provider, detector simulation, or external
compute is authorized.
