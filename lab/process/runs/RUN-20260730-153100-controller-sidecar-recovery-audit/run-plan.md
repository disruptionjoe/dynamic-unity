## Exact typed question

Audit five levels separately:

```text

  != exact executable program/configuration
  != issued command lineage
  != physically acknowledged actuation
  != all-attempt material archive and environment scope
```

For each level, classify the public evidence as:

```text

```

Do not promote an intended conditional branch into a per-row actuation
acknowledgement, or a returned-row archive into an attempted-process census.

## Positive and hostile checks

### Positive recovery

Check whether the source supplies:

- the QEC/feedback workflow and instruction ordering;
- decoder initialization categories and logical-observable definition;
- buffering, packet formation, WISHBONE transport, polling, and result use;
- clocks, topology, fixed delay, conditional-\(X\)/matched-idle semantics;
- logical circuit, selected qubits, measurement order, calibration, and
  returned-row joins.

### Hostile boundary

Check separately for:

- exact pyQuil, compiled assembly, waveforms, binary, firmware, or complete
  configuration values;
- trigger identifiers, all-attempt counts, retries, rejects, aborts, and
  dispositions;
- per-row command issue, decoder route/state, actuation acknowledgement, and
  controller-memory lineage;
- waveform/buffer lineage before integrated I/Q;
- archive write/retention/overwrite/access/reset semantics; and
- a declared environment/persistence scope.

Absence from the source bundle is a public-evidence boundary, not evidence
that the laboratory lacked the structure.

## Command/actuation countermodel

Freeze one command record \(C\), intended action map \(a(C)\), physical
actuation \(U\), and later response \(Y\). Construct two admissible physical
implementations with the same public returned record and command semantics:

```text
implementation 0: the intended X is physically delivered;
implementation 1: the same X command is issued but the pulse is lost, while
                  omitted environment/controller state compensates the
                  retained binary response.
```

If both reproduce every retained public field while differing in physical
actuation/provenance, then program semantics plus returned response do not
identify physical actuation. This is a type-level nonidentification control,
not a claim that either implementation occurred.

## Absorber, kill, and stop

- **Strongest absorber:** experimental reproducibility standards, control
  logs, event sourcing, database provenance, latent fault models, and
  process identification.
- **Cheapest positive:** the supplement closes a previously missing
  workflow/route rung and materially narrows the sidecar request.
- **Cheapest kill:** the bundle contains the exact executable, all-attempt,
  actuation, archive, and environment records; then the flagship reopener
  must be reconsidered rather than preserved.
- **Stop:** no proprietary-state inference, author/lab contact, hardware,
  provider, large raw-file download, new model of physics, or later campaign
  activation.
