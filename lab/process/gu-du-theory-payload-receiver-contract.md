# GU → Dynamic Unity theory-payload receiver

## Purpose

This contract gives Dynamic Unity a sovereign, fail-closed way to inspect a
future Geometric Unity theory payload. GU owns its theory, objects, proofs and
grades. DU owns whether any supplied packet is usable for DU-local
verification. Repository custody, a valid schema, or GU's declaration of
readiness is never Dynamic Unity evidence by itself.

The current machine record is
`lab/process/gu-du-theory-payload-current.json`; its schema is
`lab/process/gu-du-theory-payload-v0.1.schema.json`.

## Two gates that must not collapse

### Gate 1 — source qualification

A packet may move from `REJECT_NOT_READY` to
`ADMIT_FOR_LOCAL_VERIFICATION` only when all of these are present:

1. immutable GU repository revision and passport identity;
2. GU export status `ready`;
3. satisfied, evidence-bearing action/causal, physical-state and observable
   burdens in that order;
4. non-null qualified action/domain, physical-state, observable-process,
   frozen-test and truth-grade/live-null bundles; and
5. no unresolved source-side missing condition.

Admission opens only DU-local checking. It has `routing_effect: none`,
`wip_effect: none` and `grade_effect: none`.

### Gate 2 — DU-local verification

Dynamic Unity then independently checks:

- coefficient-complete action, Euler/Noether ownership, causal domain,
  boundary and common Green prescription;
- positive physical state space and the exact quotient/domain on which it is
  positive and conserved;
- source/response and preparation/intervention/outcome maps;
- target-blind record instrument, material carrier, formation, retention,
  provenance, access and reset;
- frozen projection, comparator, null, held-out target and completion fibre;
  and
- the incumbent QFT/EFT/GR/open-system absorbers and a finite no-refit
  discriminator.

Passing Gate 1 does not pass Gate 2. Passing Gate 2 still does not change
`CURRENT-RESEARCH.yaml`; any priority, WIP, grade, successor or prediction
transition requires a separately governed DU result and live-state update.
