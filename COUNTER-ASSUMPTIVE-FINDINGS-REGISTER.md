# Counter-Assumptive Findings Register

This is the “do not reason from the obvious default” register for Dynamic
Unity, GU Formalization, Time as Finality, Temporal Issuance, and Possibility
to Capability.

Every row records a result an agent is likely to reverse, silently broaden,
collapse into a neighboring type, or overlook because the earned result goes
against a plausible first reading. Read the row before reusing the named
object. Then read the source before making it load-bearing.

## Authority and use

This register is an orientation index, not a cross-repository claim ledger.

- Each source repository retains authority over its definitions, grades,
  construction forks, claims, and verdicts.
- The wording below is Dynamic Unity's provenance-bearing reuse instruction.
  If it conflicts with a source artifact, the source artifact wins.
- A row does not import a sibling claim as Dynamic Unity truth, promote a
  result, or combine partial results into a joint success.
- “Exact” means exact in the declared model or class. “Finite” is not
  “universal.” “Conditional” means the antecedent is still a burden.
- “Located,” “admitted,” “represented,” “compatible,” “selected,” “formed,”
  “accessible,” “capable,” and “final” are different grades and types.

## Cross-program rules that follow from the register

   resource-changed target closure.

   change, resource change, and occurrence/contract retyping separately.

    appear merely because a physical configuration was selected.
