# ECR-N5-S3 matter-environment provenance lift

## Objective

Hold one complete matter--environment process fixed and test whether it
physically forms the epoch/write witness required by `HC-DU-043`, rather
than adding that witness as a monitoring or archive convention. If a
formed witness exists, test whether it is a strict autonomous compression
for a frozen bounded capability. If it does not, return the smallest exact
formation or reversibility obstruction.

- the four-state alternating-rate matter host of `HC-DU-043`;

- redundant histories, trajectory unravellings, reversible computation,
  Landauer accounting, and ordinary detector physics used as mandatory
  absorbers.

## Exact questions

1. Is the minimum binary set/reset epoch transducer unique up to relabeling?
2. Can that transducer be implemented by closed reversible dynamics on
   bounded support?
3. If not, what fresh or exported support is minimally required?
4. Does the inherited matter host select that support and its write/reset
   coupling, or are they additional physical antecedents?
5. When a history output is physically retained, is the bounded epoch flag
   an autonomous strict quotient for the preregistered capability
   "did a write occur since the certified reset"?
6. Which larger capability first separates histories compressed by that
   flag?
