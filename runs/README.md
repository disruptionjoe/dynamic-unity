# Legacy run receipts

This directory preserves older, flat Dynamic Unity run receipts as historical
evidence. It is non-routing: an `active` label in one of these dated files does
not describe current work.

- Read [`../CURRENT-RESEARCH.yaml`](../CURRENT-RESEARCH.yaml) for live priority,
  WIP, execution, stops, reopeners, and dependencies.
- Put every new governed run in
  [`../lab/process/runs/`](../lab/process/runs/).
- Do not relocate or rewrite these receipts merely to normalize the historical
  layout. Supersede them additively when needed.
