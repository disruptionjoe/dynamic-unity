# Heterodox professor: operational record-capacity swing

## Result first

I chose the record problem, but not by trying again to make a Clock QCA look
like a relativistic clock.

The more foundational missing object was:

> **What is one new record, after copies, identity relays, overwritten
> memories, scheduler tags, and analyst-chosen encodings are quotiented?**

I constructed an operational candidate. Let `H_t` be the possible input
histories of an observer at step `t`, let `E_t` map a history to the
observer's physical state, and let `U_t` be a declared family of physically
available experiments. Define:

```text
h ~_U h'
    iff every admitted experiment u in U_t
        returns the same outcome from E_t(h) and E_t(h').

Q_t = |H_t / ~_U|
C_t = log_2 Q_t.
```

`C_t` is an operational capacity of distinguishable retained history under
the declared experiment family, measured in bits. In a general quotient,
`log_2 Q_t` need not be an integer and does not by itself prove that the
classes decompose into that many jointly independent binary record variables.
It is not:

- cumulative writes;
- update opportunities;
- state changes;
- causal-influence count;
- Shannon entropy under one input distribution;
- thermodynamic work;
- a count of successful repairs;
- elapsed time; or
- proper time.

The exact probe passes `16/16` checks and establishes a simple saturation
theorem:

> If every admitted response factors through a fixed observer state set `S`
> with `|S|=M`, then `Q_t <= M`. If each binary opportunity adds one
> durable independent record bit, then `Q_t >= 2^t`. Therefore `M >= 2^t`.

So a fixed finite observer cannot indefinitely add one new **independent,
durable** record per opportunity. An unbounded record clock needs at least one
of:

1. a growing internal state space;
2. an expanding or exported archive included inside the physical record
   boundary; or
3. a weaker meaning of record, such as an event token that need not preserve
   an additional independent distinction.

The escape through export is real, not a loophole to suppress. It is also not
free. In the six-bit fixture, the finite internal observer retains one bit;
the observer plus append-only external archive retains six. Removing the
archive removes five bits. The boundary and storage growth now become the
mechanism to build and price.

There is also an exact negative result:

> There is no absolute readout-independent value of `C_t`.

A full six-bit memory and a one-bit parity accumulator both have two classes
under the development readout “what is parity?” A held-out family asking for
the individual bits gives `64` classes for the full memory and only `2` for
the parity accumulator. The experiment algebra must therefore be extracted
from physical access, not selected after seeing the desired record count.

### 1.4 Primary antecedents and retained scope

The candidate is not invented from vocabulary alone.

- [Moore, *Gedanken-Experiments on Sequential Machines*
  (1956)](https://www.cs.cmu.edu/~cdm/resources/Moore1956-gedanken-experiments.pdf)
  defines finite-machine state distinguishability by whether some external
  experiment produces different outcomes. Isomorphic machines can differ in
  state names while remaining behaviorally indistinguishable. This supplies
  the standard external-experiment discipline, not a DU record ontology.
- [Crutchfield and Young, *Inferring Statistical Complexity*
  (1989)](https://doi.org/10.1103/PhysRevLett.63.105) reconstruct
  measurement-dependent equivalence classes and minimal machines from
  observed sequences. Their states are oriented toward predictive structure;
  the object here instead measures retained distinguishability among past
  input histories. The common lesson is that the measurement instrument and
  quotient must be explicit.
- [Landauer, *Irreversibility and Heat Generation in the Computing Process*
  (1961)](https://doi.org/10.1147/rd.53.0183) analyzes physical information
  storage and logically irreversible operations using explicit device
  models. I use it as a boundary on the claim, not as a numerical result:
  logical class merger is not itself a joule value, and no work/heat claim is
  made without a physical erasure protocol, bath, and implementation.

The finite-state bound below is proved directly. I do not claim novelty for


### 3.2 Experiment algebra and quotient

Let `U_t` be a declared set of physically possible queries or interventions,
and:

```text
Y_t(E_t(h),u)
```

their outcomes.

Define:

```text
h ~_U h'
    iff Y_t(E_t(h),u) = Y_t(E_t(h'),u)
        for every u in U_t.
```

Then:

```text
Q_t = |H_t / ~_U|
C_t = log_2 Q_t bits.
```

`C_t` is the maximum stock of distinguishable retained history under the
frozen physical experiment algebra. It is distribution-free. If the
equivalence classes are not powers of two, the natural generalization remains
`log_2 Q_t`; the probe uses powers of two so every displayed value is exact.

### 3.3 Durability

Present distinguishability is not enough. For any distinct time-`t` classes,
no pair of one-symbol extensions may merge:

```text
[h]_t != [h']_t
    implies
[h a]_(t+1) != [h' b]_(t+1)
    for every a,b in {0,1}.
```

This is intentionally stronger than “some record of an update occurred.”
It asks whether the accumulated stock remains available. Full append-only
memory passes. Last-bit, parity, and rolling memories eventually fail.

The event-flux alternative remains live:

```text
number of record-forming events
    !=
stock of independently retained historical distinctions.
```

The present swing solves the second object and prevents the first from
silently impersonating it.

## 5. Exact bounded swing

### 5.1 Classical finite exact-state durable-record theorem

**Theorem.** Let all admitted response signatures at time `t` factor through
a finite state set `S` with `|S|=M`. Then:

```text
Q_t <= M.
```

If at each binary opportunity:

1. previous classes never merge; and
2. the new input creates one independent binary distinction for every
   retained class,

then:

```text
Q_t >= 2^t Q_0.
```

For one initial class:

```text
2^t <= Q_t <= M,
```

so:

```text
M >= 2^t.
```

**Proof.**

1. A response signature is a function of the current state. At most `M`
   states can yield at most `M` distinct signatures.
2. Durability prevents the quotient class count from falling by merger.
3. One new independent binary record splits every retained class into two,
   so the class count doubles at each opportunity.
4. Induction gives `Q_t >= 2^t Q_0`. Combine the lower and upper bounds.

This is a classical, finite, deterministic, exact-distinguishability theorem.
It is not a no-go for:

- unbounded event number;
- a continuously growing observer;
- an environment carrying exported records;
- reversible computation;
- proper time;
- approximate records;
- continuous or quantum state spaces; or
- a clock whose events do not each add an independent persistent bit.

It is a no-go for one specific conjunction:

```text
fixed finite observer
+ one new independent durable bit per opportunity
+ indefinitely many opportunities.
```
