# Executive decision

The twenty-lens computation and networking pass should change Dynamic Unity's
research method, but it does not yet change its scientific claims.

The useful reversal is:

```text
old starting question
  Which physical mechanism writes a record, and which mechanism consumes it?

new conditional starting question
  What if state change, transition certification, and future admissible use
  are different typed faces of one closed physical transition?
```

The strongest plain-English candidate is:

> Reality is not software running on a separate computer. Its interactions
> are simultaneously the computation, the evidence that a transition
> occurred, and the change in what participating systems can do next.

This is a **conditional posit**, not an ontology result. Ordinary computation
presupposes a substrate, interpreter, memory semantics, scheduling, and an
external distinction between data and program. A bottom-level computation
may not inherit those objects silently. It must either derive them or use a
formalism in which process, state, and composition are primitive together.

The forty lens suggestions therefore collapse into eight hypothesis families,
not forty new claims. Almost every component already has a mature absorber or
a DU precursor. The genuinely new work is one non-vacuity and translation
problem:

> Define the smallest closed typed transition system, map it without refit to
> both the DU kernel and a complete quantum process specimen, and identify
> exactly which additional axioms—if any—remain after process theory,
> categorical quantum mechanics, records, actions, and resources are fully
> typed.

Only that action is executable. Four dependent positions remain conditional.
No physical hypothesis is promoted by this scaffold.

# 1. What the proposed system is

The minimum candidate is not a database, blockchain, game server, cellular
automaton, neural network, or classical global state. Those are lenses on
parts of the architecture.

The candidate is a **closed distributed typed transition system** containing:

1. local or regional physical process objects;
2. typed interactions and their allowed composition;
3. primitive operational precedence, without presuming a metric or clock;
4. transition certificates tied to occurrence and source provenance;
5. observer-indexed access, action, resource, and horizon contracts;
6. continuation or capability structure changed by enacted transitions;
7. physical equivalences under which the complete handoff descends; and
8. no external interpreter that supplies the meaning of a record after it is
   formed.

A schematic transition is therefore not merely

```text
input state -> output state.
```

It is typed as

```text
admitted local process state
  + interaction and resource contract
  -> changed process state
  + occurrence/provenance certificate
  + changed admissible continuation set.
```

This does not assert that every physical interaction forms a retained record.
It says that a candidate **record-forming** transition must locate carrier,
formation, provenance, retention, access, and continuation inside the physical
transition contract instead of appending semantic interpretation afterward.

# 2. Quantum mechanics and classical physics in this picture

The candidate cannot begin with classical messages and then add quantum
behavior. That would presuppose the layer it is meant to explain.

The honest conditional bridge is:

```text
complete noncommutative multi-time process
  -> physically selected interaction/instrument
  -> realized outcome and material transition
  -> retained provenance-bearing carrier
  -> physically selected copyable/comparable/mergeable action interface
  -> observer-accessible classical description.
```

The quantum layer is the complete order- and intervention-sensitive process.
The classical layer is conjectured to be the physically selected substructure
whose records can be copied, compared, transported, merged, and reused under
the declared action envelope.

This is stronger than saying “decoherence makes things classical,” but it is
not yet known to be true. Three objects may fail to coincide:

- an algebraically copyable commutative structure;
- an operationally mergeable or serializable record structure; and
- a materially formed, accessible, stable archive.

[`HC-DU-159`](instrument-no-section-admission-and-smallest-natural-selection-boundary-2026-07-30.md)
already proves that a bare process does not universally select an informative,
nondisturbing, complete material interface. Categorical copy/delete structure
selects a basis-like classical algebra but not its physical sampler, archive,
provenance, access, or continuation.

[`HC-DU-200`](generic-objectivity-transfer-d3-and-q0063-terminal-verdict-2026-08-28.md)
already shows that a raw Quantum-Darwinism plateau does not by itself certify
accessible classical content. Strong QD and Spectrum Broadcast Structure are
the main physical absorbers. Consequently, “classicality as composability” is
admitted only as a comparison problem:

> Do algebraic copyability, operational mergeability, and material
> accessibility select the same maximal physical substructure under one
> target-blind law?

# 3. What `HC-DU-205` means after the computation-first reversal

[`HC-DU-205`](record-algebra-consumer-action-inverse-write-boundary-and-three-mechanism-selector-frontier-2026-08-31.md)
proved that a formed record algebra admits many record-preserving consumers
with different downstream capabilities. An inverse write erases the record;
it does not select how the record is used.

In a conventional architecture this is obvious:

```text
stored data != program that consumes it.
```

The computation-first posit does not refute that theorem. It proposes a
different primitive:

```text
record-forming transition
  = physical state change
  + certificate
  + constrained continuation type.
```

That move earns nothing until one physical interaction jointly selects those
fields. If the transition is merely a tuple containing a supplied consumer,
the proposal has renamed the complete handoff from `HC-DU-054` and failed its
own anti-vacuity gate.

The decisive question is therefore no longer whether data “contains its own
meaning.” It is:

> Does physical dynamics select a joint transition type whose formation and
> continuation semantics cannot be varied independently inside the admitted
> antecedent class?

# 4. What the geometry can and cannot mean

Several exact mathematical correspondences justify using geometric language:

| Geometry | Process reading | Status |
|---|---|---|
| fibre | local state or possibility object over a context | exact structural reading |
| connection | rule for transporting/comparing local data | exact structural reading |
| section | compatible assignment across contexts | exact structural reading |
| curvature/holonomy | path-dependent transport around a loop | exact structural reading |
| obstruction/cohomology | failure of a global compatible section | exact structural reading |
| gauge | re-encoding under which complete physical response descends | exact only after all physical fields descend |
| shard/region | bounded physical access and action surface | analogy until dynamically selected |
| consensus/finality | action-safe regional certificate | analogy until physical fault/timing/action types are fixed |

The computational lenses therefore see a distributed process bundle more
readily than a global database. But geometry does not automatically follow
from network topology.

[`HC-DU-094`](operational-influence-capability-saturation-and-active-wave-geometry-reconstruction-boundary-2026-07-28.md)
proves that one complete process may realize only a suborder of the causal
possibilities allowed by the spacetime. Geometry requires a sufficiently rich,
physically realizable capability surface, not one observed history.

[`HC-DU-112`](complete-causal-set-law-scale-gauge-and-marked-anchor-necessity-2026-07-29.md)
then proves that even the complete unmarked Poisson causal-set law cannot
self-calibrate absolute scale. A physical scale-bearing relation must be
selected, formed, accessible, and calibrated independently.

Thus the geometry hypothesis is deliberately downstream:

```text
selected finite transition/capability family
  + retained response records
  + independently selected scale-bearing mark
  -> held-out causal/conformal/metric reconstruction
  OR exact remainder.
```

# 8. Five-position campaign

## Position 1 — non-vacuity and translation audit — executable

Define the smallest closed typed transition system and construct
target-independent adapters to:

1. the DU completion/record/action/resource kernel;
2. one complete finite quantum process/instrument specimen; and
3. one classical event-system control.

Return exactly one of:

- `PURE_REPRESENTATION_ABSORBED`;
- `NONTRIVIAL_AXIOM_WITH_THEOREM_OBLIGATION`;
- `INCONSISTENT_WITH_QUANTUM_PROCESS_CONTROL`; or
- `UNDERDEFINED_EXTERNAL_INTERPRETER_REMAINS`.

This is the most information-dense first move. A clean absorption prevents
five waves of relabeling. A surviving axiom gives the rest of the campaign a
real object.

## Position 2 — classical composability boundary — conditional

Compare, without changing the specimen:

- commutative/copyable algebra;
- operational mergeability and order independence;
- material formation, retention, and access; and
- action-family sufficiency.

Prove a maximality/naturality statement or return the smallest pair of
inequivalent maximal structures. Do not reopen QD threshold hunting unless a
selected composability variable produces a standard-process delta.

## Position 3 — record-capability coformation — conditional

Search for one physical interaction in which write, provenance certificate,
and continuation action are jointly selected. Use `HC-DU-205` as the hostile
control. If every candidate factorizes, bank the strongest scoped
nonselection theorem rather than adding hosts.

## Position 4 — dynamic sharding and layered finality — conditional

Only after Positions 2 and 3 supply physical types, test whether regions form
and compose without one global state. Freeze identity, timing, fault, trust,
resource, access, rollback, and action semantics before applying FLP, CAP,
CALM, gossip, metastable, threshold, or BFT mathematics.

The required return is a composition theorem, first leak, or explicit
non-unification—not “physics resembles consensus.”

## Position 5 — geometry recovery and excess gate — conditional

Apply the unchanged transition/capability object to one finite geometry
specimen. Preserve the `HC-DU-094` capability-saturation requirement and the
`HC-DU-112` scale gauge. Attempt causal/conformal reconstruction first;
absolute metric structure requires an independently selected physical mark.

End the campaign with one of:

- a scoped reconstruction theorem;
- a typed non-unification;
- a finite standard-process residual; or
- complete absorption and closure of the computation-first candidate.

# 9. Agent-orientation rules

An agent entering this program must not:

- create another computation metaphor or persona list;
- treat “information processing” as evidence for computational ontology;
- model quantum physics as a classical distributed database;
- identify decoherence, copying, redundancy, or agreement with material
  record formation;
- treat a record as action-enabling without a named physical continuation;
- import consensus, cryptographic, or networking theorems without exact
  physical assumption matching;
- infer metric geometry from topology/order alone;
- fit an observer, shard, decoder, action family, or scale after seeing the
  target; or
- proceed to a dependent position before its predecessor returns the named
  object.

An agent must:

1. read the structured portfolio and the current execution packet;
2. declare whether each map is identity, faithful representation, quotient,
   physical selection, or analogy;
3. expose every supplied interface and free choice;
4. use the strongest standard null first;
5. report what would make the candidate more than a relabel; and
6. credit absorption or exact failure as the intended result.
