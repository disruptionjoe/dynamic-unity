# Noninvertible history-certificate compiler — finite pilot

## Plain result

The finite compiler kernel is viable, but neither focal fixture produces a
remainder.

The compiler freezes a nonempty, target-independent finite grammar of
candidate record/provenance refinements and only then consults the response
and action target. It returns exactly one of:

1. `FACTORIZATION`;
2. `MINIMAL_REFINEMENT`;
3. `CANDIDATE_REMAINDER`; or
4. `INCOMPLETE_CONTRACT`.

It was applied through one unchanged typed interface to:

- an exact-rational noisy quantum-like coherent-route table; and
- an exact-rational authenticated distributed-history table.

Both return `MINIMAL_REFINEMENT`. In each case, a formed history distinction
plus certified path provenance absorbs the base-record witness:

| fixture | base response gap | unrefined path-provenance bound | selected refinement | result |
|---|---:|---:|---|---|
| noisy quantum-like coherent route | total variation `4/5` | two path values | `formed_recombination_port + certified_route_id` | interface incomplete; no remainder |
| authenticated distributed history | total variation `3/4` | two path values | `authenticated_operation_dag + authenticated_layer_id` | interface incomplete; no remainder |

This is decision-relevant negative evidence. The pilot does not give Dynamic
Unity a cross-platform physical remainder. It gives the program a runnable
way to discover that a proposed remainder was only omitted formed provenance.

The probe passes `11/11` checks.

## The frozen object

The compiler receives the same `HistoryContract` on both fixtures:

```text
finite histories
finite intervention basis
complete finite outcome alphabet
base certified record
exact rational response distributions
action target
noninvertible reconciliation-path views
primitive record/provenance refinements
resource budget
constructor audit
```

A primitive refinement is admitted only when its contract says that it is:

- independently formed;
- future-independent;
- accessible inside the frozen observer class;
- frame-preserving;
- not derived from the target; and
- inside the resource budget.

The finite candidate class consists of every nonempty combination of admitted
primitives within the frozen budget. Both focal fixtures have six such
candidates. The class-construction digest excludes:

- response distributions;
- target actions; and
- the platform label.

The probe changes the target-action table and verifies that the frozen class
and its digest remain byte-identical. This is the required separation:

```text
target-independent candidate grammar
    !=
target-dependent selection of a sufficient member.
```

It is not a physical proof that a supplied refinement really is formed or
future-independent. Those are typed inputs whose warrant must come from the
platform experiment or protocol.

## Finite certificate logic

### Response factorization

For a selected refinement set `S`, each history receives the signature

\[
\bigl(R_0(h),R_s(h):s\in S\bigr).
\]

The response factors exactly when every pair with the same signature has the
same complete rational outcome distribution under every admitted
intervention. If it fails, the artifact carries:

- the two histories;
- the intervention;
- both complete outcome distributions;
- their total-variation gap; and
- an optimal signed complete-outcome score.

This is finite convex separation of two supplied distributions. It is not an
instrument-level robust-null theorem.

### Noninvertible path equalizer

Each reconciliation path supplies a many-to-one public view

\[
v_p:H\longrightarrow V.
\]

The task action `a(h)` factors through the public view and selected certified
path tags exactly when no equal `(view, tags)` key requires incompatible
actions.

Before tags are selected, paths become vertices of a conflict graph. Two
paths conflict when they can emit the same public view for histories requiring
different actions. If each path is internally decodable, the minimum
path-only provenance alphabet is the chromatic number of this finite graph.
The pilot enumerates the coloring exactly.

Both focal fixtures deliberately use noninjective path maps: four histories
are compressed into two public values along each path. Both need two
task-relative path-provenance values.

### Four verdicts

The decision rule is:

```text
invalid contract or empty nonbase admissible class
    -> INCOMPLETE_CONTRACT

base response and path action both factor
    -> FACTORIZATION

some frozen candidate factors
    -> MINIMAL_REFINEMENT

no frozen candidate factors
    -> CANDIDATE_REMAINDER
```

`MINIMAL_REFINEMENT` is minimized by the declared ordering

```text
(total scalar cost, primitive count, refinement IDs).
```

Every strictly prior candidate is retained in the artifact with its failed
factorization/path certificate. `CANDIDATE_REMAINDER` exhausts only the frozen
finite class and carries either a uniform witness fingerprint or one failure
fingerprint per candidate. It never reports an irreducible physical
remainder.

Synthetic controls exercise all four verdict branches.

## What the two fixtures do—and do not—show

### Quantum-like fixture

The ordinary channel is identical for all four histories. A coherent
recombination intervention gives the two history classes exact noisy
distributions `(9/10,1/10)` and `(1/10,9/10)`. Each route collapses four
histories to two public views, and the two routes reverse the view convention.

The base endpoint therefore fails both response factorization and
path-independent action. A formed recombination-port record repairs the first;
a certified route register repairs the second. A duplicated endpoint copy
repairs neither.

This is a finite quantum-like table patterned on the existing route-phase and
signed-port controls. It is not a CPTP/process-tensor reconstruction, a
proper-time instrument, or a laboratory model.

### Authenticated distributed fixture

The ordinary materialized endpoint is identical across serializable and
equivocating histories. A frozen audit challenge gives exact noisy
distributions `(19/20,1/20)` and `(1/5,4/5)`. Leaderless-gossip and BFT-layer
views are many-to-one and reuse route-local public labels in incompatible
ways.

An authenticated operation DAG repairs response factorization; an
authenticated layer record repairs path decoding. Replicating the terminal
value repairs neither.

Authentication and threshold signing are declared contract fields, not a
cryptographic implementation or adversarial protocol proof. The fixture
therefore establishes only a typed structural analogy.

## Important failures and boundaries

1. **No focal remainder.** Both proposed differences are absorbed by formed
   provenance inside the frozen class.
2. **Formation is supplied.** The compiler does not derive why either
   recombination ports or authenticated DAG records physically form.
3. **The grammar is nonexhaustive.** A `CANDIDATE_REMAINDER` would remain
   relative to its constructor class and budget.
4. **Exact stochastic equality only.** The pilot rejects every nonzero
   tolerance unless a quotient/closure rule is separately declared.
   Pairwise epsilon-closeness is not assumed transitive.
5. **No calibration or shot theorem.** Exact table separation is not a robust
   margin against SPAM, drift, leakage, adaptive attacks, or finite samples.
6. **Toy resource order.** “Cost two” means two declared unit-cost primitives,
   not energy, entropy, memory, latency, coherence, or signature bytes.
7. **No protocol dynamics.** The distributed fixture does not run gossip,
   Byzantine scheduling, rollback, or quorum formation.
8. **No physical quantum process.** The quantum-like fixture does not derive
   its table from operations and error channels.
9. **Schema invariance is bounded.** Swapping the platform metadata label
   leaves the result unchanged, and one compiler handles both tables. Human
   construction of the two tables can still hide a semantic mismatch.
10. **No novelty verdict.** Finite factorization, graph coloring, exact
    enumeration, and stochastic separation are known mathematics.

## Research consequence

The coupled `HC-DU-034B/036B` route is buildable at kernel level, but the
pilot strengthens the reason not to claim a result yet:

> In both first cross-platform specimens, the apparent history remainder is
> exactly an omitted formed-provenance problem.

The compiler is useful because this outcome is one of its intended products,
not a failed run. It converts “perhaps the record is insufficient” into a
replayable certificate naming the minimum supplied repair.

The next scientifically meaningful use should not add more toy refinements.
It should replace one table at a time:

1. derive the quantum response table from a frozen complete-outcome routed
   process instrument, including the strongest implementation-complete null;
2. derive the distributed table from a replayable authenticated
   DAG/BFT/adversarial schedule;
3. replace scalar unit cost with a declared resource vector and partial
   order;
4. add a calibrated convex-null margin and finite-shot gate; and
5. freeze the expanded refinement grammar before observing which candidate
   wins.

Only if no independently formed member of that richer frozen class factors
should the program report a class-relative physical-remainder candidate.
