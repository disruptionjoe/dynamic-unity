# Typed public-shadow descent and native-interface non-equivalence

## Result in plain English

There is a real common law across the five arenas, but it applies one level
later—and to a weaker object—than the strongest version of the conjecture
assumed.

Once a physical interface has actually formed a public record, every arena
can export the same kind of **public operational shadow**:

```text
current public record
    + admitted intervention
    -> complete selective event
    + next public record.
```

Those public shadows compose by one unchanged rule:

1. the local records must be jointly physically realizable;
2. their overlaps must refer to the same certified occurrences and
   provenance;
3. restrictions must preserve complete selective processes, not only values
   or endpoint probabilities;
4. the interfaces must coexist inside one observer and resource contract;
5. every admitted future public effect must factor through the joined public
   record; and
6. harmless refinement must preserve the result.

When those conditions hold, the joined record is an autonomous regional
public process. Hidden native degrees of freedom may remain. When a condition
fails, the first failure has a finite witness.

What does **not** descend is equally important:

> Equality or descent of the public shadows does not imply equality of the
> native physical interfaces that produced them.

The native objects are genuinely different:

- an Einstein--matter archive is a material field/apparatus construction;
- an AQFT measurement is a target--probe instrument plus external
  pointer/archive;
- a gauge record is a boundary-sector archive over an interior physical
  fibre;
- a QEC syndrome is a classical quotient deliberately leaving a protected
  logical fibre; and
- a Byzantine certificate is a copyable classical value whose meaning also
  depends on authenticated provenance and an adversary model.

There is an exact reason this difference cannot simply be flattened away.
A public classical record can be copied. An arbitrary noncommuting quantum
state cannot be nondestructively broadcast. Therefore no one classical
public-record object can simultaneously be:

- a nondisturbing extraction of every native quantum state;
- physically decodable back into the full native state for every admitted
  action; and
- freely broadcast as public data.

At least one of those properties must be given up. The common object is the
public shadow, while the smallest honest cross-arena architecture is:

\[
(\text{copyable public quotient},
 \text{native residual fibre},
 \text{frozen capability envelope}).
\]

That is the central result of this swing.

The unified theorem succeeds at the **public-shadow** level and fails as a
**native-interface identity** theorem. This is not a disappointment. It
identifies the exact bridge Dynamic Unity needed:

> Regional public reality can compose while quantum, geometric, material,
> provenance, and logical structure remain underneath it. Whether that
> underneath structure is operationally irrelevant, dually representable,
> or a physical remainder depends on the future action class.

## 5. No faithful classical type erasure

The exact cross-arena mismatch appears when “public record” is required to
mean one common native object.

### Theorem 2 — no nondisturbing broadcastable faithful public lift

Let a quantum native interface admit a family \(\mathcal S\) containing two
noncommuting density operators. There is no physical map to a classical
public record \(Q\) that is simultaneously:

1. **nondisturbing:** extraction preserves every input state in
   \(\mathcal S\);
2. **physically faithful for the full native action class:** public data can
   be physically decoded into a marginal operationally identical to the
   original state for every admitted native observable; and
3. **broadcastable:** the public data can be copied and decoded for two
   independent receivers.

### Proof

If all three properties held, extract \(Q\), copy it, and apply the two
decoders. The resulting bipartite channel would have both marginals equal to
the unknown input state for every state in \(\mathcal S\). It would broadcast
\(\mathcal S\).

The no-broadcasting theorem states that a set of quantum states can be
broadcast exactly only when the states commute. Because \(\mathcal S\)
contains a noncommuting pair, the assumed channel cannot exist.
\(\square\)

The smallest witness is

\[
\rho_0=|0\rangle\langle0|,
\qquad
\rho_+=|+\rangle\langle+|,
\qquad
[\rho_0,\rho_+]\ne0.
\]

The theorem does not forbid:

- a destructive measurement record;
- a record sufficient for a commuting action subalgebra;
- a syndrome sufficient for a frozen recovery class;
- public prediction from an ensemble-level tomographic data set;
- a quantum channel carrying the native state rather than a classical public
  record; or
- an operational shadow with a retained noncommutative fibre.

It forbids only the tempting universal flattening: an exact, nondisturbing,
copyable classical public record that also preserves all noncommutative
native capability.

### Corollary — the minimal honest cross-arena architecture

Any common regional architecture that includes both public classical
certificates and noncommuting quantum capability must retain at least:

\[
\boxed{
(Q,\mathcal F_q,H)
}
\]

where:

- \(Q\) is the copyable public quotient;
- \(\mathcal F_q\) is the native residual fibre over public value \(q\); and
- \(H\) is the frozen capability/action envelope that determines whether the
  fibre is screened or exposed.

This is why Dynamic Unity's center-plus-fibre architecture is not optional
bookkeeping. It is the minimum typed structure that avoids contradicting
no-broadcasting while allowing public composition.
