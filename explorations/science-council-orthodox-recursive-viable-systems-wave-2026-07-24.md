# Orthodox professor: recursive viable-systems wave

## Executive result

The recursive premise is scientifically useful only after three different
structures are separated:

```text
Beer S1-S5 functions inside one viable system
    != levels at which a complete viable-system organization repeats
    != physical finality, causal-depth, clock, or scale strata.
```

The earlier `stratified-finality-levels` and blockbuster-vision documents
run those structures together. Their System-4 language is a productive
decomposition of the self-authoring vision, but it is not yet a physical
construction. In particular, the phrase **"Beer viability theorem"** is too
strong for the cited transfer. Beer's paper presents a necessary-and-
sufficient cybernetic model of organizational viability. It does not supply
a mathematical theorem with a declared physical state space, disturbance
family, viable set, dynamics, and proof that can simply be instantiated in
Dynamic Unity.

The orthodox positive result is narrower and more useful:

> **An unknown finite number of viability-control levels can be discovered
> in a bounded dynamical system when every added level earns a held-out
> controlled-invariance advantage through explicit upward and downward maps,
> and pays an explicit complexity cost.**

I built an exact finite tournament with planted depths `m=0`, `m=1`, and
`m=2`. It recovered all three. The two-level specimen uses two locally viable
units, an upward load summary, and a downward resource reallocation. It
survives held-out disturbances that the one-level model cannot. The following
nulls receive no recursive-viability credit:

- passive persistence;
- a wrong hand-selected partition;
- a lookup table that memorizes training disturbances;
- a redundant third level;
- upward coarse-graining without downward control;
- recording every update opportunity;
- hidden record tags; and
- changing the bookkeeping resolution.

The probe passes `17/17` exact checks. The selected depths remain `0,1,2`
when the complexity multiplier is changed from `1` to `3` to `5`, under all
twenty-four relabelings of the four microvariables, and after each channel is
split into two half-load subchannels.

This conditionally realizes **depth discovery**. It does not establish that
the universe, a causal post, an observer, or a record clock is a recursive
viable system. It also supplies an orthodox counterexample to the unqualified
claim that an absent System 4 makes a system nonviable: the fixed controllers
are viable for the declared perturbation family without adaptation. System 4
becomes necessary only after a stronger changing-environment or open-ended
adaptation burden is specified.

The new premise therefore does **not** replace `HC-DU-031A` or
`HC-DU-011A`. It adds a common admission test that can be applied to their
future physical traces. No claim is banked or seeded.

### 1.2 Primary antecedents and scope

- [Beer, *The Viable System Model*](https://www.kybernetik.ch/dwn/Viable_System_Model.pdf)
  says each System One is itself a complete viable system and the topology
  repeats. The same source treats boundaries as arbitrary, recursion as
  nonunique, and one system as participating in multiple recursive chains.
  VSM alone therefore does not select one physical depth.
- [Ashby, requisite variety](https://ashby.info/Ashby-Mechanisms_of_intelligence.pdf)
  supplies a quantitative bound on regulation against disturbances. It is a
  necessary control constraint in its formal setting, not proof of autonomy,
  adaptation, or a five-function architecture.
- [Wilson, renormalization group](https://doi.org/10.1103/RevModPhys.47.773)
  supplies the conventional comparator for repeated coarse-graining, flows,
  fixed points, and relevant variables. RG recursion need not regulate an
  essential variable.
- [Aubin, survey of viability theory](https://doi.org/10.1137/0328044)
  supplies the orthodox mathematical object: trajectories satisfying state
  constraints and the largest controlled invariant or viable subset.
- [Hoel, Albantakis, and Tononi, causal emergence](https://doi.org/10.1073/pnas.1314922110)
  supplies a macro-information criterion. A macro description outperforming
  a micro description does not by itself supply a regulator.
- [Palacios et al., hierarchical self-organisation](https://doi.org/10.1016/j.jtbi.2019.110089)
  construct hierarchical Markov blankets when lower elements carry suitable
  prior beliefs about participating in a higher blanket. They explicitly do
  not claim that every coupled random dynamical system develops a hierarchy.
- [Jansma and Hoel, *Engineering Emergence*](https://arxiv.org/abs/2510.02649)
  provide a modern multiscale causal-contribution comparator. Causal
  contribution across scales is not yet recursive controlled viability.

