# Commercial scientist: dual primitive-record-clock wave

## Executive decision

The premise is worth one tightly bounded research product. It is not worth
another broad argument about whether a fundamental clock is philosophically
allowed.

The minimum product has three rungs:

1. propagation-correct an echo record;
2. compare physical record counts at a co-located departure and reunion; and
3. only for a surviving global-clock completion, run a closed-loop
   preferred-frame/boost assay.

The exact probe passes `11/11` checks. Its decision is:

- **Branch G-full, delay-only:** distance and message travel can explain raw
  separated-clock offsets, but not unequal accumulated records at reunion.
  If every observer appends one equivalent record on every global tick, both
  observers have the same count between shared endpoints.
- **Branch L plus an SR proper-time map:** it conditionally reproduces the
  reunion difference, but the map from record count to proper time and the
  Lorentzian signal cone remain assumptions, not derivations.
- **Branch G-gated:** it can reproduce the same reunion difference by
  admitting only a fraction `sqrt(1-beta^2)` of update opportunities for the
  moving observer, but that gate and the matching spatial response are the
  mechanism to derive. Fitting them is not an explanation.
- **Clock-QCA-like Branch G:** remains genuinely live. Arrighi, Facchini, and
  Forets prove exact discrete Lorentz covariance for a particular `1+1`
  Clock QW/QCA construction. That positive control prevents the narrow
  failure of G-full latency-only from being generalized to every globally
  updated discrete model. It does not yet supply DU's observer, append-only
  record, reunion-count, `3+1`, interaction, gravity, or unit maps.

The new premise therefore changes the immediate ordering. Before more
post-renormalization work, buy one small **record-clock arena** that reproduces
the exact Clock QCA, maps its operational records, and compares it against the
naive G-full and local-cadence controls. Stop quickly if “record” cannot be
made an invariant physical readout or if the exact covariance does not govern
the reunion observable.

No branch is banked or seeded.

### 3.2 Branch L: strongest version used

Each observer has an append-only sequence


The primitive cadence denominator is **one admitted local substrate
transition opportunity**, `delta lambda`, not global time. The deterministic
version appends one equivalent record per local opportunity. An asynchronous

local opportunity. Neither version supplies cross-observer synchronization.

Messages add edges from `send_i(q)` to `receive_j(q)`, producing a partial
causal order. Message counts can define radar coordinates after a

distance or speed.

For the reunion benchmark only I add the explicit conditional map

```text
N_i(E_0,E_1) = tau_i(E_0,E_1) / delta_tau.
```

That is the strongest conventional completion, not a derivation of
`tau_i`. It lets Branch L face G-full on a known target without pretending
the target emerged.

### 3.3 Branch G-full

There is one actual integer update index `K`. For every extant equivalent
observer and every update,

```text
N_i(K_0,K_1) = K_1 - K_0.
```

The cadence denominator is one global update opportunity, `delta K=1`.
Messages move by a declared causal propagation rule and may arrive after
different numbers of `K` updates. `K` is physical in the preferred-frame null.

This is the user's idea in its sharpest delay-only form. Its strength is that
it makes an exact prediction. Its problem is not that a clock was “smuggled
in”; the clock is openly posited. Its problem is that path-independent full
record addition leaves no mechanism for differential accumulated record
counts at reunion.

## 6. Synchronization, preferred-frame, and delay-only nulls

The positive and negative controls dispose of different confounds:

1. **Synchronization null.** Changing `epsilon` changes both one-way
   latencies and one-way speeds while preserving the local round trip. A
   remote offset is not an invariant discriminator.
2. **Distance/speed scale null.** Common rescaling `(D,c)->(aD,ac)` preserves
   every message count. Radar records alone cannot recover dimensional `c`.
3. **Delay-only null.** Exact propagation forward of the returned timestamp
   removes the apparent offset.
4. **Reunion null.** At shared endpoints, travel-time subtraction is zero and
   stored counts remain. G-full has no path variable left with which to
   produce the target difference.
5. **Preferred-frame null.** A physical G-full lattice with fixed propagation
   and no compensating dynamics predicts the exact `5/4` closed-loop
   anisotropy on the fixture.
6. **Overgeneralization null.** The exact `1+1` Clock QCA blocks the inference
   from that naive preferred-frame result to all globally stepped discrete
   dynamics. The next comparison must reproduce the construction's exact
   covariance notion rather than fit a Lorentz gate after the fact.

The probe does not test Doppler shift separately. A production arena should
add repeated pulse intervals because Doppler, simultaneity, and reunion proper
time are distinct observables.
