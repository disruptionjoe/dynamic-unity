# Screened effective physics and source-attribution rank

## Result in plain English

`HC-DU-035D` showed when a public regional process is genuinely screened from
its hidden quantum fibres. This swing asks the next North-Star question:

> Once the public process is screened, how much physics does it actually
> reconstruct?

The answer has three layers.

First, it reconstructs its own public causal order, public transition laws,
and every capability defined entirely inside that screened public action
class. This is exact operational equivalence.

Second, that result is not automatically a derivation of proper time,
geometry, fields, or microscopic sources. A hidden target may vary while
remaining inaccessible to every admitted public action. In that case it is
not an observer-accessible remainder in the frozen class.

Third, adding one fibre-to-public readout can make a hidden **total phase**
accessible without identifying what caused that phase. The smallest exact
control uses two source bits:

\[
x=(\tau,\chi)\in\mathbb F_2^2,
\]

where \(\tau\) represents a clock/proper-duration contribution and \(\chi\)
represents a field/path contribution. The first readout records only

\[
\phi=\tau+\chi.
\]

Then

\[
(\tau,\chi)=(0,1)
\quad\text{and}\quad
(\tau,\chi)=(1,0)
\]

produce the same public causal network, the same total phase, and the same
first-leak outcome while assigning opposite values to both source targets.

A second independently calibrated probe sensitive to \(\tau\) alone makes
the sensitivity matrix full rank and reconstructs both components. That is a
real repair, but it is an added physical interface and record. The first
record did not secretly contain the answer.

The main program correction is:

> Operational completeness is not source reconstruction. A nontrivial
> Dynamic Unity success requires an independently formed record that strictly
> compresses the physical process and transfers to held-out physical targets
> under source-independent calibration.

## Theorem 3 — source-attribution rank

Let \(X,Y,W\) be abelian groups, let

\[
S:X\to Y
\]

be the formed record/sensitivity map, and let

\[
T:X\to W
\]

be the held-out target.

Then there exists a decoder

\[
D:\operatorname{im}S\to W
\]

with

\[
T=D\circ S
\]

if and only if

\[
\ker S\subseteq\ker T.
\]

### Proof

If \(T=D\circ S\), then \(Sx=0\) implies \(Tx=D(0)=0\), so
\(\ker S\subseteq\ker T\).

Conversely, suppose \(\ker S\subseteq\ker T\). Define

\[
D(Sx)=Tx.
\]

If \(Sx=Sx'\), then \(x-x'\in\ker S\subseteq\ker T\), so \(Tx=Tx'\).
Thus \(D\) is well defined and \(T=D\circ S\). \(\square\)

For vector spaces, full source reconstruction is equivalent to injectivity
of \(S\), or full column rank of a sensitivity matrix.

This is ordinary quotient/factorization and observability mathematics. Its
scientific role here is to prevent a detected total phase from being
misreported as an attributed proper-time, metric, or field source.

## Nontrivial North-Star success criterion

A future reconstruction should count as scientifically substantive only if
all of the following hold:

1. **Independent formation.** The record and its interface are selected or
   physically formed without using the held-out target.
2. **Strict compression.** The record is smaller or structurally simpler than
   the complete action-indexed physical behavior it predicts.

   record definition or fit.

   fields, and nuisance channels are fixed independently of the target
   values.

   legitimate sources, boundaries, controllers, environments, and resources.
6. **Attribution rank.** The admitted sensitivity map has no target-changing
   null direction, or that null direction is returned as a finite remainder.
7. **No refitting.** The same decoder transfers across held-out regions,
   paths, sources, and interventions.

Without these conditions, “records reconstruct observer-accessible physics”
risks collapsing into a complete behavioral encoding of itself.
