# Commercial scientist: premise-free foundational wave

## Executive decision

I froze the Clock-QCA observer-record arena before inspecting any fifth-wave
peer output.

The highest-decision-value question is not yet whether the Clock QCA has a
beautiful covariant circuit. The primary source already establishes its scoped
covariance. The question that controls further spending is:

> Can a bounded candidate observer make an indefinitely durable, comparable
> cumulative record without using growing or externally supplied accessible
> state?

The exact answer is **no**. If values `0,...,T` must be perfectly
distinguishable at reunion, the accessible record space must have dimension at
least `T+1`. For `k` cells of local dimension `d`,

```text
d^k >= T + 1
k >= ceil(log_d(T + 1)).
```

That result does **not** rule out a translation-invariant QCA with an unbounded
lattice. It says that a physical record must price the part of that lattice,
environment, emitted wake, or other support that remains accessible to the
observer. Calling one three-state wire, one changing phase, or one global
circuit tick a cumulative record is not enough.

The bounded probe exhausts `5,912` finite reversible permutations, tests fixed
qutrit phase, bounded ternary memory, a growing spatial archive, scheduler
relabeling, fixed replay, held-out skipped events, and recorder-off controls.
It passes `16/16` deterministic checks.

The commercial disposition is:

> **Fund one two-work-unit, source-exact Clock-QCA extraction stage. Do not
> fund observer ontology, recursive organization, `3+1`, gravity, or
> cosmology unless a candidate record with explicitly charged support
> survives the declared covariance and rescheduling quotients.**

No claim or prediction is banked or seeded.

`|X|=d^k` for `k` `d`-level cells. A reversible autonomous evolution is a
permutation `U:X->X`.

For a quantum record, the accessible record Hilbert space is `H_R` with
dimension `d^k`. Perfectly readable values occupy mutually orthogonal record
supports.

The growing-spatial rival uses a finite active prefix of an otherwise

## 4. Exact theorem

### 4.1 Finite classical record bound

Let one deterministic reversible trajectory be

```text
x_0, x_1, ..., x_T
```

and suppose `R(x_t)=t` for every `t=0,...,T`. Then all `x_t` must be distinct,
because a function cannot assign different readable values to the same state.
Therefore

```text
|X| >= T + 1.
```

For `k` cells of local dimension `d`, `|X|=d^k`, hence

```text
k >= ceil(log_d(T+1)).
```

Reversibility is stronger than the proof needs, but it makes the recurrence
and QCA comparison explicit. The probe enumerates every permutation for
`q=2,...,7`; the longest nonrepeating orbit has exactly `q` states and at most
`q-1` strict increments.

### 4.2 Perfect quantum record bound

If record values are perfectly distinguishable at reunion, the corresponding
record supports must be mutually orthogonal. `T+1` readable values therefore
require

```text
dim(H_R) >= T + 1.
```

For `k` `d`-level cells the same cell bound follows. This is a
distinguishability statement, not a measurement-dynamics or decoherence
model.

### 4.3 Count memory is not an event archive

The logarithmic bound prices the current cumulative count. A compact counter
can overwrite digits and still identify the present count before wraparound.

A dedicated unary event archive is stronger: each event occupies fresh
support and the old prefix remains. In the implemented fixture it uses `T`
cells for `T` events.

The research must say which object it needs:

- current count;
- recoverable event history;
- carried detector record;
- immutable provenance; or
- all of the above.

Calling each one “a record” hides very different costs.

### 4.4 Correct scope for QCA

A QCA can have a finite local alphabet and an unbounded global lattice. The
theorem therefore does not say “finite wire dimension forbids records.”

It says:

> A fixed bounded observer subsystem cannot hold an indefinitely
> distinguishable cumulative record unless its accessible state grows or it
> accesses charged external support.

If the Clock QCA leaves a wake, distributes markers, emits correlations, or
uses an ever larger region, that is a viable path. It makes system boundary,
locality, access at reunion, and covariance of the archive load-bearing
questions.
