# Physical Descent from Selected Apparatus to North-Star Adjudication

## Decision

The next ten-swing campaign is one conditional funnel:

```text
physical apparatus class
  -> admissible completion directions
  -> uniform descent theorem or smallest lawful counterexample
  -> no-refit transfer
  -> complete relational probability
  -> equivariant interface theorem
  -> field/direct-action first leak
  -> formation/provenance intervention
  -> regional composition
  -> North-Star theorem, remainder, prediction, or exact stop
```

Only Swing 1 is executable. Swings 2--10 are prepared but blocked by typed
returns. This is not ten permission slips and not ten independent bets.

The campaign advances Dynamic Unity's North Star:

> Determine whether independently selected, observer-indexed certified causal
> records reconstruct all observer-accessible time, geometry, fields, and
> capability, or leave a finite physical remainder.

`HC-DU-151` supplies the immediate opening. In a linear Gaussian field, a
common apparatus completion changes the relative phase by

\[
\delta\Delta I=\langle T_1-T_0,GK\rangle .
\]

The open physical question is no longer whether arbitrary completions can
change a phase. They can. It is whether an actual physical apparatus model
selects an admissible completion class \(K_{\rm phys}\) on which this pairing
vanishes, is bounded, or remains detectably nonzero.

This scaffold earns no scientific grade and assumes no preferred foliation,
record ontology, direct-action ontology, new phase correction, or hardware
access.

**Activation.** Executable now as
`PDSI-01-PHYSICAL-APPARATUS-CLASS-EXTRACTION`.

boundary conditions, conservation closure, approximation order, response
kernel, and stated heavy/homogeneous limits. Classify each as selected,
assumed, calibrated, neglected, or outside scope. Do not simulate.

**Positive.** A source-warranted class \(K_{\rm phys}\), or a finite family of
classes, with a declared topology/norm and response domain.

**Cheapest kill.** The paper specifies only one nominal apparatus trajectory

`SELECTED_PHYSICAL_CLASS`, `PARTIAL_PHYSICAL_TYPING`, or
`UNSELECTED_INTERFACE`.

Swing 6 or `NO_READY_SUCCESSOR`.

## Approach-selection rule for every future swing

Before execution, the lead must compare at least three methods:

1. direct proof or symmetry reduction;
2. minimal counterfactual/counterexample; and
3. bounded computation or source audit.

Choose by:

\[
\frac{
  \text{expected dependency reduction}
  \times
  \text{scope transfer}
  \times
  \text{falsifier strength}
}{
  \text{new assumptions}
  \times
  \text{refit freedom}
  \times
  \text{execution cost}
}.
\]

If direct analysis already decides the boundary, computation is disallowed.
If a local computation cannot produce new learning before external hardware,
the build is disallowed. If primary literature already proves or absorbs the
claim, record the collision and stop.
