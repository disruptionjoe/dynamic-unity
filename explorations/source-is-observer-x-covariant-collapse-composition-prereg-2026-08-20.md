# Source-is-observer × covariant-finality-collapse — the composition pre-registration

Two DU-owned products were each driven to an honest verdict **in isolation**. Neither file composes
them, and the composition exposes a property tension that could kill, weaken, or sharpen the covariant
objective-collapse prize. This file freezes the question **before** any probe, so the answer is graded
against pre-declared outcomes and cannot be back-fit.

## The question (one sentence)

The new-physics leg of covariant finality collapse (**PRED-DU-002**) is gated on the finality being a
**real sharp threshold** = **genuine becoming**; the source-is-observer result says genuine becoming
requires **exactly one external involution σ** and is **observer-relative** — so does the σ that makes
#2 predictive **preserve** the two properties #2's third position is built on (**covariant** and
**objective = observer-independent**), or does the predictive version of #2 **slide into relational-QM**
(observer-relative ⇒ not the objective collapse it advertises) **or break covariance** (the bit must be
frame-dependent to select outcomes)?

## Why neither file closes it (the gap is structural, not an oversight)

- **#2 was scoped to the covariance of the update.** Its kill *deliberately* holds Born and
  single-outcome inherited-OPEN and grades the as-built account **block-structural / B-theory, no
  becoming, no prediction**. Its new physics (PRED-DU-002) is a SEAM, *doubly-gated on the unbuilt
  mode-issuance threshold* — so #2 never had to say what supplies the threshold.
- **#1 was scoped to what supplies the threshold.** It found the threshold-as-genuine-becoming is a
  CONDITIONAL-THEOREM: a fully source-internal mint is a Kleene quine (disclosure); becoming needs the
  external Krein σ as its L2, and the #1 kill names the result precisely — **"becoming on an external
  orientation, not source-internal … observer-relative, not source-INTERNAL."**
- **The seam:** #2's antecedent is #1's conclusion, and #1's conclusion carries a property (**observer-
  relative**) that is the *negation* of the property #2 leans on to be distinct from RQM/QBism
  (**observer-independent**). The two products were correct apart and may be in tension together.

## The two objects, with the exact properties in tension

| | Source-is-observer (#1) | Covariant finality collapse (#2) |
|---|---|---|
| Load-bearing datum | the external involution **σ** (one Z/2 Krein sign, Gödel-independent, R7) | the finality fact / H¹ section over the causal poset |
| "External/objective" sense | **source-external** — the inside provably cannot mint it (Kleene) | **observer-independent** — a fact about the block, true in every frame |
| Becoming | **required**, and **observer-relative** (first-person underivable, third-person computable) | **not earned** as-built (block-structural); **required** for PRED-DU-002 |
| Covariance | not addressed | **yes** — typed on J⁺, foliation-not-smuggled (computed) |

The crux is that **"source-external" (#1) and "observer-independent" (#2) are not the same predicate**,
and the whole composition turns on whether they can be jointly held by one σ.

## The steelman (why "all three" might survive)

The optimistic reading, stated at full strength so the kill has a real target: **σ is a single global
Z/2 external orientation, shared by all observers, frame-independent by construction** (a Krein sign is
not tied to a slice, and there is exactly one of it — CPRED-03's "exactly one external bit," partly
Lean-proved as `no_invariant_valuation`). On this reading:

- **Covariance survives:** one global frame-independent bit adds no "when," no slice — the redundancy-
  count trigger stays the covariant invariant #2 needs.
- **Objectivity survives in a weakened, still-real form:** the finality fact is observer-independent
  *modulo one external orienting convention* shared by everyone — which is **not** RQM's per-agent,
  agent-indexed relativity. "Objective up to one external bit" is a genuine third-position property, not
  a collapse into QBism.

If the steelman holds, PRED-DU-002 survives — but its honest headline downgrades from **"covariant
objective collapse"** to **"covariant, objective-up-to-one-external-orientation collapse,"** and that
downgrade must be stated loudly, not buried.

## The discriminator (the one thing to characterize)

**Characterize σ's indexing.** Is the external involution that #1 requires:

- **(G) one global, shared, frame-independent Z/2** — the same orientation for every observer in every
  frame; or
- **(I) observer-indexed** — a bit each observer supplies relative to their own locus (the RQM shape)?

Everything follows from (G) vs (I). The sub-checks that pin it:

1. **Frame-independence.** Does σ enter any outcome-relevant step through a slice/foliation, or only as a
   global constant? (If it needs a slice to *do work*, covariance breaks — same failure mode as #2's
   locality-of-update proviso.)
2. **Observer-independence.** Is there **one** σ for the whole causal set, or one **per** observer's J⁻(p)?
   #1's "exactly one external bit" (CPRED-03) argues for one; the #1 kill's "observer-relative" phrasing
   argues it is relative *to the observer as the external locus*. These must be reconciled, not assumed.
3. **Does σ actually touch outcome-selection, or only orientation?** #1's σ fires the *becoming-diagonal*
   (which mode actualizes / its orientation). If that is the same lever as Born/single-outcome selection,
   the composition is gated on those OPEN legs; if σ sets only a global orientation and outcome-selection
   is a separate (still-open) mechanism, the composition can be run at STRUCTURAL grade without resolving
   Born. Deciding which is itself part of the test.

## Pre-registered lethal outcomes (declare before building)

- **L1 — COLLAPSES-TO-RELATIONAL.** The becoming-enabling σ is **necessarily observer-indexed** (I): the
  external orientation cannot be one global shared bit without losing its becoming role. Then PRED-DU-002's
  becoming is **relational**, the "objective" property is lost, and #2's third position **dissolves into
  RQM-with-covariant-dressing.** *Consequence:* "covariant objective collapse" is refuted as advertised;
  the predictive #2 is a relational interpretation. A clean, bankable negative.
- **L2 — COVARIANCE-BREAKS.** σ can be global, but to do real **outcome-selecting** work it must be read
  on a slice / frame-dependent structure. Then PRED-DU-002 inherits the standard relativistic-collapse
  tension (**DEVIATION-BUT-NON-COVARIANT**) — the same Sorkin/locality failure #2's kill already priced,
  now sourced from the σ side. *Consequence:* the covariance prize is lost the moment the account becomes
  predictive.
- **SURVIVES (weakened) — OBJECTIVE-UP-TO-ONE-BIT.** σ is (G): one global, shared, frame-independent
  external orientation. PRED-DU-002 survives as a **covariant, objective-modulo-one-external-orientation**
  collapse candidate. *Consequence:* the prize stands but the headline is honestly downgraded, and the
  residual open leg is exactly outcome-selection (Born/single-outcome), where the real stochastic-
  covariance tension still lives — so even SURVIVES is a SEAM, not a theorem.

At most one fires. The value is that **all three are worth having**: L1 and L2 are clean kills that
retire an over-claim; SURVIVES is a real (bounded) advance with an honest downgrade.

## Positive controls (so the verdict is informative, not rigged)

Run the identical indexing analysis on two reference systems whose answers are known:

- **QM-with-no-collapse (pure block / decoherent histories):** should need **no** external bit, and come
  out trivially objective + covariant (no becoming to source). If the test reports a tension here, it is
  over-firing — the discriminator is broken.
- **Standard CSL:** its noise field is known **frame-dependent** → should trip **L2 (covariance breaks)**.
  If the test does not flag CSL, it cannot detect L2 and the DU verdict is uninformative.

A test that separates these two controls (no-tension for the block, L2 for CSL) and *then* reads DU is
informative; one that returns the same verdict everywhere is not.

## Scope fences (honesty discipline)

- **σ untouched (R7).** This composition does not re-derive, move, or externalize σ; it only asks whether
  σ-as-already-accepted preserves #2's two properties. The GU-owned σ = w₁ identification is **consumed as
  substrate, not hardened here** (per the 2026-07-21 ownership split; see the source-is-observer note).
- **Born / single-outcome stay inherited-OPEN.** The complete answer to sub-check 3 may be gated on them.
  The structural version (does a global external orientation preserve frame- and observer-independence)
  can be graded without resolving Born; a full predictive answer cannot. Say which grade any future result
  reaches.
- **Not seeded.** PRED-DU-002 remains a SEAM. Nothing here promotes it; a SURVIVES outcome would *add the
  observer-independence hardening obligation* to its checklist, not seed it.
