# Next Five Swings: Branch-Safe Knowledge Sequence

## Plain-English conclusion

The best next sequence is a funnel, not a fan-out.

Swing 1 finishes the open cross-arena adjudication. Swing 2 uses that result
to select exactly one successor from only the branches whose reopen conditions
are satisfied. Swing 3 takes the smallest decisive constructive/adversarial
shot at that winner. Swing 4 asks whether the result survives a second serious
physical arena and the strongest known absorber. Swing 5 forces a durable
verdict: theorem, exact non-unification, finite discriminator, explicit
external boundary, or clean portfolio reset.

This preserves ambition without pretending that the answer to Swing 1 is
already known. Only `CURRENT-RESEARCH.yaml` can activate a position.

## 1. Ten-lens Triple Diamond convergence

The lenses are method selectors, not scientific voters.

| lens | contribution to the sequence |
|---|---|
| Category theorist | Make the first output a factorization/descent theorem or the first failed square, not another analogy. |
| Counterfactual statistician | Compare matched worlds and choose later work by expected decision-changing information. |
| Quantum-foundations theorist | Freeze complete instruments and multi-time processes; never infer history from endpoints. |
| AQFT/relativity theorist | Keep locality, covariance, foliation, algebra, and observer access separately typed. |
| Distributed-systems theorist | Use consensus and DAGs as ground-truth controls only after a meaning-preserving physical adapter exists. |

| Inverse-problems/control theorist | Express reconstruction and selection through fibres, kernels, observability, and held-out actions. |
| Complexity/emergence theorist | Reject unselected order parameters, scaling families, thresholds, and “emergence” as mechanisms. |
| Experimentalist/metrologist | Demand one finite matched-budget discriminator and state what is actually measured. |
| Overbuild-protection champion | Do not build a new host, simulator, hardware bridge, or registry when proof, counterexample, or literature decides first. |

### Diamond 1 — the real problem

The program does not currently lack candidate ideas. It lacks a justified
transition from the completed control stack to one next scientific commitment.
Old branches have explicit stop/reopen rules, and the live cross-arena action
must be allowed to change the dependency map.

### Diamond 2 — the selected architecture

```text
branch adjudication
  -> reopener-gated portfolio choice
  -> minimum decisive attack
  -> cross-arena and literature collision
  -> finite consequence or portfolio reset
```

Each swing may use parallel internal arms, but it returns one synthesis and
activates at most one successor.

### Diamond 3 — assurance

Every position freezes:

- exact question and typed objects;
- completed evidence consumed;
- strongest absorber;
- smallest discriminator;
- current and maximum grade;
- cheapest kill and retreat cost;
- local-computation boundary;
- durable return; and
- the one dependency it changes.

An adverse result shortens or redirects the sequence. It never triggers
another fitted host.

```text

```

### Exact question

resource, and target matching, what does a preferred foliation change relative
to a causal-partial-order description?

### Orchestration

Freeze the one ledger already named in the live execution packet, then run
three arms:

1. serious global-leaf positive representation;
2. matched causal-partial-order control; and
3. independently selected physical record arena.

Synthesize only after each arm returns the quotient, first witness, and
strongest absorber.

### Stops

- Stop the exactly compensated branch on `NO_EXCESS_CONTENT`.
- Route observable leaf dependence to a separately frozen leaking branch.

- Do not spend another swing restating generic factorization.

### Maximum grade

Grade 4: scoped branch-invariant theorem, necessity/dependency result, exact
non-unification, or clean no-excess theorem. No new physics is available from
an exactly compensated premise.

## 4. Position 2 — reopener-gated successor tournament

### Exact question

Given Position 1's dependency diff, which single open program can now change
the North-Star verdict most, locally and without repeating an absorber?

### Hard gate before scoring

| candidate class | may enter only if |
|---|---|
| Branch-invariant CCR kernel | Position 1 returns a nontrivial kernel, dependency theorem, or exact no-excess statement with a formal delta still unbanked. |
| Physical interface selection | A new independent antecedent fixes write/access, or an exact archive-relocation breaker appears. Existing fitted hosts do not qualify. |
| Covariant finality dynamics | An explicit local covariant generator, state space, coefficient-selection route, positivity, conservation, and no-signalling contract exist. |
| Corrected mathematical moonshot | A self-contained proposition survives the parity counterexample and does not borrow unearned GU physical externality. |
| Lawful physical reconstruction | A new law, target, boundary class, or finite-regulator term changes the already closed `3+1` packet and beats the Einstein absorber. |
| New route from Position 1 | Position 1 identifies the exact changed dependency, smallest discriminator, and maximum grade. |

The separately prepared paper candidate is not a scientific tournament arm.

### Scoring after the hard gate

Score each admitted arm on:

1. North-Star dependency removed;
2. expected decision-changing information;
3. local decidability before hardware;
4. novelty/profundity ceiling;
5. reuse across serious physical arenas;
6. strength and cost of the cheapest kill; and
7. external-dependency penalty.

Select one. If none passes its hard gate, return:

```text
NO_READY_SCIENTIFIC_SUCCESSOR
```

and perform a portfolio reset rather than inventing work.

### Maximum grade

Method/priority result only. Position 2 cannot promote a scientific claim.

## 5. Position 3 — minimum decisive attack

### Exact question

What is the smallest exact construction or counterexample that decides the
selected successor's load-bearing claim?

### Orchestration

Run three bounded arms against one frozen statement:

1. **Builder:** prove or construct the strongest positive at the smallest
   honest scope.
2. **Killer:** search first for the minimum counterexample, representation
   dependence, target coding, omitted interface, or empty fibre.
3. **Source auditor:** reconstruct the closest primary-source theorem and
   identify what is known, supplied, selected, or absent.

The chairman reconciles mechanisms, not headline votes.

### Local-model gate

Use symbolic algebra or a deterministic finite probe only when it finds an
exact witness or validates a proof boundary unavailable by inspection. Stop
before simulation, scale-up, or hardware if no new learning appears.

### Required returns

```text
SCOPED_POSITIVE_THEOREM
EXACT_COUNTEREXAMPLE
MECHANISM_CONSTRUCTED
REPRESENTATION_DEPENDENT
ABSORBED_BY_KNOWN_RESULT
INCOMPLETE_PHYSICAL_CONTRACT
BRANCH_KILLED
```

### Maximum grade

Normally grade 4. Grade 5 is reserved for a finite discriminator that survives
the full admitted standard-physics completion class, which Position 3 alone
will rarely establish.

## 6. Position 4 — cross-arena and novelty collision

### Exact question

Does Position 3's statement retain the same meaning and truth conditions in a
second serious physical arena, and what survives the strongest literature
absorber?

### Orchestration

1. Reuse Position 3's definitions unchanged.
2. Choose a second arena because it stresses the load-bearing premise—not
   because it shares vocabulary.
3. Carry a distributed or cryptographic control only when every theorem
   assumption has a physical counterpart.
4. Run a primary-source collision against the closest existing theorem,
   no-go, reconstruction, or phenomenology.
5. Locate the first failed premise instead of averaging incompatible results.

Candidate physical arenas include localized AQFT, gauge boundaries, QEC,
quantum clocks/process tensors, causal action/CFS, and lawful relativistic
inverse problems. Closed arenas reopen only when their declared new premise is
present.

### Required returns

```text
CROSS_ARENA_INVARIANT
SCOPED_ARENA_SPECIFIC_THEOREM
EXACT_NON_UNIFICATION
SCOPE_NARROWED
FULLY_ABSORBED
NOVEL_DELTA_SURVIVES
```

### Stop

Do not add a third arena when the first two already identify the failed
premise or full absorber.

## 7. Position 5 — finite consequence or portfolio reset

### Exact question

What is the strongest finite consequence honestly earned by Positions 1–4,
and what should Dynamic Unity do next because of it?

### Orchestration

Compile in parallel:

1. theorem/no-go statement and assumption boundary;
2. finite observable or held-out intervention, if one exists;
3. matched standard-physics null and confound ledger;
4. implementation-completeness and local-versus-external boundary;
5. novelty/publishability collision; and
6. successor portfolio update.

### Required returns

```text
SCOPED_THEOREM_BANKED
EXACT_NON_UNIFICATION_BANKED
FINITE_DISCRIMINATOR_LOCKED
IMPLEMENTATION_COMPLETE_EXTERNAL_BOUNDARY
NO_EXCESS_PORTFOLIO_RESET
ONE_NEW_PROGRAM_ACTIVATED
```

If the first decision-changing evidence requires unavailable external
hardware, lock the prediction and record one awareness note. Do not keep
building toward the wall or repeatedly revisit providers.

If no finite excess survives, a clean no-go, boundary theorem, or explicit
portfolio reset is the success condition.

### Maximum grade

Grade 5 only for a finite discriminator surviving the complete admitted
physical completion class. Otherwise bank the exact grade-3/4 theorem,
non-unification, or no-go that was actually earned.

## 8. Cross-swing state discipline

After each executed position:

1. bank one dated result or clean null;
2. update `CURRENT-RESEARCH.yaml` and increment its revision;
3. leave exactly one executable action;
4. remove killed candidates from later positions;
5. preserve parked branches unless their exact reopener fired;
6. rerun the schema, semantic governance, cold-start, link, and approach
   regressions; and
7. stop the series early if the North-Star decision is already forced.

## 9. Why this sequence is the best current bet

It concentrates effort where uncertainty actually lives. The repository has
already learned that another host, another consensus analogy, another
preferred-frame existence discussion, another `3+1` variant with the same
boundary class, or another unselected threshold will mostly reproduce known
absorbers.

The sequence therefore spends one swing deciding the branch, one selecting
the worthy successor, two trying to prove and break it, and one forcing a
usable scientific disposition. It preserves the blockbuster ceiling while
making every negative result shorten the path.
