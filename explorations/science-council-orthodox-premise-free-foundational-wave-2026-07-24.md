### 3.4 Exact memory theorem

Let an observer record the exact elapsed count `n∈{0,...,T}` in states
`rho_n`. If a single measurement reads each `n` with certainty, the supports
of the `rho_n` are mutually orthogonal. Therefore:

```text
dim(H_record) >= T+1.
```

This is achieved by a count register with basis
`|0>,...,|T>`.

If the system instead stores `T` independently variable binary facts, every
string in `{0,1}^T` must be distinguishable. Therefore:

```text
dim(H_record) >= 2^T.
```

These are different burdens. A monotone elapsed counter is not automatically
a log of `T` independent happenings.

A fixed `d`-state cyclic counter supplies the simplest rival:

```text
R(n)=n mod d=R(n+d).
```

It is an exact finite clock phase but not an unbounded elapsed record.
