# Next Ten Swings: Selected Physical Record to North-Star Adjudication

## Plain-English result

The next campaign should try to carry **one independently selected physical
record** all the way through the North-Star chain:

```text
antecedent physics selects an operational interface
  -> a distinction is physically written and retained
  -> an observer can access and certify it under a declared rival class
  -> the record restricts a nonempty class of lawful physical completions
  -> a held-out time, geometry, field, or capability target is reconstructed
     OR an exact physical remainder survives
```

The campaign is a **gated funnel**, not ten independent bets. The ten positions
are prepared now, but only Swing 1 may be activated by the next explicit
authorization. Each later swing becomes eligible only when the prior swing
returns the prerequisite it needs. A clean no-selector, correlation-only,
empty-fibre, law-only, or absorption result can close the campaign early.

That is not failure. It converts the North Star into a precise theorem or
obstruction rather than keeping a favored physical arena alive by adding
interfaces after the fact.

This file does not activate the campaign. `CURRENT-RESEARCH.yaml` remains the
only live routing authority.

## 1. What this campaign does not repeat

Dynamic Unity already knows several things that a fresh agent could otherwise
waste swings rediscovering:

- [`HC-DU-033F`](antecedent-relative-physical-are-selector-and-minimum-premise-theorem-2026-07-26.md)
  gives the general antecedent-relative selector condition. An antecedent
  point-selects an interface exactly when its fibre is constant under the
  interface map; otherwise the honest return is an image, orbit, or plural
  family.
- [`HC-DU-033H`](localized-aqft-source-probe-pointer-archive-selection-ladder-2026-07-26.md)
  shows that localized AQFT dynamics can select an induction/realizability
  family relative to a supplied architecture without selecting the particular
  instrument, pointer, archive, or access boundary.
- [`HC-DU-068`](finite-time-infrared-memory-typed-record-reopener-audit-2026-07-28.md)
  shows that finite-time infrared memory physically forms a soft carrier and
  conditionally selects part of a dressing only after a frame is supplied.
  The bounded detector, resolution quotient, access algebra, archive, action
  class, certification rule, and held-out target remain supplied.
- [`HC-DU-073`](causal-priority-intervention-ladder-and-process-transfer-2026-07-28.md)
  shows that equal terminal states do not orient formation. In its frozen
  direct-arrow/common-cause class, both one-sided pre-formation interventions
  are jointly necessary and sufficient; the process direction is an
  operational result, not an ontological verdict.
- State-only record functionals, unselected order parameters, terminal
  copying, dephasing, redundancy, confidence, and endpoint agreement cannot
  fill the missing typed interfaces by relabeling.

Therefore Swing 1 is **not** another generic record metric, interface-selector
audit, infrared-memory continuation, or AQFT instrument construction. A prior
candidate can re-enter only with a new antecedent, theorem, or physical
construction that satisfies its exact reopener.

## 2. Campaign invariant

Every candidate must preserve this typed separation:

```text
physical antecedent A
candidate interface family I
selected interface or selected equivalence class I*
complete process P with intervention ports
write/provenance map W
observer-access map X
certificate/finality rule C
lawful completion class Mphys / gauge G
certified record R
independently escrowed target T
action/resource envelope E
```

No object may silently do two jobs. In particular:

- `T` may not select `I*` and then count as held out;
- a gauge choice may not count as a detector;
- a detector may not count as an archive;
- an archive value may not count as occurrence provenance;
- access may not count as certification;
- certification may not count as global or irreversible finality;
- a lawful completion filter may not count as record information;
- agreement under one action class may not count as ontological identity; and
- adding an omitted environment, controller, resource, or observer after a
  failure is contract retyping, not record refinement.

### Target escrow

Every candidate admitted by Swing 1 must name one held-out target before the
candidate interface is assessed. The target may be:

- an observer-accessible time quantity;
- a geometric quantity;
- a field or future-response quantity; or
- an action/capability quantity.

The selection, formation, access, and certification arms may know the **type**
of the target but may not inspect its values or optimize the interface against
it. If the target must change, that is a new campaign contract.

### Hardware and local-model boundary

External hardware is unavailable by default. A swing may use symbolic or
deterministic local computation only when it:

1. finds an exact counterexample;
2. validates a proof boundary;
3. checks a finite rank, kernel, orbit, or sample-complexity claim; or
4. produces decision-changing learning before any hardware boundary.

If the first new information requires external hardware, the campaign records
one awareness note and takes a local alternative. It does not build toward a
wall merely to reproduce a literature result.

### Diamond 1 — discover the real problem

The missing object is not “a record” in the abstract. The missing result is a
physical antecedent that selects enough of the operational interface to make a
record noncircular, while leaving a genuinely independent target to test.

The high-value questions are:

1. Is there a new physical premise that changes the already known selector
   fibre?
2. Does it select a usable interface or only an admissible family?
3. Can that interface be realized locally and accessed finitely?
4. Does a real write occur, with provenance and retention?
5. Does the result restrict lawful completions beyond what the law already
   fixes?

- the exact proposition and typed objects;

- the cheapest kill and retreat cost;

Every positive must survive a mandatory positive control and a mandatory
hostile control. Every negative must show that the tested class was rich enough
