# Philosopher of science: primitive record-rate wave

## Executive judgment

The clock premise is legitimate, but it divides into materially different
models:

```text
G-full    one record for every observer at every global tick K
G-gated   K offers an opportunity; an additional law admits or skips a record
G-hidden  K orders updates, but its physical or gauge status is unresolved
```

At shared endpoints, `G-full` entails

```text
Delta n_A = Delta K = Delta n_B.
```

So an unequal `20:16` reunion rejects `G-full` and a delay-only account.
`G-gated` fits it, but `4,845` four-skip histories share that endpoint count;
the gate, not the clock, carries the explanation.

Every finite causal record DAG also admits a topological `K` plus arbitrary
gates that reproduce it. A finite trace therefore does not identify L against
unrestricted `G-gated` or `G-hidden`. Hidden does not mean gauge: gauge status
requires invariance of the complete observable dynamics under rescheduling.
The probe realizes both an invariant kernel (`1/2,1/2`) and a leaking kernel
(`3/4,1/4`). No Lorentzian metric, gate law, physical `c`, or observer
ontology is derived. No claim is banked or seeded.

### 3.3 Strongest coherent Branch L

Branch L is an asynchronous causal record graph. Each observer has a chain

```text
o_0 ≺ o_1 ≺ ... ≺ o_n
```

and uses the same dimensionless local transition kernel from an admitted
predecessor state to the next record. Its cadence denominator is **one local
update opportunity indexed by the preceding record state**. This gives a
common rule without global time. It does not give a physical rate.

Defining a Poisson hazard “per unit proper time” would be coherent only after
proper time exists; it would not derive proper time. The present version
therefore stops at order and count. Knuth–Bahrenyi coordinated-chain
valuations and causal-set order-plus-number reconstruction show possible
added bridges, but their assumptions are not consequences of local cadence.

### 3.4 Strongest coherent Branch G

Branch G declares one primitive update interval `delta_K` and index `K`.
Its cadence denominator is **one global update interval**.

- `G-full`: every observer adds one equivalent record per `K`.
- `G-gated`: every observer receives an opportunity per `K`; a separate
  local/field/motion rule admits, skips, or weights the record.
- `G-hidden`: a total scheduler orders spacelike updates. It is operationally
  nonidentified if present data do not reveal it, gauge only if the full law
  factors through a rescheduling quotient, and hidden physical if it enters
  future probabilities.

The exact Clock QW/QCA antecedent shows that a global circuit clock and a
specific exact discrete covariance notion can coexist in `1+1` dimensions.
It does not show that arbitrary `G-full` records, arbitrary gating, or a
regular preferred slicing reproduces special relativity.

### 5.2 Finite trace compilation

Let `D` be any finite acyclic graph in `O`.

1. Every finite DAG has at least one topological order.
2. Use that order as global indices `K=0,...,|D|-1`.
3. At each `K`, offer every observer an update opportunity.
4. Admit a record only for the observer labels attached to that event.
5. Preserve all causal/message edges.

Projection back to local observer chains exactly recovers `D`. Thus every
finite Branch-L trace has an unrestricted `G-gated` realization. Forgetting
`K` in any `G-gated` realization returns a causal graph and local chains.

This is an **observed-trace equivalence**, not equality of every stochastic
law. Repeated held-out trials can distinguish constrained distributions.
Arbitrary gating defeats identification precisely because it can compile
each trace after the fact.

## 6. Synchronization, preferred-frame, and delay-only nulls

### Synchronization null

The `epsilon` family preserves all local echo records while trading B-clock
offset against asymmetric one-way latency. Radar time is a conventionally
coordinated assignment unless an additional synchronization standard or
one-way calibration is supplied.

### Reslicing/preferred-frame null

Exchanging the two spacelike events in the causal diamond changes `K` but not
the observed partial order. If any later probability changes, `K` is
preferred physical structure. If every physical quantity is invariant, the
two schedules can be quotiented. Merely failing to observe `K` in the
diamond establishes neither result.

The Poisson-sprinkling theorem supplies one scoped no-direction antecedent;
the Clock QCA supplies one scoped exact-covariance antecedent. A regular
global update lattice inherits neither property automatically.

### Nonuniform-cadence null

Early, periodic, and late B gates share the same reunion total and differ at
the intermediate count. Endpoint agreement cannot identify a constant gate,
a Lorentz gate, or any microscopic cadence history.

### Delay-only null

For the echo:

```text
raw round trip - modeled forward and return delay = 14 - (d_AB+d_BA) = 0.
```

For reunion, endpoint latency is zero:

```text
(20-16) - 0 = 4.
```

Propagation delay explains the echo offset but not the accumulated reunion
difference. Distance can alter what remote time is assigned under a
synchronization scheme; it does not, by itself, alter how many records two
reunited observers accumulated.
