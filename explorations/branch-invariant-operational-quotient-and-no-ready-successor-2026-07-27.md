## 1. Exact scoped theorem

Fix:

- a nonempty completion/model class \(M\);
- a declared gauge or representation equivalence \(G\);
- a fixed occurrence-identity convention;
- a complete physical and observer-operational map

  \[
  O:M/G\longrightarrow \mathcal O;
  \]

- and an external query \(q\) with target or verdict map

  \[
  V_q:M/G\longrightarrow \mathcal V_q.
  \]

Define the operational equivalence

\[
m_1\sim_O m_2
\quad\Longleftrightarrow\quad
O(m_1)=O(m_2).
\]

Then \(q\) is exactly reconstructable from the physical object if and only if

\[
\ker O\subseteq\ker V_q,
\]

equivalently, if and only if \(V_q\) is constant on every operational fibre.

Suppose two presentations

\[
\phi_i:M/G\longrightarrow X_i
\]

generate the same operational equivalence:

\[
\ker\phi_1=\ker O=\ker\phi_2.
\]

Every admitted query has the same reconstruction verdict in both
presentations. Therefore neither the names nor the number of presentation
coordinates are physical invariants of the reconstruction problem.

This is the presentation-invariant consequence of `HC-DU-059`. Its
mathematical core is standard factorization, sufficient-statistic,
observability, database-dependency, and minimal-realization terrain. Dynamic
Unity earns the typed scope and the protection against circular target-coded
schemas, not a new general theorem of mathematics.

## 3. Exact non-unification

Let

\[
a:M/G\longrightarrow A
\]

be an independently supplied physical antecedent, and let

\[
\xi:M/G\longrightarrow \Xi
\]

be the complete physical interface architecture: carrier, write, provenance,
retention, route, access, action envelope, and resource horizon.

Antecedent selection of the interface requires

\[
\ker a\subseteq\ker\xi.
\]

Target reconstruction from the resulting operational object requires

\[
\ker O\subseteq\ker V_q.
\]

Neither inclusion implies the other.

- Archive-relocation twins can preserve \(a\) while changing \(\xi\), even
  when either realized interface is dynamically sufficient for a restricted
  task.
- A selected interface can remain noninjective for a larger action class or
  held-out target.
- Injective tomography can repair reconstruction by enlarging access and
  resources without explaining why that interface formed.

Thus:

```text

  != dynamic or target sufficiency
  != unique coordinate presentation
  != ontological fundamentality.
```

`HC-DU-059`.
