## 2. Exact finite theorem package

### 2.1 Record descent and the public quotient

Let a connected graph \(G=(V,E)\) carry a finite record fibre \(X_v\) at
every vertex and an invertible comparison
\(\phi_e:X_u\rightarrow X_v\) on every directed edge. Choose a reference
vertex \(r\). Closed paths generate a holonomy group
\(H_r\leq\operatorname{Sym}(X_r)\).

A family of facts is path-independent exactly when its reference fact is
constant on every \(H_r\)-orbit. Therefore the universal finest public fact
is

\[
\boxed{X_r/H_r}.
\]

Every other path-independent fact factors uniquely through that quotient.
In an observable algebra \(\mathcal A_r\), the corresponding maximal public
algebra is

\[
\boxed{\mathcal A_r^{H_r}}.
\]

Nonzero holonomy does not eliminate shared facts. It restricts them to the
loop-invariant part.

### 2.2 Reconciliation-Frustration Monotonicity

Add a comparison edge while retaining the old fibres and maps. The new
holonomy group contains the old group, so its orbits can merge but cannot
split:

\[
\boxed{
C_{\mathrm{pub}}(G+e)
=\log_2|X/H_{G+e}|
\leq
\log_2|X/H_G|
=C_{\mathrm{pub}}(G).
}
\]

The inequality can be strict. For a triangle whose loop acts on
\(\mathbb Z_m\) by translation through \(k\), the orbit size is
\(m/\gcd(m,k)\) and the number of public states is
\(\gcd(m,k)\). In the binary flip triangle, a tree carries one public bit;
closing the inconsistent loop leaves only the constant fact.

This refutes the unqualified intuition that more connectivity always creates
more shared reality. Access and route-independent finality are different.

### 2.3 Project-or-Lift Provenance Bound

Let \(y:X\rightarrow Y\) be an action or readout that may distinguish states
inside one holonomy orbit. If the public orbit label is already retained, the
exact minimum additional provenance alphabet is

\[
\boxed{
M_y=\max_{O\in X/H}|\{y(x):x\in O\}|.
}
\]

The zero-error classical support cost is
\(\lceil\log_2M_y\rceil\) bits. For full-state recovery it becomes the log of
the largest orbit. With error, ordinary Fano-type bounds apply.

This is an information-support theorem, not a work, heat, entropy or gravity
law. A physical cost statement additionally needs an independently selected
encoding and a complete resource ledger.

### 2.4 Cycle-Lift Classification

Suppose each edge is implemented by a unitary \(U_e\), but the record retains
only the ordinary channel
\(\operatorname{Ad}_{U_e}\). Central phase replacements
\(U_e\mapsto z_eU_e\) leave every edge channel unchanged.

Modulo vertex rephasings, compatible lifts form

\[
\boxed{
H^1(G;U(1))
\cong
U(1)^{|E|-|V|+1}
}
\]

for a connected graph. There is one phase parameter per independent cycle.
Coherent route comparison can expose that phase even when every branch
channel is the identity channel.

The probe checks four loop phases, both coherent quadratures, a dephased
route null, vertex-gauge invariance and a routed-phase refinement. The
refinement predicts the signal, so the current verdict is
**interface incompleteness**, not new physical curvature.

### 2.5 Passive Refinement Flatness

For a fixed completion space \(\Omega\), passive certified update

\[
J_c(X)=X\cap C_c
\]

is associative, commutative and idempotent. The order of learning the same
facts cannot matter, and actuality—constancy on the surviving nonempty
class—is monotone under refinement.

Therefore passive learning cannot create perspectival holonomy or a new
joint past. A route effect requires active disturbance, loss or
coarse-graining, context-dependent translation, noncommuting instruments, a
changed rival class, omitted provenance, or approximate/resource-bounded
gluing. Pairwise compatibility with global inconsistency is a section
obstruction, not automatically an order effect.

## 3. Robust physical history-certificate construction

Let a complete trial record have finite outcomes \(k\). Freeze a convex set
\(C\) of every admitted classical-history instrument, an alternative set
\(A\), and bounded scores \(\|w\|_\infty\leq1\). Define

\[
g^*=
\max_{\|w\|_\infty\leq1}
\left[
\inf_{q\in A}w\cdot q-
\sup_{p\in C}w\cdot p
\right].
\]

For finite vertices this is a linear program. A positive margin gives the
optimal bounded certificate; a nonpositive margin says that the current
outcome record cannot decide the question. For a point alternative, the
margin is its \(L^1\) distance from the convex null set.

For null ceiling \(b\), alternative floor \(a\), gap \(g=a-b>0\), type-I
error \(\alpha\) and type-II error \(\beta\), an independent bounded-score
gate is

\[
n\ge
\frac{
2\left(\sqrt{\ln(1/\alpha)}+\sqrt{\ln(1/\beta)}\right)^2
}{g^2}.
\]

Preparation/readout error, leakage, detector asymmetry, arbitrary classical
history weights, phase noise, drift and calibration uncertainty belong
inside \(C\), not in an after-the-fact caveat. All ports, invalid trials,
settings and provenance flags remain in the outcome alphabet.

This turns the next physical swing into a decision product: if no complete
accessible outcome record has positive robust margin, do not run an
expensive proper-time platform. If a margin survives, the same compiler asks
which physically formed refinement absorbs it.

## 6. Measurable tests newly exposed

The council identifies six tests that were not explicit enough before:

1. **Invariant versus noninvariant readout.** On the same reconciliation
   network, verify that loop-invariant observables remain route-independent
   while a chosen noninvariant action either disappears or requires
   provenance.
2. **Provenance-capacity sweep.** Vary accessible route labels through the
   exact \(M_y\) threshold and test when action capability becomes
   route-independent.
3. **Connectivity anti-monotonicity.** Add one authenticated comparison edge
   while holding existing endpoint records fixed; measure whether the new
   cycle reduces the safe public quotient before a higher certificate repairs
   it.
4. **Approximate loop budget.** Calibrate every edge comparison error. A loop
   residue larger than the sum of edge bounds rejects the approximate-flat
   local model.
5. **Coherent cycle-lift assay.** Hold ordinary branch channels fixed, retain
   both route quadratures and every port, compare coherent and dephased
   routing, and then add authenticated implementation provenance.
6. **Robust convex-null margin.** Optimize one bounded all-record statistic
   against every calibrated classical-history instrument and stop if its
   margin is swallowed by systematic uncertainty.

These tests distinguish three possible outcomes:

```text
known process or phase control explains signal
    -> absorbed known physics

formed route/provenance record explains signal
    -> interface incompleteness

signal survives the frozen complete physical refinement class
    -> candidate formation-relative remainder
```

The third outcome is not reachable until the refinement class is nonempty,
physical and resource-bounded.

## 11. Plain-English meaning

Imagine that Alice, Bob and Carol each have a perfectly sensible way to
translate records to the next person. Carrying a detail around the full
triangle may still change it.

That does not mean there is no shared reality. The shared part is exactly
whatever survives the round trip unchanged. If they want to preserve
something that changes, they must either stop calling it a universal public
fact or record enough about the route to interpret it correctly.

The surprising part is that connecting Alice and Carol directly can reveal a
new disagreement. Everyone has more access, but fewer details are safe to
treat as route-independent until another layer resolves the loop. This gives
the user's layered-consensus intuition a precise first theorem.

In the quantum case, coherent routing can expose a phase that ordinary
channel records omit. But because an implementation/provenance record already
explains it, that is better bookkeeping, not new physics.

The research opportunity is now sharply stated:

> Find out whether the same project-or-lift law governs a real coherent
> proper-time instrument and an adversarial distributed history, and whether
> any measured residue survives every independently admissible physical
> provenance refinement.

That would turn the metaphor of “curved shared reality” into a falsifiable
theorem-and-assay program without assuming the ontology it is trying to test.
