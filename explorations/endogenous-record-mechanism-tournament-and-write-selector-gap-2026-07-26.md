# Endogenous record mechanism tournament

## Executive verdict

The strict tournament returns:

```text
NO_READY_ARENA
```

None of the five candidates currently supplies all seven `H-CCR-17`
obligations in one target-independent physical chain.

This is not a five-way tie and it is not evidence that records cannot form
physically. The mechanisms divide cleanly:

- open-system metastability and phase structure can select slow or stable
  macroscopic alternatives;
- decoherence and Spectrum Broadcast Structure can form redundant records
  relative to a supplied system--environment interaction and fragment
  structure;
- topological phases and quantum codes can select or protect a quotient
  relative to a supplied Hamiltonian or code architecture;
- causal-action and local-QFT frameworks can constrain a source or local
  measurement family; and
- material phase boundaries can retain a stable historical distinction.

But a selected stable algebra, slow manifold, phase orbit, code sector, or
induced-observable family is still only a **potential record structure**.
None of the present candidates derives, from the same target-independent
antecedent, the complete physical tokenization:

\[
(\text{blank carrier},
 \text{event-to-carrier write},
 \text{occurrence provenance},
 \text{retention/reset}).
\]

That missing object is the common **write-selector gap**.

The exact result is elementary but decisive. If two complete lawful
realizations agree on the claimed antecedent and on its selected stable
quotient, while one performs no write and the other writes the quotient into
a memory—or while they implement incompatible writes—then the formed record
does not factor through that antecedent. Stability or redundancy alone cannot
repair the failed factorization.

The tournament therefore does not activate four arena-specific builds.
It retypes `ECR-N5-S2` as one concentrated test:

> **Can a matter-flow-coupled metastable dynamics select a
> write-complete interface, up to physical gauge, rather than merely a slow
> phase simplex or a monitoring-dependent trajectory?**

Matter flow plus metastability is the first host because it alone combines a
partially selected physical clock/source structure, plausible material
memory formation, target-open time/geometry quantities, and a local
pre-hardware theorem boundary. Environment-induced records are its mandatory
absorber and near-tie control, not a second active branch.

`H-CCR-17` remains open. `HC-DU-042` earns a scoped tournament result and a
minimum-premise obstruction, not a universal no-go.

`NO_READY_ARENA` is relative to the five frozen candidate chains, the current
repository contracts, and the bounded primary-source collision used here. It
does not assert that no complete detector, biological memory, phase recorder,
or record-formation model exists in the wider literature. Such a model would
reopen the verdict if it supplied the unchanged seven receipts without
target coding or refit.

## 1. Unchanged seven-obligation passport

For one frozen lawful realization class \(\Omega/G\), let:

- \(a:\Omega/G\to A\) be the independently declared physical antecedent;
- \(\xi:\Omega/G\to I\) be the interface architecture;
- \(W\) be a physical write from a declared blank memory;
- \(r:\Omega/G\to R\) be the formed record;
- \(t:\Omega/G\to T\) be an independently held-out physical target; and
- \(\beta_H:\Omega/G\to B_H\) be complete behavior under capability and
  resource envelope \(H\).

Every candidate was tested against:

1. **target-independent selection**
   \[
   \ker a\subseteq\ker\xi;
   \]
2. **physical formation:** a provenance-bearing write from a declared blank;
3. **strict compression:** \(r\) is noninjective on the lawful nongauge
   class;
4. **record attribution:** the target varies before record conditioning;
5. **held-out reconstruction**
   \[
   \ker r\subseteq\ker t;
   \]
6. **frozen-envelope sufficiency**
   \[
   \ker r\subseteq\ker\beta_H;
   \]
7. **capability honesty:** one finite verdict after
   \(H\subset H'\).

The dispositions used below are:

| mark | meaning |
|---|---|
| `SUPPORTED` | the candidate mechanism or a primary source supports this component in a scoped class |
| `CONDITIONAL` | the component closes only after a physical partition, coupling, carrier, instrument, target, or action class is supplied |
| `OBSTRUCTED` | an exact local counterexample defeats the component under the candidate's current antecedent |
| `OPEN` | a credible route exists but no exact current receipt closes it |

`CONDITIONAL` is not “unphysical.” It locates explanatory credit.

## 2. Exact result: stable structure is not a formed record

### 2.1 Potential record structure

Let

\[
q:X\longrightarrow Q
\]

be a dynamically selected slow, invariant, central, protected, phase, or
pointer quotient. Suppose the physical evolution descends to \(Q\), exactly
or within a declared finite error and horizon.

This is a **potential record structure**. It identifies distinctions that can
be stable or autonomously propagated. It does not yet assert that any event
has written a token into a memory.

A write-complete interface is a typed object

\[
\xi_W=(M,B,W,\pi,\tau,\mathsf{reset}),
\]

where:

- \(M\) is a physical memory carrier or worldtube;
- \(B\subseteq M\) is its declared ready/blank class;
- \(W\) is the source-to-memory interaction;
- \(\pi\) certifies occurrence identity and provenance;
- \(\tau\) is a persistence horizon or error contract; and
- \(\mathsf{reset}\) names and receipts every admitted memory removal.

Observer access, decoding, and the complete future action envelope are later
fields. They cannot substitute for this formation object.

### 2.2 Theorem — write-selector factorization

Let

\[
a_0:\Omega/G\to A_0
\]

be a claimed antecedent that determines the source dynamics and potential
record quotient \(q\), and let

\[
\xi_W:\Omega/G\to I_W
\]

be the write-complete interface.

There exists an antecedent-relative write selector

\[
s_W:A_0\to I_W
\quad\text{with}\quad
\xi_W=s_W\circ a_0
\]

if and only if

\[
\ker a_0\subseteq\ker\xi_W.
\]

Consequently, if two lawful realizations have the same source dynamics and
the same selected stable quotient but different blank carrier, write,
provenance, retention, or reset structure, then the source/stability
antecedent does not select a formed record.

### Proof

This is the ordinary set-factorization criterion already used by
`HC-DU-033F`. A factor \(s_W\) exists exactly when \(\xi_W\) is constant on
every fibre of \(a_0\). Any same-antecedent/different-interface pair violates
that constancy. \(\square\)

### 2.3 Minimum exact counterexample

Let the selected potential quotient be

\[
Q=\{0,1\}
\]

and let the memory alphabet be

\[
M=\{\bot,0,1\},
\]

where \(\bot\) is blank.

Use the same source state \(q\), the same autonomous source dynamics, and the
same selected quotient in two realizations:

\[
W_{\mathrm{idle}}(q,\bot)=(q,\bot)
\]

and

\[
W_{\mathrm{write}}(q,\bot)=(q,q).
\]

The source/stability antecedent is identical. The formed record differs:
the first realization has no token; the second does. Therefore no record
selector factors through the shared antecedent.

Postcomposing \(W_{\mathrm{write}}\) with a nontrivial memory relabeling or
using a different occurrence tag gives the incompatible-write version. A
relabeling is gauge only if every read, action, provenance test, and resource
contract is correspondingly equivariant. Otherwise it is a different
physical interface.

### 2.4 What this does and does not establish

It establishes:

```text
selected stable quotient
    does not entail
formed provenance-bearing record.
```

It does **not** establish:

```text
physical dynamics can never select a write.
```

A refined physical antecedent

\[
a_W=(a_0,\text{material fields and boundary},
     \text{full coupling and environment dynamics},
     \text{physical initial/preparation state},
     \text{retention/reset resources})
\]

may select \(\xi_W\). The antecedent contains physical microdynamics and
state, not a predeclared semantic record map. The blank class, write,
provenance, persistence, and reset receipt must still be derived from or
tested against that physics. This is not “smuggling in” the answer if the
physical fields are independently motivated parts of the realization and
the factorization is proved before the held-out target is inspected.

The next swing asks whether such a write-complete antecedent can itself be
derived or naturally isolated in one arena, not whether a fundamental law
must point-select a laboratory apparatus without matter or boundary data.

## 3. Primary-source collision

### 3.1 Open-system metastability

[Macieszczak et al.](https://arxiv.org/abs/2006.01227) show that a
timescale-separated open quantum system can possess a metastable manifold
approximately represented by mixtures of finitely many metastable phases,
with effective classical stochastic dynamics among them. Time-coarse-grained
continuous-measurement records can then look like noisy classical
trajectories.

That is a strong source for:

- a dynamically selected slow subspace;
- approximate phase disjointness;
- a finite stability window; and
- effective classical transition dynamics.

It is not, by itself, a unique physical record channel. Quantum trajectories
are conditioned on an environmental monitoring. The same Markovian master
equation admits multiple diffusive unravelings with distinct monitoring
interpretations; see
[Wiseman and Diósi](https://arxiv.org/abs/quant-ph/0012016).

Thus:

```text
Liouvillian slow manifold
    may select a potential archive alphabet

monitoring / material source-to-memory coupling
    selects an actual record trajectory.
```

The distinction can disappear only if the full environment, carrier,
coupling, provenance, and access process—not merely the reduced
generator—is included in the antecedent and shown to select the same
interface up to physical equivalence.

### 3.2 Decoherence, Quantum Darwinism, and SBS

[Ollivier, Poulin, and Zurek](https://arxiv.org/abs/quant-ph/0408125)
describe the environment as a witness that redundantly spreads information
about preferred system observables.
[Le and Olaya-Castro](https://arxiv.org/abs/1803.08936) identify the
relation among strong Quantum Darwinism, strong independence, and Spectrum
Broadcast Structure.

These are the strongest established controls for:

- interaction-selected pointer information;
- redundant environmental fragments;
- observer agreement on a classical label; and
- a classical public quotient of a larger quantum state.

They do not make the system/environment/fragment/access partition disappear.
Nor do they make a pointer record sufficient for noncommuting source
structure. Coherent global access can distinguish source states whose
pointer populations and accessible fragments agree.

The DU delta cannot be “redundancy makes facts objective.” That terrain is
occupied. A surviving contribution must derive the physical partition/write
or reconstruct an independent target beyond the pointer quantity without
refitting.

### 3.3 Topological and logical sectors

[Bravyi, Hastings, and Michalakis](https://arxiv.org/abs/1001.0344) prove
stability of topological quantum order for a scoped class of local
commuting-projector Hamiltonians under weak perturbations.
[Bravyi and Terhal](https://arxiv.org/abs/0810.1983) prove that
two-dimensional stabilizer Hamiltonians cannot provide a macroscopic energy
barrier for self-correcting quantum memory.

This is strong support for Hamiltonian-selected protected structure and a
sharp limit on passive two-dimensional thermal memory. It does not turn a
ground-space sector or syndrome algebra into a provenance-bearing classical
write. The exact `HC-DU-040E` control already separates:

\[
\text{complete syndrome}
\quad\text{from}\quad
\text{protected logical quotient }N(S)/S.
\]

Measuring the syndrome, logging the source, or reading the logical sector
adds a physical interface or capability.

### 3.4 Causal-action and local-QFT sources

The causal action can select universal measures inside a supplied
variational problem, but the audited causal-fermion-system literature does
not currently select a unique observer, probe, instrument, pointer, archive,
or access boundary.

In the Fewster--Verch local measurement framework,
[Fewster and Verch](https://arxiv.org/abs/1810.06512) show how a supplied
probe state, system--probe coupling, and probe effect induce a system
observable or instrument with causal composition. The scattering structure
selects an induction map, not one input to it.

This is the strongest relativistic host after a record mechanism exists.
It is not currently the cheapest place to derive the write.

### 3.5 Phase selection and material domains

[Wallace](https://arxiv.org/abs/1808.09547) gives a decoherent-histories
account of spontaneous symmetry breaking in finite quantum systems through
approximately dynamically isolated sectors. This supports physically robust
phase alternatives without pretending that finite systems possess an exact
thermodynamic-limit superselection rule.

A symmetric phase law normally selects an orbit of phases. A realized
initial condition, fluctuation, boundary, environment, or explicit field
selects a branch. A domain can retain history, but the event-to-domain
coupling and the independent target remain to be specified. Treating “which
phase occurred” as both the record and the held-out target would be
target-coded reconstruction.

**Exact current obstruction.**

The reduced generator and its slow manifold do not select one monitoring

It is the only candidate that already joins:

1. a partially selected physical source/clock structure;
2. a plausible nonengineered material memory mechanism;

4. an exact local selector question that can be answered before hardware.

**Disposition.** `FIRST S2 HOST, NOT A POSITIVE H-CCR-17 SPECIMEN`.

physical **write-complete antecedent**:

\[
a_W=
(\text{lawful source and material fields},
 \text{physical boundary/worldtube},
 \text{full source--carrier--environment dynamics},
 \text{initial/preparation state},
 \text{retention/reset resources and horizon}).

The next claim must prove:

\[
\ker a_W\subseteq\ker\xi_W
\]

up to a declared physical gauge or unavoidable orbit.

The blank class, event-to-token map, provenance relation, persistence, and
reset receipt are outputs \(\xi_W\) to be derived or classified from this
antecedent; they are not silently copied into \(a_W\) as semantic labels.
The physical antecedent may itself be dynamically derived from realized
matter. It need not be fundamental or externally imposed. But it must be
explicit enough to exclude:

- the no-write twin;
- incompatible monitoring/unravelling twins;
- symmetry-related but operationally different memory orientations;
- a passive value that was present in the initial condition;
- a post hoc choice of coarse graining;
- a record defined from the held-out target; and
- an archive whose provenance or reset memory is omitted.

The minimal honest failure return is the fibre image

\[
\Sigma_{a_W}(\alpha)
=
\{\xi_W(\omega):a_W(\omega)=\alpha\},
\]

classified as one point, one physical orbit, a plural family, a trivial
interface, or no nontrivial interface.
