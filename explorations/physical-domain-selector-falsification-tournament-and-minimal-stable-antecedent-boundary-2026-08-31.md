# Executive result

The candidate-domain problem from `HC-DU-213` is real, but its strongest
reading was too demanding.

```text
NO_SOURCE_FREE_DOMAIN_SELECTOR_FOUND
FIVE_ESTABLISHED_FAMILIES_ARE_DOMAIN_RELATIVE
CONSISTENCY_INTERSECTIONS_CAN_SHARPEN_STRONGLY
RG_UNIVERSALITY_CAN_REMOVE_MICRODOMAIN_SENSITIVITY
GENERATED_DOMAIN_RELOCATES_TO_A_SMALLER_ANTECEDENT
ABSOLUTE_SELECTION_FROM_NOTHING_IS_NOT_A_PHYSICAL_GATE
ACTION_INDEXED_MINIMAL_STABLE_ANTECEDENT_IS_THE_REPAIR
COMPLETE_HANDOFF_STILL_UNSELECTED
NO_READY_SUCCESSOR
```

Anomaly and cobordism constraints, positivity and bootstrap, locality and
factorization, renormalization-group structure, and variational principles
all make genuine selections. None selects the complete type of object on
which it acts.

That is not a failure of those mechanisms. Every selector must be stated on
some domain. A predicate `P:C->Bool` can select a proper subfamily of `C`; it
cannot also determine that `C`, rather than another domain, was the intended
input unless a higher antecedent ranges over candidate domains. An action
`A:C->R` can select minimizers in `C`; it cannot choose its own carrier and
codomain merely by being minimized.

The opposite overcorrection is also wrong. Physics need not select its
language from nothing. A compact law package can jointly define a model
class and constrain its solutions. It then generates a domain relative to a
smaller antecedent: a signature, law, boundary contract, and equivalence.
Demanding that this antecedent also select itself produces an endless type
regress, not a sharper experimental question.

The useful replacement is therefore **not** “find a principle that chooses
the whole theory space from nothing.” It is:

> For a frozen observer action/access class, find an inclusion-minimal
> antecedent frontier whose law-generated solution class yields a no-refit
> target response stable under declared benign domain enlargement; show by
> premise ablation that every retained antecedent is load-bearing.

There need not be one context-free minimal bundle. `HC-DU-160` already proves
that action-indexed minimal selecting bundles can form an antichain. The new
criterion asks which members of that frontier are stable when the candidate
domain is enlarged in ways that preserve the antecedent's declared physical
meaning.

The strongest survivor in the literature tournament is not one principle.
It is a **consistency intersection plus universality** architecture:

```text
compact antecedent passport
  -> generated candidate class
  -> independent anomaly / unitarity / causality / crossing constraints
  -> RG or other stability quotient
  -> stable held-out response image.
```

This can plausibly derive a proper effective-theory class and make robust
predictions without selecting microscopic ontology. It is still missing from
DU as a concrete, source-pinned, physically ruler-complete example. It also
does not select the material writer, archive, provenance, observer access,
consumer, or resource horizon required for a complete record handoff.

The result is scoped Grade 4 as an exact typing/nonimplication boundary and a
source-grounded disposition. The mathematics is elementary and absorbed by
ordinary specification, model-class, inverse-problem, and selection theory.
No new law of physics, universal no-go, or ready successor is claimed.

# 1. Frozen question and distinction table

The tournament used the same question for every family:

1. What typed domain must exist before the principle can be stated?
2. What does the principle genuinely eliminate or select?
3. Does it generate the candidate domain from a smaller physical antecedent?
4. Is the selected object unique modulo a declared physical equivalence?
5. Does a held-out physical response sharpen without refitting?
6. Which ruler and material handoff fields remain supplied?

The load-bearing distinction is:

| status | exact meaning |
|---|---|
| relative filter | `P` selects a proper subfamily of a declared `C` |
| generated domain | a smaller package `(Sigma,L)` defines `C=Mod_Sigma(L)` |
| consistency intersection | several independently stated predicates shrink the same declared class |
| universality quotient | many microscopic candidates induce the same stable effective response |
| absolute selector | the mechanism selects its own language, domain, law, equivalence, and target contract with no antecedent |

The first four can be physically substantive. The fifth is not a requirement
used by ordinary science and has no clear finite falsifier.

# 3. Family 1 — anomalies, indices, and cobordism

`HC-DU-213` is already the exact positive control. Linear and cubic `U(1)`
anomaly equations selected one orbit inside the frozen five-charge, bound-nine
domain without copying the answer. Enlarging the charge bound or changing
fermion cardinality restored alternatives. The constraint was real and the
uniqueness was domain-relative.

The cobordism conjecture does not remove this boundary. McNamara and Vafa
argue that a quantum-gravity configuration space with nontrivial cobordism
classes lies in the swampland, based on the premise that consistent quantum
gravity has no global symmetries. Trivializing the classes then demands
defects ([primary paper](https://arxiv.org/abs/1909.10355)). This is a bold
constraint on a supplied quantum-gravity configuration category; the paper
states the no-global-symmetry premise and labels the result an argument and
conjecture, not an unconditional classification of all physical domains.

**Value.** Topological and anomaly constraints can reveal missing sectors or
defects and can eliminate vast candidate regions without fitting a measured
number.

**Kill.** They do not select spacetime dimension, the entire field category,
the symmetry language, the observer action class, or the detector ruler by
themselves.

**Disposition.** `RELATIVE_FILTER_ONLY`, with high structural value and no
new DU novelty.

# 4. Family 2 — unitarity, positivity, analyticity, and bootstrap

Adams, Arkani-Hamed, Dubovsky, Nicolis, and Rattazzi show that canonical
analyticity of a local Lorentz-invariant UV S-matrix imposes strict positivity
on leading irrelevant EFT coefficients; wrong signs manifest as superluminal
fluctuations and obstruct the assumed UV completion
([primary paper](https://arxiv.org/abs/hep-th/0602178)). This is exactly the
kind of non-copy physical selector DU should credit.

Its antecedent is explicit: local Lorentz-invariant EFTs and UV theories with
the canonical analytic S-matrix properties. It selects coefficient regions
inside that object type; it does not establish that every physical theory
must have that S-matrix or select the EFT field content.

Conformal bootstrap is an even sharper positive control for intersection
selection. Rattazzi, Rychkov, Tonni, and Vichi derive bounds from unitarity,
operator-product structure, conformal blocks, and crossing in an arbitrary
unitary four-dimensional CFT with a declared scalar operator
([primary paper](https://arxiv.org/abs/0807.0004)). The method can produce
small allowed regions when more assumptions and data are supplied. The phrase
“arbitrary unitary 4D CFT” is broad inside CFT, but still supplies dimension,
unitarity, conformal symmetry, an operator category, and crossing structure.

**Value.** This family has the highest near-term power to contract locked
response images without proposing new microscopic dynamics.

**Kill.** It filters an S-matrix/EFT/CFT domain already typed. Islands may be
unique relative to declared gaps, symmetries, operator assumptions, and
numerical completeness, not absolute theory selection.

**Disposition.** `CONSISTENCY_INTERSECTION_SHARPENING`; strongest tournament
survivor, but no ready DU successor until one frozen physical arena carries
all assumptions and a locked ruler-complete target without refit.

# 5. Family 3 — locality, causality, and factorization

Weinberg's soft-particle S-matrix result is a powerful derivation rather than
a relabel. From Lorentz invariance and pole structure, plus the assumed zero
mass and spins of photons and gravitons, it derives charge conservation and
equality of gravitational and inertial mass and constrains higher-spin
macroscopic couplings
([primary paper](https://journals.aps.org/pr/abstract/10.1103/PhysRev.135.B1049)).

This shows exactly why “the assumptions were supplied” must not be used as a
blanket dismissal. A small antecedent can force profound downstream
structure. It also shows the selection boundary: the S-matrix, Lorentz
structure, pole assumptions, and particle mass/spin content are present
before the theorem acts.

Factorization approaches likewise describe how local observables compose.
For example, perturbative AQFT observables can form a factorization algebra
for a large class of declared Lorentzian theories
([primary construction](https://arxiv.org/abs/2212.08175)). The construction
organizes observables of a supplied theory; it does not select which
Lorentzian theory or which material records nature realizes.

**Value.** Causal/factorization assumptions can force universal coupling and
composition relations and may be the cleanest route from a small antecedent
to large physical consequences.

**Kill.** They do not choose the S-matrix, regions, algebra net, particle
content, lawful intervention set, or source provenance from nothing.

**Disposition.** `GENERATED_DOMAIN_RELATIVE_TO_SMALLER_ANTECEDENT` for
specific reconstructions; otherwise `RELATIVE_FILTER_ONLY`.

# 6. Family 4 — RG stability, fixed points, and UV completion

Renormalization-group theory contributes something different: not selection
of one microscopic domain, but controlled irrelevance of microscopic detail.
Komargodski and Schwimmer derive a monotonically decreasing quantity along
four-dimensional unitary RG flows from the dilaton effective action and
S-matrix unitarity, establishing the `a`-theorem in that scope
([primary paper](https://arxiv.org/abs/1107.3987)). It orders flows after the
four-dimensional QFT and its assumptions are declared.

Asymptotic-safety work makes the domain dependence especially visible.
Reuter introduces a scale-dependent effective gravitational action and an
exact evolution equation, then solves a simple truncation of the space of
actions ([primary paper](https://arxiv.org/abs/hep-th/9605030)). The flow can
select fixed-point behavior relative to the chosen theory-space and
truncation; it does not choose the entire action space by running inside it.

**Value.** RG universality can make a target stable across many microscopic
completions. DU may not need to reconstruct or select inaccessible
microphysics if all admitted completions lie in one response universality
class.

**Kill.** Universality is a many-to-one quotient, not a unique microscopic
selector. Flow and fixed points require a declared theory/action space,
scale map, and physical interpretation of the couplings.

**Disposition.** `GENERATED_DOMAIN_RELATIVE_TO_SMALLER_ANTECEDENT` plus
`CONSISTENCY_INTERSECTION_SHARPENING`. This is the most important correction
to the assumption that the candidate microdomain must be uniquely selected.

# 7. Family 5 — variational/action selection and stability

A variational principle can be a genuine physical selector. Once its carrier,
action, constraints, and boundary class are fixed, it may select a unique
orbit or target-sufficient minimizer class. This is stronger than a
representation of already chosen solutions.

It remains domain-relative by construction. Finster and Langer prove
existence of minimizers for causal variational principles on second-countable
locally compact Hausdorff spaces under stated Lagrangian and regularity
conditions, first on compact subsets and then through controlled limits
([primary paper](https://arxiv.org/abs/2002.04412)). The theorem is
substantive; the topological space, Lagrangian properties, measure type, and
variation class are antecedents.

This matches DU's earlier causal-action audit: selecting a universal measure
inside the supplied variational problem does not automatically select an
observer, instrument, archive, access boundary, or complete record interface.

**Value.** Variational physics is the strongest candidate for selecting
realized configurations, stable sectors, or relational orbits after a compact
law package is justified.

**Kill.** Minimizing an action cannot make its carrier, constraints, boundary
conditions, and physical quotient disappear. A minimizer is not thereby a
record or its consumer.

**Disposition.** `RELATIVE_FILTER_ONLY`, with the highest state/solution
selection strength and no complete-handoff selection.

# 8. Exact typed theorem boundary

## Proposition 1 — object-level selectors are domain-relative

Let `D` be a class of candidate domains and let

\[
C_d
\]

be the candidate set at `d in D`. For each `d`, let

\[
P_d:C_d\to\{0,1\}
\]

be a selection predicate and define

\[
S_d=\{x\in C_d:P_d(x)=1\}.
\]

The object-level selector determines `S_d` conditional on `d`. If two
distinct domains have nonempty selected families, the predicates alone do
not select one domain. A domain decision requires an additional rule

\[
\mu:D\to\{0,1\}
\]

or equivalent higher antecedent.

### Proof

The total selected family is

\[
S=\bigcup_{d\in D}\{d\}\times S_d.
\]

When `S_d` and `S_e` are both nonempty for `d!=e`, `S` contains candidates
over both domains. No value of `P_d` compares `d` with `e`, because those
predicates are typed on different fibres. A rule on the base `D` is needed.
QED.

This is elementary dependent typing and set theory, not a novel theorem.
If the family is defined over an explicitly supplied base `D` and exactly one
fibre survives, then it does select that fibre **relative to `D`**. That is a
legitimate consistency-intersection success, not absolute selection of the
meta-domain `D` itself.

## Proposition 2 — domain generation relocates rather than fails

Let a specification package `(Sigma,L)` define

\[
C_{\Sigma,L}=\operatorname{Mod}_{\Sigma}(L).
\]

Then `(Sigma,L)` generates its model domain rather than selecting a member of
an externally enumerated list. It does not, without a meta-rule, select
`(Sigma,L)` from all signatures and laws.

This is not a defect. `(Sigma,L)` may be a smaller, independently motivated
physical antecedent with extensive downstream consequences. Requiring every
meta-rule to select its own input domain repeats Proposition 1 at the next
type level and supplies no finite empirical discriminator.

## Corollary — absolute source-free selection is not a usable DU gate

No ordinary physical theory earns credit by having no antecedents. The
scientific burden is instead to expose and minimize the antecedent relative
to a declared action/target problem, then test its necessity, stability, and
predictive consequences.

# 9. Repaired criterion — action-indexed minimal stable antecedent

`HC-DU-160` already blocks one universal minimum. For a fixed action/access
class `H`, inclusion-minimal response-sufficient antecedent bundles can form
an antichain. The repair therefore preserves a frontier rather than naming
one privileged bundle.

Let:

- `B` be one candidate antecedent bundle;
- `C_B` be the class generated by it;
- `Q_B` be the subfamily selected by its independent consistency and dynamic
  constraints;
- `R_H` be the complete admitted response for action class `H`;
- `T` be a held-out target; and
- `E(B)` be declared benign enrichments that preserve the physical meaning
  of `B` while widening representational or microscopic detail.

Call `B` **stable and target-sufficient** when:

1. `Q_B` is nonempty and proper in `C_B`;
2. the selector contains no coordinate isomorphic to the selected answer;
3. `T(Q_B)` is narrower than the law-only incumbent image without refit;
4. the physical response and target image are invariant under every declared
   enrichment in `E(B)` after quotienting physical equivalence;
5. removing any load-bearing premise either enlarges the response/target
   image or destroys the construction; and
6. the ruler, action envelope, and every claimed material interface are
   explicitly present rather than inferred from the selected state.

The inclusion-minimal bundles satisfying these conditions form the
**minimal stable antecedent frontier for `(H,T,E)`**.

This is a research contract, not a theorem of nature. Robust optimization,
specification minimality, model selection, sufficient statistics, and
universality absorb its ingredients. Its DU value is that it makes the
candidate-domain objection finite and attackable.

# 10. What the result changes

## The old reopener was too strict

The phrase “physically selected candidate domain” could be read as requiring
the domain, language, and law to arise with no antecedent. No established
mechanism passes that reading, and the regress shows why. Keeping it would
reject ordinary successful derivations such as Weinberg's soft theorem merely
because they begin with typed assumptions.

## The corrected reopener

A future candidate need not select itself from nothing. It must provide:

```text
one explicit compact antecedent passport
  + a generated rather than target-curated candidate class
  + independent non-copy constraints or dynamics
  + an action-indexed minimality/ablation audit
  + stability under declared benign domain enlargement
  + a no-refit locked physical response with its ruler
  + a separately selected complete material handoff before any record claim.
```

This remains demanding but is attainable in principle.

## Why consistency intersection is the best survivor

No single principle needs to do everything. Anomaly freedom, positivity,
unitarity, crossing, locality, RG stability, and variational stability can be
independent filters on one generated class. Their intersection may be far
smaller than any one filter and may stabilize a response even when the
microscopic completion remains nonunique.

That architecture earns credit only when:

- all predicates are fixed before the target is inspected;
- the intersection is not made unique by a hand-chosen finite box;
- each premise is ablated;
- nearby domain enrichments do not reopen the target image; and
- the target is a physical response with a calibrated ruler, not a bare
  representation coordinate.

# 11. What remains open

The tournament does not provide a ready physical successor.

1. No DU candidate currently supplies a compact generated QFT domain on which
   independent consistency intersections produce a stable new held-out
   response.
2. The anomaly calibration remains the only exact non-copy positive control,
   and its target/ruler stability fails under simple domain enlargement.
3. RG universality suggests that unique microdomain selection may be
   unnecessary, but no source-pinned DU specimen yet proves target constancy
   across a physically complete universality class.
4. None of the five families selects the complete writer--archive--provenance--
   access--consumer--resource handoff.
5. A consistency-selected theory or state is not thereby a formed record.

The honest portfolio disposition is therefore still `NO_READY_SUCCESSOR`.
The no-ready state is now better localized: the missing object is not an
impossible source-free source. It is one concrete minimal stable antecedent
passport with a locked physical response—and, on the record branch, a
separately selected complete material handoff.
