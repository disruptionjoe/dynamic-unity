# Heterodox professor: dual primitive-record-clock wave

## Executive verdict

The new premise opens a real research route, but not in its shortest verbal
form.

The bounded swing overturns this proposition:

> Universal record cadence plus causal message delay is sufficient by itself
> to yield Lorentzian kinematics and reunion aging, and Branch L and `G-full`
> are equally complete without extra structure.

The exact result is:

> **`CADENCE-PLUS-DELAY-ALONE-OVERTURNED /
> L-ORDER-PLUS-SPACETIME-DENSITY-CONDITIONALLY-RECOVERS-1P1-KINEMATICS /
> G-FULL-FAILS-REUNION-AND-PREFERRED-FRAME-NULLS /
> G-GATED-FINITE-RECOVERY-REQUIRES-EXPOSED-CLOCK-AND-MATERIAL-DYNAMICS`.**

Three conclusions should be kept separate.

1. **Branch L is promising but incomplete.** Causal order supplies a
   conformal structure under substantial coordination, linearity, and
   manifoldlike assumptions. A common **spacetime-event** density can remove
   the conformal factor in the exact `1+1` fixture. The density of records
   along one observer chain is not automatically that volume density, and a
   separate observer-chain calibration remains necessary.
2. **Bare `G-full` is locally killed as an account of relativistic elapsed
   time.** If every observer writes exactly one physical record on every
   global tick, reunited observers have equal counts. Message latency changes
   remote assignments, not the counts at their shared endpoints. The same
   substrate exposes absolute motion in a two-way light-time experiment.
3. **Branch G itself remains live.** A `G-gated` completion with a
   Lorentz-shaped internal-record gate and matching material contraction
   reproduces the finite reunion and round-trip targets. Those are added
   dynamics, not consequences of delay. More importantly,
   [Arrighi, Facchini, and Forets](https://arxiv.org/abs/1404.4499) give a
   positive antecedent: a special `1+1` Clock QCA is exactly covariant under
   their discrete circuit-encoding transformations. The high-value next
   build is therefore not another generic clock argument. It is to extract an
   operational observer and accumulated-record functional from that exact
   construction and test it at reunion.

The global clock should not be rejected for being a clock. It should be made
physical enough to calculate with. If its foliation has no possible
operational consequence, it risks being surplus structure; if it does have a
consequence, that consequence is the discriminator.

## 3. Type and stress-test both premise branches

### 3.1 Common ontology

The following definitions are used in both branches.

**Causal precedence.** A locally finite partial order \(x\prec y\) means that
event \(x\) can causally condition event \(y\). It is not a metric distance,
coordinate time, or simultaneity relation.

**Observer.** An observer is a causally persistent finite-memory process: a
selected chain or causally connected aggregate whose state transitions can
receive a message, retain a stable distinction, and later condition an
outgoing message. It is not assumed to carry proper time in advance.

**Physical record.** A record is an irreversible or operationally stable
change in that process's distinguishable memory state, with causal
provenance. A substrate computation step, duplicated bit, gauge label, or
reversible internal oscillation is not automatically a new record.

**Record equivalence.** Two records are equivalent for cadence comparison
when they instantiate the same calibrated local transition class after
quotienting duplicate encodings, while retaining causally different
provenance. This is an assumption to be implemented, not a solved observer
ontology.

**Message.** A message is a payload-bearing causal connection from one
observer's send record to another observer's receipt record, optionally
followed by reflection or acknowledgement. A path can contain unobserved
substrate events.

**Logical-clock order.** Logical order is the partial ordering recovered from
local succession and message relations. It need not determine a unique
global linear order.

**Proper time.** Proper time is not primitive here. It is a candidate scalar
reconstructed from a successful interval rule and then calibrated to a
physical observer-record process.

**Coordinate time and simultaneity.** These are chart and synchronization
objects reconstructed from observer comparisons. They are not local record
counts.
